# 段階1-C：不動点の一意存在と反復列の収束

2026年9月15日実施。P1-04を中心に、第10〜12章の不動点定理の本文・予告・再掲・演習を修正しました。Part 2の到達目標も実装内容に合わせました。環境は引き続き Lean 4.29.0-rc6 / Mathlib `5c8398df528176d9c87ccd9226ba8f7c8852d59c` です。

## 数学とAPIの修正

不動点の存在を述べる一般定理に `[Nonempty X]` を追加しました。空の距離空間は完備で、空集合上の自己写像は縮小条件を満たしますが、不動点となる元は存在しません。初期点を引数として受け取る版も用意し、そこから局所的な `Nonempty X` を構成しています。

固定版には `ContractingWith.existsFixedPoint` というAPIはありません。次の役割を区別して証明を組み立て直しました。

| 役割 | API |
|---|---|
| 不動点の構成 | `hf.fixedPoint f` |
| 構成した点が不動点であること | `hf.fixedPoint_isFixedPt` |
| 任意の不動点が構成した点と等しいこと | `hf.fixedPoint_unique` |
| 既に与えられた2つの不動点の一致 | `hf.fixedPoint_unique'` |
| 反復列の収束 | `hf.tendsto_iterate_fixedPoint` |

構成と収束には非空性・完備性を使いますが、与えられた2つの不動点の一致を示す `fixedPoint_unique'` は距離空間と縮小性だけで使えます。`ContractingWith` 自体は型クラスではなく命題です。拡張距離空間向けの `efixedPoint` には初期点と有限距離の仮定が必要なことも説明しました。

Mathlibの一般の定理を最初から再証明するのではなく、既存APIを適用して一意存在・具体的な値・反復収束を示す章であることを、本文とPart 2で明記しました。

## 完成した掲載例

- 非空な完備距離空間上の一意存在、および全初期点から同じ不動点への収束。
- `x / 2` の縮小性、一意存在、不動点が0であること、任意の実数からの反復収束。
- `x / 3 + 1` の縮小性の2通りの証明、一意存在、不動点が3/2であること、反復収束。
- ℓ²上のスカラー倍 `(1 / 2 : ℝ) • x` が成分ごとの `x n / 2` と一致すること、縮小性、一意存在、ゼロ列への反復収束。
- 縮小性から各点での連続性を得る証明と、不動点の近傍についての `Tendsto`。連続性と反復回数についての収束は別の主張であると説明。

具体的な収束先を0や3/2とするには、まずその点が不動点であることを確認し、一意性でMathlibの不動点と同定します。収束定理の戻り値から、根拠なく具体的な値を取り出すコードを削除しました。
