## ディリクレ関数の可積分性

実数値のディリクレ関数は、有理数の像の指示関数として定義しました。有理数の像は可算で、Lebesgue測度は原子を持たないため、この集合の測度は0です。従ってこの関数はほとんど至るところ0に等しく、全実数上でもLebesgue可積分で、その積分は0です。

第16章では、次の主張を別々に証明しています。

1. 有理数の像の測度が0であること。
2. ディリクレ関数がAEでゼロ関数と等しいこと。
3. `Integrable.congr` により、ゼロ関数の可積分性を移せること。
4. `integral_congr_ae` により、その積分が0になること。
5. `ae_restrict_of_ae` で測度を `[0,1]` に制限した場合も、可積分性と積分値0の両方が成立すること。

`integral_undef` の前提は非可積分性です。ディリクレ関数にこの定理を適用しようとしていた演習は、可積分な関数との対比へ修正しました。`[0,1]` 上でリーマン可積分ではないという紙上の説明と、Lebesgue可積分であるという主張を区別しています。リーマン不可積分性自体をLeanで証明した、という意味ではありません。

第12章の予告も同じ説明へ揃え、第14章のAEの例では実数値の指示関数を用いました。AEフィルターの確認コマンドも、存在する `MeasureTheory.ae` に訂正しています。

## 可測性と積分の説明

優収束定理の前提とつながるよう、第16章の `Integrable` の説明を `AEStronglyMeasurable f μ ∧ HasFiniteIntegral f μ` へ修正しました。正部分・負部分で積分を説明できるのは実数値関数であり、一般のバナッハ空間値関数にこの分解を適用する記述を訂正しました。

関連するP2-029・P2-030・P2-031にも対応しました。

- 有限測度上の定数関数と、有界閉区間上の正弦関数の可積分性を検証。
- 非負実数値関数の変換公式を `integral_eq_lintegral_of_nonneg_ae` とAE強可測性に揃え、命題として検証。`ENNReal.toReal ∞ = 0` の規約にも触れ、通常の有限な積分として使う場合には可積分性を確認することを明記。
- `exp(-x)` の半直線上の可積分性を、`integrableOn_exp_neg_Ioi` と `integrableOn_Ici_iff_integrableOn_Ioi` で証明。補足では、連続性からAE強可測性を、前の完成解答から有限性を取り出して定義を確認。補足が独立した再証明ではないことを明記。
- 積分のノルム不等式について、非可積分の場合は左辺が規約値0、右辺は非負であると説明。右辺まで必ず0になるという記述を訂正。

## Fatou・優収束と演習

| 対象 | 修正した仮定と呼び出し |
|---|---|
| `lintegral_iSup` | 各項の `Measurable` と、関数列の各点での `Monotone` を渡す。AE版の `lintegral_iSup'` と区別する。 |
| `lintegral_liminf_le` | 各項の `Measurable` を受け取る版。 |
| `lintegral_liminf_le'` | 各項の `AEMeasurable` を受け取る版。本文のAEを仮定する完成例はこちらを使う。 |
| `tendsto_integral_of_dominated_convergence` | 優関数の後に、AE強可測性、優関数の可積分性、AE支配、AE収束の順で渡す。 |

実数値関数では `AEMeasurable.aestronglyMeasurable` で必要な仮定へ移せることも、独立した補題で確認しました。比較表・InfoViewの要約・Q&Aの仮定と引数順を合わせています。Fatouが等号を主張するかのような導入、可測性を省いた表、三定理を単純な強さの順位で比較する記述、優関数を探すことが唯一の作業だという説明を訂正しました（P2-032）。

第17章の演習はすべて未証明部分を除き、以下を検証しています。

- `Monotone f` の各点での意味と、各項が定数関数 `f n a = n` である単調増加列への適用。
- `movingIndicator n = 1_[n,n+1)` の可測性、各項の非負積分が1であること、各点で0に収束すること。これらからFatouの両辺が `0 < 1` となる真の不等式を証明。
- `sineSequence n x = sin(n*x)/n` のノルムを `1/n` で評価し、はさみうちで各点収束を証明。`n=0` はLeanの除算の定義と一致するよう0とし、定数1による支配の証明では明示的に分岐。
- `[0,1]` の制限測度上で、定数1の可積分性と各項のAE強可測性を揃え、優収束定理による積分列の0への収束を証明。別解では区間の測度が1であることと積分のノルム評価から直接はさみうちを適用（P2-033）。

Part 3の到達目標は、本文で使用している実数値の積分への優収束定理の適用に合わせました。一般定理を最初から再証明する範囲ではないことも明記しました。
