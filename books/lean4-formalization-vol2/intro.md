# はじめに

本巻は「Lean 4で始める数学の形式化」シリーズの第2巻です。連続性を表す `Filter.Tendsto` と `nhds` から出発し、距離空間・位相空間・完備性を学んで、Banachの不動点定理を使うところまで進みます。

本巻の本文は[合本](https://zenn.dev/matsuteru/books/lean4-formalization)のPart 2（第6〜11章）に対応します。合本をお持ちの場合は同じ内容を読めるため、本巻を重ねて購入する必要はありません。

## この巻で目指すこと

Mathlibの `ContractingWith.fixedPoint` と関連する定理を使い、**非空な完備距離空間上の縮小写像について、不動点の一意存在と反復列の収束を証明する**ことが到達目標です。具体例では、不動点の値も求めます。

一般定理の適用では、数学の仮定を型クラスや命題として揃える過程を説明します。Banachの不動点定理そのものを最初から再証明することと、ライブラリにある定理を使って結論を得ることを区別して読み進めてください。

| 章 | 学ぶ内容 |
|---|---|
| [第6章](ch06) | 連続性の仮定、フィルター、近傍、極限と連続性の対応 |
| [第7章](ch07) | 距離空間の構造、距離の公理、開球と閉球 |
| [第8章](ch08) | 位相空間、連続写像、コンパクト性 |
| [第9章](ch09) | Cauchy列、完備性、収束と延長 |
| [第10章](ch10) | ℓ²、Hilbert空間、有限次元と無限次元の違い |
| [第11章](ch11) | 縮小写像、不動点の一意存在、具体的な値、反復列の収束 |

章番号は第1巻・合本との対応を保つため、第6〜11章としています。Zennの目次では序文も一項目として数えるため、画面の項目番号と本文の章番号は異なります。

## 前提知識

数学では、数列・関数の極限、距離空間と位相の基礎、線形代数の基本的な概念を前提とします。Leanでは、型クラス、仮定とゴールの読み方、基本的なタクティク、Mathlibの補題探索を使います。

[第1巻『AI駆動で学ぶ Lean 4 入門』](https://zenn.dev/matsuteru/books/ab366ea6fa62f6)がこれらのLeanの基礎を扱っています。同程度の知識があれば、本巻から始めることもできます。第6章の出発点となる予告コードは、その章にも再掲しています。

## 掲載コードと同じ環境を使う

検証に使用した組み合わせは、**Lean 4.29.0-rc6** と **Mathlib `5c8398df528176d9c87ccd9226ba8f7c8852d59c`** です。Leanはリリース候補版であり、最新版や安定版という意味ではありません。

第1巻の固定環境を準備済みなら、同じ `lean` フォルダを使えます。初めて準備する場合は、無料公開の[第1巻・第1章の環境構築](https://zenn.dev/matsuteru/books/ab366ea6fa62f6/viewer/d579df)を参照してください。

Git、VS Code、公式Lean 4拡張機能を準備したうえで、新しい作業場所に次の手順で検証用プロジェクトを取得します。

```sh
git clone https://github.com/sakuramaguro/zenn-articles.git
cd zenn-articles
# 掲載コードを検証した版を使う
git checkout de47df71b6aae0523272ef689d6d30a623bfbdc4
cd lean
lake exe cache get
lake build
```

VS Codeで開くのは `lean` フォルダです。通常の学習では `lake update` を実行せず、固定した依存関係を使ってください。詳しい手順は[検証環境のREADME](https://github.com/sakuramaguro/zenn-articles/blob/de47df71b6aae0523272ef689d6d30a623bfbdc4/lean/README.md)にあります。

## コード欄の読み方

| 表示 | 使い方 |
|---|---|
| 完成例・確認コマンド | 本文に示した `import`、先行宣言などの前提を揃えて実行します。型の確認に成功することと、新しい定理を証明することは区別します。 |
| 断片 | 本文で指定された前後のコードと連結するか、指定位置へ挿入します。 |
| 意図的なエラー例 | 失敗する理由を調べる例です。完成例とは別のファイルで試します。 |
| 未完成の骨格・練習問題 | `sorry` などの穴を自分で埋める問題です。完成した解答とは区別します。 |

各章の冒頭にある実行手順を確認してください。同じ章の中でも、別ファイルで試す例と、先行する宣言を引き継ぐ例があります。

`No goals` はその位置のゴールが閉じたことを示します。完成の確認では、エラー・警告、主要定理の `#print axioms`、仮定と結論の数学的な意味を確認します。未証明部分に依存する `sorryAx` が残っていないことも確かめます。

## 練習問題の進め方

各章に4問、計24問の章末問題があります。概念を説明する問題、Leanで証明する問題、数学と型の対応を読む問題、発展問題を通じて復習します。

まず問題を読み、紙の上で何を示すか考えてからコードを書いてください。詰まったらヒントを開き、解答と比較します。動いたコードを写すだけで終わらず、「どの仮定を、どの定理に渡したか」を説明できるか確かめると理解が深まります。

それでは、[第6章](ch06)で連続性の仮定と `Filter.Tendsto` の関係から始めましょう。
