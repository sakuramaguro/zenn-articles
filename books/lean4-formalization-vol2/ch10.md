## 10.1 `lp` 空間とは何者か ──── Mathlib の深淵を覗く

### 最初の `#check` から始める

まず型シグネチャを確認します。

```lean:完成例・確認コマンド
#check @lp
-- 出力の末尾は AddSubgroup (PreLp E)。引数の型クラスも確認する。
```

:::message
**💡 型シグネチャを読む**

`lp E p` は、各成分の型 `E i` が `NormedAddCommGroup` を持つときに定義される加法部分群です。

- `E`：各添字 `i` に成分の型を割り当てる関数
- `p : ℝ≥0∞`：拡張非負実数で表した指数
- 戻り値：`AddSubgroup (PreLp E)`。`PreLp E` の元は各成分を持つ関数です。

加法部分群は型としても使えます。そのときの元は、関数と所属条件の証明を組にした部分型です。実数列の $\ell^2$ は次のように書けます。

```lean:完成例・確認コマンド
#check (lp (fun _ : ℕ => ℝ) (2 : ℝ≥0∞) : Type)
#check (lp (fun _ : ℕ => ℝ) 2 : Type) -- 2 の型は引数から推論される
```

`(2 : ℝ≥0∞)` という注釈は指数の型を読者に明示しますが、ここでは必須ではありません。注釈なしの `2` も、`lp` の第2引数の型から `ℝ≥0∞` と推論されます。
:::

### `lp` の数学的中身

```lean:完成例・確認コマンド
#print lp
#print Memℓp
#check memℓp_zero_iff
#check memℓp_infty_iff
#check @memℓp_gen_iff

-- 本章の実数列・指数2に特殊化した同値
theorem mem_two_iff (f : ℕ → ℝ) :
    Memℓp f (2 : ℝ≥0∞) ↔ Summable (fun n => ‖f n‖ ^ (2 : ℕ)) := by
  simpa using (memℓp_gen_iff (by norm_num : 0 < (2 : ℝ≥0∞).toReal) (f := f))
```

`lp` を型として使うと、その元は **部分型（subtype）** の元になります。「すべての成分を持つ関数 `f : ℕ → ℝ` のうち、$\sum_{n=0}^\infty |f(n)|^2 < \infty$ を満たすもの」という条件付きの型です。

`Memℓp f p` の定義は、指数によって次のように分かれます。

| 指数 | 所属条件 |
|---|---|
| `p = 0` | 非零の成分を持つ添字が有限個 |
| `p = ∞` | 成分のノルム全体が上に有界 |
| `0 < p < ∞` | `Summable (fun i => ‖f i‖ ^ p.toReal)` |

`memℓp_gen_iff` の仮定 `0 < p.toReal` は、最後の行に対応します。実数値の `∑'` は総和可能でない族にも規約値を持つため、「`∑'` が実数として有限」と書くだけでは級数の収束条件になりません。ここでは `Summable` を使います。上の `mem_two_iff` では、実数冪の指数を自然数の2乗に整理しています。

数学的に書けば：

$$
\ell^2 = \ell^2(\mathbb{N}, \mathbb{R}) = \left\{ (x_n)_{n \geq 0} \in \mathbb{R}^{\mathbb{N}} \;\middle|\; \sum_{n=0}^{\infty} |x_n|^2 < \infty \right\}
$$

```lean:完成例・確認コマンド
-- lp を型として使い、所属条件の証明を伴う標準基底ベクトルを作る
example (n : ℕ) : lp (fun _ : ℕ => ℝ) (2 : ℝ≥0∞) :=
  lp.single 2 n (1 : ℝ)
```

### 数学↔Lean 対応表：`lp` の基本構造

| 数学の記法 | Lean の記法 |
|-----------|------------|
| $\ell^2(\mathbb{N}, \mathbb{R})$ | `lp (fun _ : ℕ => ℝ) (2 : ℝ≥0∞)` |
| $x \in \ell^2$ の $n$ 成分 $x_n$ | `x n`（`x : lp (fun _ : ℕ => ℝ) (2 : ℝ≥0∞)` として） |
| $\sum_{n} \lvert x_n\rvert^2 < \infty$ | `Memℓp x 2` |
| 標準基底 $e_n = (\delta_{nk})_{k \geq 0}$ | `lp.single 2 n (1 : ℝ)` |
| $\ell^2$ ノルム $\|x\| = \sqrt{\sum_n \lvert x_n\rvert^2}$ | `‖x‖`（`lp` のノルム構造） |
| $\ell^2$ 距離 $d(x,y) = \|x - y\|$ | `dist x y`（`MetricSpace` から自動導出） |

## 10.2 免許証の確認 ──── `MetricSpace` と `CompleteSpace`

### `MetricSpace` の確認

```lean:完成例・確認コマンド
-- lp は NormedAddCommGroup のインスタンス
#check (inferInstance : NormedAddCommGroup (lp (fun _ : ℕ => ℝ) (2 : ℝ≥0∞)))

-- NormedAddCommGroup から MetricSpace が自動導出される
-- dist x y := ‖x - y‖
#check (inferInstance : MetricSpace (lp (fun _ : ℕ => ℝ) (2 : ℝ≥0∞)))
```

**距離構造を項として与える例：次の2つのブロックを連結する**

```lean:完成例・確認コマンド
noncomputable example : MetricSpace (lp (fun _ : ℕ => ℝ) (2 : ℝ≥0∞)) := by
```

`noncomputable` は、この距離構造が非計算的な実数ノルムに依存することを表します。上の `:= by` の直後では、構造を項として与える次のゴールが残っています。

```text
⊢ MetricSpace (lp (fun _ : ℕ => ℝ) (2 : ℝ≥0∞))
```

```lean:断片
  exact inferInstance  -- No goals ✓
```

Leanのインスタンス探索が、`lp` の `NormedAddCommGroup` から距離空間構造を取得します。距離空間から擬距離空間へは分離条件を忘れられますが、擬距離空間一般から距離空間へ進めるわけではありません。

### `CompleteSpace` の確認

一般の `lp E p` のノルム空間構造・完備性を使うには、`[Fact (1 ≤ p)]` が必要です。完備性にはさらに各成分 `E i` の完備性を仮定します。本章では `p = 2`、各成分が `ℝ` なので、これらの証明をインスタンス探索で得られます。

```lean:完成例・確認コマンド
#check (inferInstance : CompleteSpace (lp (fun _ : ℕ => ℝ) (2 : ℝ≥0∞)))

-- 一般形では Fact (1 ≤ p) と各成分の完備性が必要
#check @lp.completeSpace
#check @lp.memℓp_of_tendsto
#check @lp.tendsto_lp_of_tendsto_pi
```

:::message
**💡 「$\ell^2$ が完備」の証明の核心**

`lp.completeSpace` の証明はどのようなものでしょうか。内部を覗くと：

1. $\ell^2$ の Cauchy 列 $(f^{(k)})_{k}$ を取る
2. 各座標 $n$ について $\mathbb{R}$ の Cauchy 列 $(f^{(k)}_n)_k$ が収束する（$\mathbb{R}$ の完備性）
3. 各座標の極限を $f_n$ とすると、$f = (f_n)_n \in \ell^2$ が示せる
4. $f^{(k)} \to f$（$\ell^2$ のノルムで）

ステップ3では、Cauchy列のノルムが一様に有界であることを使います。有限個の座標について二乗和の評価を極限へ移し、有限部分和の共通の上界から極限列の総和可能性を得ます。固定版では、この部分を `lp.memℓp_of_tendsto`、ステップ4を `lp.tendsto_lp_of_tendsto_pi` が担います。座標ごとの収束だけで十分なのではなく、Cauchy性による評価が必要です。この証明は有限部分和とノルムの評価で読め、Bochner積分を展開する必要はありません。
:::



### `ProperSpace` の意味とインスタンス探索の限界

```lean:完成例・確認コマンド
-- 10.0節の import と ell2 の定義の後に置く
#check ProperSpace
#check (inferInstance : ProperSpace ℝ)
-- ell2 については10.3節で ¬ ProperSpace ell2 を証明する。
```

`ProperSpace` は、すべての閉球がコンパクトであることを表します。$\ell^2$ ではこの性質が成り立ちません。ただし、`inferInstance` が失敗しても、それだけでは性質の否定を証明したことにはなりません。インポート、仮定、インスタンスの登録が足りない可能性もあるからです。

ここでは標準基底列を使って単位閉球の非コンパクト性を証明し、その結果から `¬ ProperSpace ell2` を導きます。

## 10.3 有限次元の直感、崩壊の瞬間 ──── 単位閉球は非コンパクト

### 標準基底ベクトルの距離を計算する

$\ell^2$ の標準基底ベクトルを定義します。

$$
e_n = (\underbrace{0, \ldots, 0}_{n \text{ 個}}, 1, 0, 0, \ldots) \quad (n = 0, 1, 2, \ldots)
$$

各 $e_n$ は $\|e_n\|_{\ell^2} = 1$ であり、したがって $e_n \in \bar{B}(0, 1)$（単位閉球）に属します。

では、$m \neq n$ のとき $e_m$ と $e_n$ の距離はいくつでしょうか。

$$
\|e_m - e_n\|_{\ell^2} = \sqrt{|1|^2 + |-1|^2} = \sqrt{2}
$$

$m$ と $n$ がどれだけ離れていても、距離は常に $\sqrt{2}$ です。

### Lean での確認

まず標準基底ベクトルを定義します。

```lean:完成例・確認コマンド
-- 以降は10.0節の import・open scoped ENNReal・ell2 の定義に続けて置く
noncomputable def e (n : ℕ) : ell2 := lp.single 2 n 1

theorem norm_e (n : ℕ) : ‖e n‖ = 1 := by
  simp [e, lp.norm_single (by norm_num : (0 : ℝ≥0∞) < 2)]
```

非コンパクト性の証明には、異なる項の距離が1以上であることを使います。$m$ 番目の成分を見ると $(e_m-e_n)_m=1$ なので、成分の絶対値は全体のノルム以下という `lp.norm_apply_le_norm` から導けます。上の $\sqrt{2}$ という等式は数学的な計算として説明し、Leanでは証明に必要な下界を次のように確認します。

```lean:完成例・確認コマンド
theorem basis_separated (m n : ℕ) (hmn : m ≠ n) :
    1 ≤ dist (e m) (e n) := by
  have hcoord := lp.norm_apply_le_norm
    (by norm_num : (2 : ℝ≥0∞) ≠ 0) (e m - e n) m
  change ‖e m m - e n m‖ ≤ ‖e m - e n‖ at hcoord
  simpa [e, dist_eq_norm, lp.single_apply, hmn] using hcoord
```

:::message
**🔍 1つの成分から全体のノルムを評価する**

`hcoord` は $|(e_m-e_n)_m| \le \|e_m-e_n\|$ を表します。`change` で差を成分ごとの形に書き直し、`lp.single_apply` と $m\ne n$ を使うと左辺が $|1-0|=1$ になります。最後に `dist_eq_norm` で距離とノルムを対応させます。
:::

### 収束部分列が取れない ──── Heine-Borel 崩壊の核心

単位閉球 $\bar{B}(0,1) \subset \ell^2$ は有界かつ閉集合です。しかし**コンパクトではありません**。

標準基底列 $(e_n)_{n \geq 0}$ はすべて $\bar{B}(0,1)$ に属しますが、どの部分列 $(e_{n_k})$ も収束しません。なぜなら任意の2項の距離が $\sqrt{2}$ だからです。

$$
\forall k \neq l,\; \|e_{n_k} - e_{n_l}\|_{\ell^2} = \sqrt{2} > 0
$$

$\varepsilon = \frac{\sqrt{2}}{2}$ に対して「$N$ 番目以降の任意の2項の距離が $\varepsilon$ 未満」という Cauchy 条件を満たす $N$ は取れません。したがって $(e_{n_k})$ は Cauchy 列ではなく収束しません。

```lean:完成例・確認コマンド
theorem unitClosedBall_not_compact :
    ¬ IsCompact (Metric.closedBall (0 : ell2) 1) := by
  intro h
  have he (n : ℕ) : e n ∈ Metric.closedBall (0 : ell2) 1 := by
    simp [Metric.mem_closedBall, dist_zero_right, norm_e]
  obtain ⟨x, _, φ, hφ, hlim⟩ := h.isSeqCompact he
  obtain ⟨N, hN⟩ := Metric.cauchySeq_iff.mp hlim.cauchySeq 1 (by norm_num)
  have hlt := hN N (le_refl N) (N + 1) (by omega)
  have hge := basis_separated (φ N) (φ (N + 1))
    (ne_of_lt (hφ (Nat.lt_succ_self N)))
  exact (not_lt_of_ge hge) hlt

theorem ell2_not_proper : ¬ ProperSpace ell2 := by
  intro h
  exact unitClosedBall_not_compact (isCompact_closedBall (0 : ell2) 1)
```

Leanの証明では、コンパクト性から厳密単調な添字写像 `φ` と収束部分列を取り出します。収束列はCauchy列なので、ある `N` 以降の距離は1未満です。しかし `φ N ≠ φ (N+1)` であり、`basis_separated` による距離1以上という下界と矛盾します。

`ell2_not_proper` では、`ProperSpace ell2` を仮定すると単位閉球がコンパクトになることを使い、直前の定理と矛盾させています。これで性質の否定が証明できました。

:::message alert
**💥 ℓ²の単位閉球は非コンパクト**

$\ell^2$ の単位閉球は：
- ✅ 有界（すべての点が原点から距離 1 以内）
- ✅ 閉集合（極限点を含む）
- ❌ **コンパクトではない**（収束部分列のない有界点列 $(e_n)$ が存在する）

[第7章](ch07)で学んだ $\mathbb{R}^n$ の「有界かつ閉 ↔ コンパクト」は、$\ell^2$ には拡張できません。実ノルム空間では、この性質と有限次元性が対応します。

ここで根拠となるのは、完成した `unitClosedBall_not_compact` と `ell2_not_proper` の証明です。探索エラーの有無を数学的な証明の代わりにはしません。
:::

| 性質 | 有限次元実ノルム空間 | $\ell^2(\mathbb{N},\mathbb{R})$ |
|---|---|---|
| 有界閉集合 | コンパクト | コンパクトとは限りません |
| 単位閉球 | コンパクト | コンパクトではありません |
| 有界列 | 収束部分列を持ちます | 収束部分列を持たない例があります |

後者の例が標準基底$(e_n)$です。異なる2項の距離は$\sqrt{2}$なので、どの部分列もCauchy列になりません。

## 10.4 無限次元で「使えるもの」と「使えないもの」の整理

有限次元の直感が崩れた後、何が残るのかを整理します。

### 使えるもの（免許証あり）

```lean:完成例・確認コマンド
-- ℓ² でも使えること
#check (inferInstance : MetricSpace ell2)     -- 距離の計算
#check (inferInstance : CompleteSpace ell2)   -- Cauchy 列は収束する
#check (inferInstance : NormedAddCommGroup ell2) -- ノルムの代数
-- → cauchySeq_tendsto_of_complete が使える
-- → dist_triangle（三角不等式）が使える
-- → 連続写像が定義できる
```

### 単位閉球には適用できないもの

```lean:完成例・確認コマンド
-- 10.3節の証明を使う
#check ell2_not_proper

theorem ell2_not_finiteDimensional : ¬ FiniteDimensional ℝ ell2 := by
  intro h
  exact ell2_not_proper (FiniteDimensional.proper ℝ ell2)

-- コンパクト集合に関する定理は ell2 内でも使える。
-- ただし単位閉球は、そのコンパクト性の仮定を満たさない。
```

整理すると：

| 性質 | $\mathbb{R}^n$（有限次元） | $\ell^2$（無限次元） |
|------|:---:|:---:|
| `MetricSpace` | ✅ | ✅ |
| `CompleteSpace` | ✅ | ✅ |
| `ProperSpace` | ✅ | ❌ |
| `FiniteDimensional` | ✅ | ❌ |
| 単位閉球がコンパクト | ✅ | ❌ |
| Cauchy 列が収束 | ✅ | ✅ |
| 三角不等式 | ✅ | ✅ |
| 連続写像の合成 | ✅ | ✅ |

:::message
**💡 「完備性」は無限次元でも生き残る**

単位閉球がコンパクトでなくても、**完備性（`CompleteSpace`）は $\ell^2$ でも成立します**。

これが重要な理由は、次章で扱う Banach の不動点定理が「完備距離空間」を前提としているからです。コンパクト性は不要です。非空な完備距離空間上の縮小自己写像には、一意な不動点が存在します。

[第9章](ch09)で「Cauchy 列の行き先が必ず存在する空間」として `CompleteSpace` を学びました。$\ell^2$ の単位閉球はコンパクトでなくても、$\ell^2$ 全体は完備です。この区別が、次章のラスボスを倒す鍵になります。
:::

## 10.5 `lp` の構造を少し深く ──── ノルムと内積

$\ell^2$ の特別な点は、**ノルムが内積から来ている**ことです。

$$
\langle x, y \rangle_{\ell^2} = \sum_{n=0}^{\infty} x_n y_n, \quad \|x\|_{\ell^2} = \sqrt{\langle x, x \rangle_{\ell^2}}
$$

ここでは実数列を扱っています。複素数列へ広げるとき、Mathlibの内積は第1引数に共役を取る規約なので、総和の項は $\overline{x_n}y_n$ になります。

Lean でもこの構造が確認できます。

```lean:完成例・確認コマンド
-- ℓ² は内積空間（Hilbert 空間）
#check (inferInstance : Inner ℝ (lp (fun _ : ℕ => ℝ) (2 : ℝ≥0∞)))
#check (inferInstance : InnerProductSpace ℝ (lp (fun _ : ℕ => ℝ) (2 : ℝ≥0∞)))

-- Hilbert 空間 = 完備な内積空間
-- ℓ² は CompleteSpace + InnerProductSpace = Hilbert 空間
```

:::message
**💡 Banach 空間と Hilbert 空間**

| 構造 | 定義 | Lean の型クラス |
|------|------|----------------|
| ノルム空間 | ベクトル空間 + ノルム | `NormedAddCommGroup` + `NormedSpace` |
| Banach 空間 | ノルム空間 + 完備 | + `CompleteSpace` |
| 内積空間 | 内積とノルムが対応する空間 | `InnerProductSpace` |
| Hilbert 空間 | 内積空間 + 完備 | + `CompleteSpace` |

$\ell^2$ は Hilbert 空間です。[第11章](ch11)のBanachの不動点定理は、さらに一般の非空な完備距離空間上の縮小自己写像に使えます。$\ell^2$ はその特殊ケースなので、もちろん不動点定理が使えます。
:::

## 10.6 本章のまとめ ──── 崩壊と希望

本章で確認した事実を整理します。

**ℓ²にはそのまま拡張できない性質：**

$$
\text{（実ノルム空間では有限次元に対応）}\quad \text{有界かつ閉} \iff \text{コンパクト}
$$

**ℓ²でも成立する性質：**

$$
\text{（無限次元でも成立）}\quad \ell^2 \text{ は完備距離空間（Banach 空間、Hilbert 空間）}
$$

```lean:完成例・確認コマンド
-- 10.0節から10.3節までの完成例の後に置く
section Chapter10Summary

example : ¬ ProperSpace ell2 := ell2_not_proper
example : CompleteSpace ell2 := inferInstance

example (a : ℕ → ell2) (ha : CauchySeq a) :
    ∃ L : ell2, Filter.Tendsto a Filter.atTop (nhds L) :=
  cauchySeq_tendsto_of_complete ha

end Chapter10Summary
```

:::message alert
 **🏆 [第11章](ch11)への架け橋：「完備性があれば戦える」**

有限次元の安全地帯を離れ、$\ell^2$ という無限次元の荒野に踏み込んだ結果：

- 単位閉球にはHeine–Borelの結論を適用できない
- しかし `CompleteSpace` は健在だった

これは偶然ではありません。関数解析学の多くの主定理——Banach の不動点定理、閉グラフ定理、一様有界性定理——は、コンパクト性ではなく**完備性**を仮定して成立します。

**次章のラスボス「Banach の不動点定理」が要求する条件は：**
1. $X$ が**非空な完備距離空間**（`MetricSpace X`・`CompleteSpace X`・`Nonempty X`）
2. $f : X \to X$ が**縮小写像**（ある $c < 1$ に対して $d(f(x), f(y)) \leq c \cdot d(x, y)$）

$\ell^2$ はこの条件①を満たしています。有限次元でも無限次元でも、非空な完備距離空間上の縮小自己写像であれば不動点定理が使えます。

「単位閉球のコンパクト性は使えなくても、空間の完備性を使える」——これが[第11章](ch11)の出発点です。
:::

**📝 理解度チェック**

 **問1（概念）**

次の空間が `ProperSpace` の性質を満たすかどうかを、数学的な理由とともに説明してください。肯定例は `inferInstance` でも確認し、否定例は探索失敗だけで判断しないでください。

- (a) $\mathbb{R}^{100}$（100次元実ユークリッド空間）
- (b) $\ell^2$（本章で扱った無限次元空間）
- (c) $C([0,1])$（閉区間上の連続関数空間、sup ノルム）

:::details ヒントを見る

`ProperSpace` は閉球のコンパクト性を表します。実ノルム空間では「有限次元 ↔ 単位閉球がコンパクト」という対応が使えます。
:::

:::details 解答を見る

**(a) $\mathbb{R}^{100}$（100次元）：ProperSpace を持つ ✓**

```lean:完成例・確認コマンド
#check (inferInstance : ProperSpace (EuclideanSpace ℝ (Fin 100)))
```

有限次元の実ノルム空間は `ProperSpace` です。`FiniteDimensional.proper` は、より一般に局所コンパクトな非自明ノルム体上でこの結論を与えます。

**(b) $\ell^2$：ProperSpace を持たない ✗**

```lean:完成例・確認コマンド
-- 10.3節の完成証明を使う
example : ¬ ProperSpace ell2 := ell2_not_proper
```

本章で見たように、単位閉球には収束部分列を持たない標準基底列が含まれています。したがって単位閉球はコンパクトではありません。

**(c) $C([0,1])$（sup ノルム）：ProperSpace を持たない ✗**

```lean:完成例・確認コマンド
-- 無限次元の実ノルム空間について使う一般形
theorem notProperOfInfiniteDimensional {E : Type*}
    [NormedAddCommGroup E] [NormedSpace ℝ E]
    (h : ¬ FiniteDimensional ℝ E) : ¬ ProperSpace E := by
  intro hp
  exact h (FiniteDimensional.of_isCompact_closedBall ℝ
    (by norm_num : 0 < (1 : ℝ)) (isCompact_closedBall (0 : E) 1))
```

実数値の $C([0,1])$ は、単項式 $1,x,x^2,\ldots$ が線形独立なので無限次元です。したがって上の一般定理から `ProperSpace` の性質は成り立ちません。この無限次元性の説明はここでは紙上の議論です。Ascoli–Arzelàの定理では、一様有界性と同程度連続性から相対コンパクト性を得ます。集合自体のコンパクト性を結論するには閉性も必要です。
:::

:::details 別解を見る

Heine-Borel と有限次元性の同値：

```lean:完成例・確認コマンド
#check FiniteDimensional.proper
#check FiniteDimensional.of_isCompact_closedBall
```

実ノルム空間では、有限次元から単位閉球のコンパクト性へは `FiniteDimensional.proper` を経由し、逆向きには `FiniteDimensional.of_isCompact_closedBall` を使います。一般の係数体へ広げる場合は、それぞれの定理の仮定を確認してください。
:::

 **問2（Lean）**

次の未完成の演習を `sorry` なしで完成させてください。完成例とは別ファイルで実行します。

```lean:未完成の骨格・練習問題
import Mathlib

-- 演習の穴。完成例とは別ファイルで実行する。
theorem reciprocal_mem_two_exercise :
    Memℓp (fun n : ℕ => (1 : ℝ) / (n + 1)) 2 := by
  sorry
```

:::details ヒントを見る

解答と同じ方針を使う場合は、10.1節の `mem_two_iff` も演習用のファイルにコピーしてください。これで二乗ノルムの総和可能性に帰着できます。`Real.summable_one_div_nat_pow` は、自然数の指数 `p` について逆数冪の級数が総和可能であることと `1 < p` の同値を与えます。`summable_nat_add_iff 1` で添字を1つずらしてください。
:::

:::details 解答を見る

```lean:完成例・確認コマンド
-- 10.1節の mem_two_iff を使う
theorem reciprocal_mem_two :
    Memℓp (fun n : ℕ => (1 : ℝ) / (n + 1)) 2 := by
  rw [mem_two_iff]
  have hbase : Summable (fun n : ℕ => (1 : ℝ) / (n : ℝ) ^ 2) :=
    Real.summable_one_div_nat_pow.mpr (by norm_num)
  have hshift : Summable (fun n : ℕ => (1 : ℝ) / (n + 1) ^ 2) := by
    simpa only [Nat.cast_add, Nat.cast_one] using (summable_nat_add_iff 1).mpr hbase
  simpa only [Real.norm_eq_abs, sq_abs, div_pow, one_pow] using hshift
```

`hbase` は指数2の逆数冪級数の総和可能性、`hshift` は添字を1つずらした級数の総和可能性です。Leanの実数では `1 / 0 = 0` と定義されているため、`hbase` の0番目の項も定義されています。有限個の項を取り除いても総和可能性は変わらず、`summable_nat_add_iff` がその事実を使います。

最後は `‖a‖² = a²` と商の2乗を整理します。この演習で必要なのは総和可能性であり、和が $\pi^2/6$ に等しいというBasel問題の値までは使いません。
:::

:::details 別解を見る

上の `mem_two_iff` を使い、添字の移し方だけを変える別解です。

```lean:完成例・確認コマンド
-- 添字のシフトを、単射による部分列として扱う別解
theorem reciprocal_mem_two_alt :
    Memℓp (fun n : ℕ => (1 : ℝ) / (n + 1)) 2 := by
  rw [mem_two_iff]
  have hbase : Summable (fun n : ℕ => (1 : ℝ) / (n : ℝ) ^ 2) :=
    Real.summable_one_div_nat_pow.mpr (by norm_num)
  have hshift : Summable (fun n : ℕ => (1 : ℝ) / (n + 1) ^ 2) := by
    simpa only [Function.comp_def, Nat.cast_succ] using
      hbase.comp_injective Nat.succ_injective
  simpa only [Real.norm_eq_abs, sq_abs, div_pow, one_pow] using hshift
```

`Nat.succ` は単射なので、`Summable.comp_injective` により元の総和可能な級数から部分列を取れます。`Function.comp_def` と `Nat.cast_succ` で関数合成と型変換を整理すると、同じ `hshift` が得られます。
:::

 **問3（数学的考察）**

$\ell^2$ の単位閉球 $B = \{ x \in \ell^2 \mid \|x\| \leq 1 \}$ について：

- (a) $B$ は有界か？（定義に従って答えよ）
- (b) $B$ は閉集合か？（ノルムの連続性を使って答えよ）
- (c) $B$ はコンパクトか？（本章の議論を参照して答えよ）
- (d) $\mathbb{R}^n$ の単位閉球と(a)-(c)の結果を比較し、Heine-Borel 定理の「射程」を論じよ。

:::details ヒントを見る

有界性はノルムの上界から、閉集合性はノルムの連続性から、コンパクト性は標準基底列の例（各項が $\sqrt{2}$ 離れている）を使います。
:::

:::details 解答を見る

**(a) $B$ は有界か：有界 ✓**

定義から $B = \{x \in \ell^2 \mid \|x\| \leq 1\}$ は直径 $\leq 2$ の集合（任意の $x, y \in B$ に対して $\|x - y\| \leq \|x\| + \|y\| \leq 2$）。

**(b) $B$ は閉集合か：閉集合 ✓**

ノルム関数 $\| \cdot \| : \ell^2 \to \mathbb{R}$ は連続（三角不等式から Lipschitz 連続）。$B = \|\cdot\|^{-1}([0,1])$ は連続関数の閉集合 $[0,1]$ の逆像なので閉集合。

**(c) $B$ はコンパクトか：コンパクトでない ✗**

標準基底列 $e_n \in B$（$\|e_n\| = 1$ なので $B$ に属する）は $\|e_m - e_n\| = \sqrt{2}$（$m \neq n$）なので収束部分列を持たない。

**(d) $\mathbb{R}^n$ との比較：**

$\mathbb{R}^n$ の単位閉球は (a)(b) を満たしかつコンパクト（Heine-Borel）。$\ell^2$ の単位閉球は (a)(b) を満たすがコンパクトでない。実ノルム空間について「閉かつ有界な集合はすべてコンパクト」という性質は有限次元性と同値です。無限次元でも個々のコンパクト集合は存在しますが、閉性と有界性だけでは十分ではありません。
:::

:::details 別解を見る

(b) の別証明：

$B$ の補集合 $B^c = \{x \mid \|x\| > 1\}$ が開集合であることを示す。$x \in B^c$ なら $r = \|x\| - 1 > 0$ とおき、$\|y - x\| < r/2$ なら $\|y\| > \|x\| - r/2 > 1$ となるので $y \in B^c$。よって $B^c$ は開集合、$B$ は閉集合。
:::

 **問4（発展：弱収束）**

標準基底列 $(e_n)$ はノルム位相では収束しないことを本章で見ました。しかし実は $(e_n)$ は **弱位相（weak topology）** では $0$ に弱収束します：

$$
\forall \varphi \in (\ell^2)^*,\; \langle \varphi, e_n \rangle \to 0 \quad (n \to \infty)
$$

Riesz の表現定理（$\ell^2$ の双対空間 $(\ell^2)^* \cong \ell^2$）を使って、この事実を直感的に確認してください。この問の解答は紙上の証明です。末尾の `#check` はRiesz表現定理のAPIを確認するもので、弱収束そのものを形式化してはいません。

:::details ヒントを見る

Riesz の表現定理から $\ell^2$ の任意の連続線形汎関数 $\varphi$ は「ある $y \in \ell^2$ との内積」として表せます：$\varphi(x) = \langle y, x \rangle = \sum_n y_n x_n$。
:::

:::details 解答を見る

**直感的確認：** Riesz 表現定理から、$\varphi \in (\ell^2)^*$ は $\varphi(x) = \langle y, x \rangle$ （ある固定 $y \in \ell^2$）と書ける。

$$
\varphi(e_n) = \langle y, e_n \rangle = \sum_{k=0}^{\infty} y_k \cdot (e_n)_k = y_n
$$

$y \in \ell^2$ なら $\sum_n |y_n|^2 < \infty$ であり、総和可能性から一般項 $|y_n|^2$ は0へ収束します。その平方根 $|y_n|$ も0へ収束するので、$y_n \to 0$（$n \to \infty$）です。したがって：

$$
\varphi(e_n) = y_n \to 0 \quad (n \to \infty)
$$

これが「$(e_n)$ は弱収束で $0$ に収束する」の本質です。

```lean:完成例・確認コマンド
-- Riesz表現定理による同型を確認する。弱収束そのものの証明ではない。
#check InnerProductSpace.toDual ℝ ell2
#check @lp.inner_single_right
```
:::

:::details 別解を見る

ノルム収束と弱収束の違いの視覚化：

- **ノルム収束**（強収束）: $\|e_n - 0\| = 1 \not\to 0$ — 収束しない
- **弱収束**: $\varphi(e_n) = y_n \to 0$ — すべての汎関数に対して収束

弱収束はノルム収束より「緩い」収束概念です。無限次元では「弱収束するがノルム収束しない」列が豊富に存在します。これが第3巻（測度論・確率論）のテーマへの伏線になります。
:::

**📝 第10章 つまずきポイントQ&A**

**Q1. `ℓ²` 空間とは何ですか？直感的に教えてください**
→ 「二乗和が有限な無限数列の全体」です。`(a₀, a₁, a₂, …)` で `∑ aₙ² < ∞` を満たすものです。各数列をベクトルとみなすと、無限次元ユークリッド空間になります。Lean では `lp (fun _ : ℕ => ℝ) 2` と書きます。

**Q2. `Memℓp f 2` の意味を教えてください**
→ 「数列 `f : ℕ → ℝ` が `ℓ²` に属する」という命題です。`mem_two_iff` により `Summable (fun n => ‖f n‖ ^ (2 : ℕ))` と同値です。実数値の `∑'` の値だけでは総和可能性を表せません。これが型クラスではなく命題（`Prop`）である点に注意してください。

**Q3. `lp` と `EuclideanSpace` は何が違いますか？**
→ `EuclideanSpace ℝ (Fin n)` は n 次元有限ユークリッド空間です。`lp (fun _ : ℕ => ℝ) 2` は自然数で添字付けた数列の空間で、実ベクトル空間として無限次元です。標準基底は可算な正規直交基底ですが、一般の元を表すには無限級数が必要です。有限の線形結合だけで全ての元を表す代数的な基底（Hamel基底）とは区別します。どちらの空間でも、Cauchy列の収束には完備性を使います。Mathlibには両方の完備性が証明・登録されています。有限次元なら係数体によらず完備というわけではなく、例えば $\mathbb{Q}$ は自身の上で1次元ですが完備ではありません。

**Q4. `inferInstance` で `CompleteSpace ell2` が通るのはなぜですか？**
→ Mathlib が `lp` 空間の完備性インスタンスをあらかじめ証明・登録しているからです。`#check (inferInstance : CompleteSpace (lp (fun _ : ℕ => ℝ) 2))` を実行すると、Lean がそのインスタンスを見つけてきます。証明の詳細は `Mathlib.Analysis.Normed.Lp.lpSpace` にあります。

**Q5. 内積空間（Hilbert 空間）と `ℓ²` はどう関係しますか？**
→ `ℓ²` は `⟨f, g⟩ = ∑ fₙ gₙ` で内積を定義でき、Hilbert 空間になります。Lean では `InnerProductSpace ℝ (lp (fun _ : ℕ => ℝ) 2)` のインスタンスも Mathlib に存在します。完備な内積空間が Hilbert 空間の定義です。
