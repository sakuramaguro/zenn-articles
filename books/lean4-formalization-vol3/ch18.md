# 第18章：$L^p$空間と確率空間

## 18.0 本章のゴール

第3巻の最終章では、積分を使って関数空間と確率を記述します。$L^p$に属する条件、確率測度、期待値をLeanで確認し、マルチンゲールの基本的な性質を取り出します。Mathlibの定義・インスタンス・定理を使い、数学の仮定と対応させることが目的です。章末の総合演習では、[0,1]の一様分布で期待値と二乗の期待値を計算し、同じ関数から $L^2$ の元を作ってノルムの二乗まで求めます。

通常の例は、記載したimportから始まる別々のLeanファイルとして実行できます。総合演習18.4・18.5は例外で、問題18.3の内積・ノルムの公式と共通準備を引き継ぎ、指定された順に同じファイルへ置きます。本書の固定環境での型は `#check`・`#print` の実出力で確認してください。コード中のコメントはその要約です。

```lean:完成例・確認コマンド
import Mathlib
open MeasureTheory
open scoped ENNReal

-- 型の全体は実際の #check 出力で確認する。コメントは要約。

#check @expectation

theorem expectation_const {Ω : Type*} [MeasurableSpace Ω]
    (P : Measure Ω) [IsProbabilityMeasure P] (c : ℝ) :
```

## 18.1 $L^p$空間の動機

実数値関数について、まず $1 \leq p < \infty$ とします。$p$乗可積分な関数をa.e.等しいものどうしで同一視した空間が $L^p$ です。

$$
L^p(X,\mu)
:= \left\{ f:X\to\mathbb{R}\;\middle|\;
f\text{ はa.e.可測},\ \int |f|^p\,d\mu<\infty
\right\}/\sim
$$

ここで $f\sim g$ は $f=g$ $\mu$-a.e.を意味します。ノルムは

$$
\|f\|_p := \left(\int |f|^p\,d\mu\right)^{1/p}
$$

です。$p=\infty$ の場合はこの式を使わず、$\|f\|_\infty$ を $|f|$ の**本質的上限**とし、それが有限な関数を扱います。実数値の $L^p$ は $1\leq p\leq\infty$ でBanach空間です。一般の値域 `E` について同様の完備性を使う際には、`E` 自体の完備性も仮定します。

$0<p<1$ でもべき積分から量を定義できますが、一般にはノルムの三角不等式を満たしません。Mathlibが `p : ℝ≥0∞` 全体で定義を用意していることと、通常のノルム空間の性質が使える範囲を区別します。

商をとる前は、異なる関数でもa.e.等しければ距離が0になり得ます。商をとった `Lp ℝ 2 μ` では、距離0なら同じ元です。これは[第2巻・第10章](https://zenn.dev/matsuteru/books/lean4-formalization-vol2/viewer/ch10)で区別した擬距離と距離の違いに対応します。

![有限測度上のL∞、L2、L1の包含関係を示す入れ子図](/images/vol3/fig-14.png)
*図18-1：包含は真の包含とは限りません。a.e.同値類を自然に対応させた包含です。無限測度上では一般に成り立ちません。*

有限測度の場合の包含は $L^\infty\subseteq L^2\subseteq L^1$ です。常に真の包含になるとは限らず、測度が無限の場合には、この包含をそのまま使うこともできません。

## 18.2 `Lp E p μ` と `MemLp f p μ`

### $L^p$空間の構造を確認する

```lean:完成例・確認コマンド
import Mathlib
open MeasureTheory
open scoped ENNReal

#check @MeasureTheory.Lp

-- 定義域と測度を明示する。
#check (inferInstance : NormedAddCommGroup (Lp ℝ 2 (volume : Measure ℝ)))
#check (inferInstance : NormedSpace ℝ (Lp ℝ 2 (volume : Measure ℝ)))
#check (inferInstance : InnerProductSpace ℝ (Lp ℝ 2 (volume : Measure ℝ)))
#check (inferInstance : CompleteSpace (Lp ℝ 2 (volume : Measure ℝ)))
```

`volume : Measure ℝ` と明示したので、この例の定義域は実数直線、測度はLebesgue測度です。`NormedAddCommGroup` と `NormedSpace` がノルム空間としての構造を、`InnerProductSpace` が内積を、`CompleteSpace` が完備性を表します。内積の存在だけで完備性まで確認したことにはなりません。

実数値の $L^2$ の内積は

$$
\langle f,g\rangle=\int f(x)g(x)\,d\mu(x)
$$

です。ノルムと内積に加えて完備性があるので、Hilbert空間と呼べます。

### 関数が$L^p$に属する条件

固定版での名前は `MemLp` です。引数の順番は `f p μ` で、定義は `AEStronglyMeasurable f μ ∧ eLpNorm f p μ < ∞` です。

```lean:完成例・確認コマンド
import Mathlib
open MeasureTheory
open scoped ENNReal

#check @MeasureTheory.MemLp
#print MeasureTheory.MemLp
#check @MeasureTheory.memLp_const
#check @MeasureTheory.memLp_one_iff_integrable
#check @MeasureTheory.eLpNorm_eq_lintegral_rpow_enorm_toReal

theorem memLp_definition (f : ℝ → ℝ) (p : ℝ≥0∞) (μ : Measure ℝ) :
    MemLp f p μ ↔ AEStronglyMeasurable f μ ∧ eLpNorm f p μ < ∞ :=
  Iff.rfl

theorem constant_memLp (c : ℝ) (p : ℝ≥0∞) (μ : Measure ℝ)
    [IsFiniteMeasure μ] : MemLp (fun _ => c) p μ :=
  memLp_const c

theorem memLp_one_on (f : ℝ → ℝ) (s : Set ℝ) :
    MemLp f 1 (volume.restrict s) ↔ IntegrableOn f s volume :=
  memLp_one_iff_integrable

-- 0・有限の正の指数・∞を分ける。
theorem eLpNorm_at_zero (f : ℝ → ℝ) (μ : Measure ℝ) :
    eLpNorm f 0 μ = 0 := by
  simp

theorem eLpNorm_at_finite (f : ℝ → ℝ) (p : ℝ≥0∞) (μ : Measure ℝ)
    (hp0 : p ≠ 0) (hptop : p ≠ ∞) :
    eLpNorm f p μ = (∫⁻ x, ‖f x‖ₑ ^ p.toReal ∂μ) ^ (1 / p.toReal) :=
  eLpNorm_eq_lintegral_rpow_enorm_toReal hp0 hptop

theorem eLpNorm_at_top (f : ℝ → ℝ) (μ : Measure ℝ) :
    eLpNorm f ∞ μ = eLpNormEssSup f μ :=
  eLpNorm_exponent_top
```

`MemLp` は、商をとる前の関数 `f` に対する条件です。`Lp E p μ` はa.e.等しい関数を同一視した空間です。`Lp` の元 `f` を `f x` と書くときには、Mathlibが選ぶ代表関数への変換を使っています。点での値そのものは同値類の不変量ではなく、積分などa.e.等式で変わらない量を扱います。

具体的な関数を空間の元にするときは、次の順序で進めます。

| 段階 | Leanで扱うもの |
|---|---|
| 関数を定める | `f : α → ℝ` |
| 所属条件を示す | `hf : MemLp f 2 μ` |
| L²の元を作る | `hf.toLp f : Lp ℝ 2 μ` |
| 元の関数との対応を得る | `hf.coeFn_toLp : hf.toLp f =ᵐ[μ] f` |
| ノルムを計算する | 内積・積分の公式とa.e.等式を使う |

総合演習18.5では、この順序を一つの具体例で実行します。

`eLpNorm` は `ℝ≥0∞` に値をとり、次のように場合分けされます。

| 指数 | `eLpNorm f p μ` |
|---|---|
| `p = 0` | 規約で0 |
| `0 < p < ∞` | ノルムの `p.toReal` 乗を非負積分し、`1 / p.toReal` 乗した量 |
| `p = ∞` | ノルムの本質的上限 `eLpNormEssSup f μ` |

`‖f x‖ₑ` は拡張非負実数値のノルムです。上の `eLpNorm_at_finite` は指数が0でも∞でもないことを仮定して公式を使っています。`p = 0` では `MemLp` はAE強可測性だけを要求するので、通常の $L^1$・$L^2$ の可積分性と混同しないでください。

`memLp_const` は有限測度上の定数関数について、∞を含む任意の指数で `MemLp` を与えます。`memLp_one_iff_integrable` は `MemLp f 1 μ ↔ Integrable f μ` を表します。`IntegrableOn f s volume` と対応させる場合は、上の `memLp_one_on` のように測度を `volume.restrict s` にします。[第16章](ch16)の可積分性は、この $p=1$ の場合です。

## 18.3 確率空間

総合演習では、[第13章の問題13.3](ch13)で調べた `volume.restrict (Set.Icc 0 1)` を使います。共通準備には同じ確率測度を `unitIntervalMeasure` として再掲するので、第13章のファイルをimportする必要はありません。

集合 $\Omega$（標本空間）、σ代数 $\mathcal{F}$（事象の族）、確率測度 $P$ の三つ組 $(\Omega,\mathcal{F},P)$ を確率空間と呼びます。確率測度は $P(\Omega)=1$ を満たす測度です。

```lean:完成例・確認コマンド
import Mathlib
open MeasureTheory

#print IsProbabilityMeasure

theorem probability_univ {Ω : Type*} [MeasurableSpace Ω]
    (P : Measure Ω) [IsProbabilityMeasure P] : P Set.univ = 1 :=
  IsProbabilityMeasure.measure_univ

-- Leanの測度は任意の部分集合で評価できる。この不等式には可測性は不要。
theorem probability_le_one {Ω : Type*} [MeasurableSpace Ω]
    (P : Measure Ω) [IsProbabilityMeasure P] (A : Set Ω) : P A ≤ 1 :=
  prob_le_one

theorem probability_of_univ_eq_one {Ω : Type*} [MeasurableSpace Ω]
    (P : Measure Ω) (hP : P Set.univ = 1) : IsProbabilityMeasure P :=
  ⟨hP⟩
```

`IsProbabilityMeasure P` は `P Set.univ = 1` を唯一のフィールドとして持つPropの型クラスです。`P` が測度であることは既に `Measure Ω` に含まれており、可算加法性をここで再び仮定する必要はありません。`probability_of_univ_eq_one` は、その1つの証明からインスタンスを作る方法です。

| 数学の表現 | Leanの表現 |
|---|---|
| 標本空間 $\Omega$ | `Ω : Type*` |
| 事象のσ代数 $\mathcal{F}$ | `[MeasurableSpace Ω]` |
| 確率測度 $P$ | `P : Measure Ω` と `[IsProbabilityMeasure P]` |
| $P(\Omega)=1$ | `IsProbabilityMeasure.measure_univ` |
| $P(A)\leq1$ | `prob_le_one` |

測度の値は `ℝ≥0∞` なので非負です。`prob_le_one` と合わせて値が $[0,1]$ に入ることがわかります。Leanの測度は可測とは限らない集合にも値を与えるため、この不等式自体は任意の `A : Set Ω` に適用できます。一方、確率空間の事象として扱う集合は可測集合です。

| 数学のデータ・条件 | Leanでの表現 |
|---|---|
| 標本空間Ω | `Ω : Type*` |
| 事象のσ-代数 | `[MeasurableSpace Ω]` |
| 測度P | `P : Measure Ω` |
| P(Ω)=1 | `[IsProbabilityMeasure P]` |

`Ω : Type*`だけでは確率空間になりません。測度のデータと、その全体の測度が1であることの証明を区別します。

## 18.4 確率変数

総合演習の確率変数は $X(x)=x$ です。関数の定義域は実数全体で、[0,1]の外側の値が積分に寄与しないことは制限測度が表します。

実数値確率変数は、$(\Omega,\mathcal{F},P)$ から実数のBorel可測空間への可測関数 $X:\Omega\to\mathbb{R}$ です。

```lean:完成例・確認コマンド
import Mathlib
open MeasureTheory

-- 可測性の証明そのものには、確率測度は必要ない。
theorem random_variable_preimage {Ω : Type*} [MeasurableSpace Ω]
    (X : Ω → ℝ) (hX : Measurable X) (B : Set ℝ) (hB : MeasurableSet B) :
    MeasurableSet (X ⁻¹' B) :=
  hX hB
```

$X$ がBorel集合 $B$ に入る事象は逆像 $X^{-1}(B)$ で、その確率は $P(X^{-1}(B))$ と書けます。`hX hB` は、この逆像が事象のσ代数に属することを示します。可測性は確率を測度論の規則に従って扱うための条件であり、数値を実行可能な方法で計算できることを保証するものではありません。

![実数値確率変数と、Borel集合の逆像が事象になる関係を示す図](/images/vol3/fig-16.png)
*図18-2：Borel集合Bの逆像が事象になります。確率はP(X⁻¹(B))で表します。逆像は逆関数を意味しません。*

## 18.5 期待値

可積分な実数値確率変数 $X$ の期待値は

$$
\mathbb{E}[X] := \int_\Omega X(\omega)\,dP(\omega)
$$

です。[第16章](ch16)のBochner積分を、そのまま確率測度に対して使います。

```lean:完成例・確認コマンド
import Mathlib
open MeasureTheory

noncomputable def myExpectation {Ω : Type*} [MeasurableSpace Ω]
    (P : Measure Ω) (X : Ω → ℝ) : ℝ :=
  ∫ ω, X ω ∂P

-- 加法性を使う段階では両方の可積分性が必要。
theorem expectation_add {Ω : Type*} [MeasurableSpace Ω] (P : Measure Ω)
    (X Y : Ω → ℝ) (hX : Integrable X P) (hY : Integrable Y P) :
    myExpectation P (fun ω => X ω + Y ω) =
      myExpectation P X + myExpectation P Y :=
  integral_add hX hY
```

`noncomputable` は未証明であるという意味ではありません。積分の定義に実行用の計算手順を要求しない宣言です。`myExpectation` の定義自体に `Integrable` は不要ですが、加法性を使う `expectation_add` では両方の可積分性の証明を渡します。

非可積分な関数にもLeanの `integral` は規約で0を与えます。その0を、通常の意味で有限な期待値が存在して0になった結果と読んではいけません。確率変数の可測性だけでは可積分性は保証されません。

### 定数の期待値 $\mathbb{E}[c]=c$

確率測度は有限なので、定数は可積分です。定数積分の公式と $P(\Omega)=1$ から証明します。

```lean:完成例・確認コマンド
import Mathlib
open MeasureTheory

theorem integral_const_probability {Ω : Type*} [MeasurableSpace Ω]
    (P : Measure Ω) [IsProbabilityMeasure P] (c : ℝ) :
    (∫ _ω : Ω, c ∂P) = c := by
  rw [integral_const]
  simp
```

以下のInfoViewはゴールだけの要約です。

**`rw [integral_const]` の前：**

```text
⊢ ∫ (_ω : Ω), c ∂P = c
```

**`rw [integral_const]` の後：**

```text
⊢ P.real Set.univ • c = c
```

`P.real Set.univ` は `(P Set.univ).toReal` です。`simp` は確率測度の `P Set.univ = 1` と、`ENNReal` から実数への変換、`1 • c = c` を使います。

**`simp` の後：**

```text
No goals
```

型クラスそのものが簡約規則なのではなく、そのフィールドに対応する補題などが簡約に利用されます。

### 総合演習で計算する期待値

$P=\lambda\vert_{[0,1]}$ と $X(x)=x$ なら、紙上の計算は

$$
\mathbb{E}[X]=\int_0^1 x\,dx=\frac12,\qquad
\mathbb{E}[X^2]=\int_0^1 x^2\,dx=\frac13
$$

となります。Leanでは、まず可測性とこの測度に関する可積分性を確認し、その後で既存の積分公式に渡せる形へ書き換えます。有限測度であることだけでは任意の関数の可積分性は保証されません。ここでは、閉区間上で連続であることも使います。問題18.4でこれらの手順を実行し、18.5では二乗の期待値をL²ノルムの計算に使います。

## 18.6 条件付き期待値とマルチンゲール

`Filtration ι m₀` は、`[Preorder ι]` で順序付けられた添字ごとに、`m₀` 以下のσ代数を割り当てる単調な族です。`ℱ s ≤ ℱ t` は、時刻が進むと利用できる情報が増えることに対応します。

固定版での条件付き期待値の名前は `condExp` です。`condExp m P X` を通常の条件付き期待値として扱うには、実数値の場合、次の条件を確認します。

- `hm : m ≤ m₀`：条件付けるσ代数が元のσ代数以下である。
- `SigmaFinite (P.trim hm)`：`m` へ制限した測度がσ有限である。
- `Integrable X P`：もとの確率変数が可積分である。

`P.trim hm` はσ代数を制限した測度で、部分集合に制限する `P.restrict s` とは異なります。元の `P` のσ有限性だけでは、より粗いσ代数でのσ有限性は保証されません。確率測度では全体の測度が1なので、`P.trim hm` も有限であり、必要なσ有限性を得られます。

`condExp` の式自体は上の証明を引数として要求しません。固定版の定義は、いずれかの条件が成立しないときに0を返します。一般の値域には完備な実ノルム空間の構造を要求します。本章では実数値を扱います。

```lean:完成例・確認コマンド
import Mathlib
open MeasureTheory

#check @MeasureTheory.Filtration
#check @MeasureTheory.Martingale
#check @MeasureTheory.condExp
#check @MeasureTheory.Martingale.condExp_ae_eq

-- 確率測度は有限なので、部分σ代数上の定数の条件付き期待値も元の定数。
theorem condExp_const_probability {Ω : Type*} [m₀ : MeasurableSpace Ω]
    (P : Measure Ω) [IsProbabilityMeasure P]
    (m : MeasurableSpace Ω) (hm : m ≤ m₀) (c : ℝ) :
    condExp m P (fun _ => c) = fun _ => c :=
  condExp_const hm c

-- 既にマルチンゲールであると仮定した過程の性質を取り出す。
-- この結論には IsProbabilityMeasure P を別途仮定する必要はない。
theorem martingale_condExp_property {Ω : Type*} [m₀ : MeasurableSpace Ω]
    (P : Measure Ω) {ι : Type*} [Preorder ι]
    (f : ι → Ω → ℝ) (ℱ : Filtration ι m₀) (hf : Martingale f ℱ P)
    (s t : ι) (hst : s ≤ t) :
    (condExp (ℱ s) P (f t)) =ᵐ[P] f s :=
  hf.condExp_ae_eq hst

theorem martingale_term_integrable {Ω : Type*} [m₀ : MeasurableSpace Ω]
    (P : Measure Ω) {ι : Type*} [Preorder ι]
    (f : ι → Ω → ℝ) (ℱ : Filtration ι m₀) (hf : Martingale f ℱ P) (t : ι) :
    Integrable (f t) P :=
  hf.integrable t
```

`condExp_const_probability` は、定数の条件付き期待値が同じ定数であることを示します。

`Martingale f ℱ P` の定義は、各 `f t` が `ℱ t` に関して強可測であるという `StronglyAdapted` と、$s\leq t$ に対する条件付き期待値のa.e.等式を組にしたものです。`hf.condExp_ae_eq hst` で後者を取り出せます。各時刻の可積分性も `hf.integrable t` で得られます。

ここで証明しているのは、`hf : Martingale f ℱ P` を仮定したときの性質です。具体的な過程がマルチンゲールであることの証明とは別の作業です。また、この性質の取り出しには `IsProbabilityMeasure P` や `SigmaFinite P` を別に仮定する必要はありません。確率過程の個別の定理では、その定理が要求する追加条件を確認します。

## 18.7 まとめと練習問題

| 数学の表現 | Leanの表現 |
|---|---|
| $L^p(X,\mu)$ | `Lp E p μ` |
| $L^p$に属する関数 | `MemLp f p μ` |
| $L^p$の元のノルム | `‖f‖`。通常のノルム空間として扱う範囲は $1\leq p\leq\infty$ |
| 確率空間 | `[MeasurableSpace Ω]`、`P : Measure Ω`、`[IsProbabilityMeasure P]` |
| 実数値確率変数 | `X : Ω → ℝ` と `Measurable X` |
| 可積分な$X$の期待値 | `∫ ω, X ω ∂P` |
| フィルトレーション | `Filtration ι m₀` |
| 条件付き期待値 | `condExp m P X` |
| マルチンゲール | `Martingale f ℱ P` |

:::details 追加確認：内積とノルムの公式

```lean:完成例・確認コマンド
import Mathlib
open MeasureTheory
open scoped ENNReal

#check @MeasureTheory.L2.inner_def
#check @MeasureTheory.Lp.norm_def

theorem real_l2_inner {α : Type*} [MeasurableSpace α] (μ : Measure α)
    (f g : Lp ℝ 2 μ) : inner ℝ f g = ∫ x, f x * g x ∂μ := by
  rw [L2.inner_def]
  congr 1
  funext x
  exact mul_comm (g x) (f x)

theorem real_l2_norm_sq {α : Type*} [MeasurableSpace α] (μ : Measure α)
    (f : Lp ℝ 2 μ) : ‖f‖ ^ 2 = ∫ x, (f x) ^ 2 ∂μ := by
  rw [← real_inner_self_eq_norm_sq, real_l2_inner]
  simp only [pow_two]

theorem complex_l2_inner {α : Type*} [MeasurableSpace α] (μ : Measure α)
    (f g : Lp ℂ 2 μ) :
    inner ℂ f g = ∫ x, star (f x) * g x ∂μ := by
  simpa only [RCLike.inner_apply, RCLike.star_def, mul_comm] using
    (L2.inner_def (𝕜 := ℂ) f g)
```

内積の補題名は `L2.inner_def` です。`real_l2_inner` は実数値関数について $\langle f,g\rangle=\int fg\,d\mu$ を、`real_l2_norm_sq` は $\|f\|^2=\int f^2\,d\mu$ を示します。後者は、内積とノルムの関係を前者へ代入しています。

一般の `Lp` のノルムを `eLpNorm` へ戻す補題は `Lp.norm_def` です。`f : Lp E p μ` では有限性が既に保証されているため、`(eLpNorm f p μ).toReal` として実数値のノルムを表せます。

複素数値の場合、Mathlibの内積は**第1変数が共役線形**です。`complex_l2_inner` は $\langle f,g\rangle=\int \overline{f(x)}g(x)\,d\mu(x)$ を確認しています。`star` は複素数では複素共役です。実数の場合は共役が恒等写像になります。
:::

**問題18.4**　上の測度 $P$ と関数 $X$ について、次をLeanで証明してください。

1. $X$ は可測である。
2. $X$ と $X^2$ は $P$ に関して可積分である。
3. $\mathbb{E}[X]=1/2$ である。
4. $\mathbb{E}[X^2]=1/3$ である。

発展として、これらの値から分散 $\mathbb{E}[X^2]-(\mathbb{E}[X])^2$ を紙上で計算してください。

:::details ヒント1：数学の条件を揃える

$X$ と $X^2$ は連続です。閉区間[0,1]はコンパクトで、Lebesgue測度はコンパクト集合上で有限なので、両方ともこの区間上で可積分です。実数全体のLebesgue測度について可積分だと主張しているのではありません。

Leanでは `IntegrableOn f (Set.Icc 0 1) volume` と `Integrable f unitIntervalMeasure` が定義を展開すると同じ条件になることを利用します。
:::

:::details ヒント2：補題を探す

可積分性には `ContinuousOn.integrableOn_Icc` が使えます。積分値は `integral_Icc_eq_integral_Ioc` で端点を取り除き、`intervalIntegral.integral_of_le` を逆向きに使って区間積分へ移すと、`integral_id` と `integral_pow` を使えます。

端点を取り除いても値が変わらないのは、Lebesgue測度で一点集合の測度が0だからです。Dirac測度などにそのまま適用できる変形ではありません。
:::

:::details 解答：可測性と可積分性

```lean:完成例・確認コマンド
-- 総合演習の共通準備を引き継ぐ。
theorem unitCoordinate_measurable : Measurable unitCoordinate := measurable_id

theorem unitCoordinate_integrable : Integrable unitCoordinate unitIntervalMeasure := by
  exact continuous_id.continuousOn.integrableOn_Icc

theorem unitCoordinate_sq_integrable :
    Integrable (fun x => unitCoordinate x ^ 2) unitIntervalMeasure := by
  exact (continuous_id.pow 2).continuousOn.integrableOn_Icc
```

`measurable_id` は恒等関数の可測性です。続く2つの証明では、Leanが `unitCoordinate`・`unitIntervalMeasure`・`IntegrableOn` を展開して、閉区間上の連続関数の可積分性とゴールを対応させます。可測性だけから可積分性を結論しているわけではありません。

残る積分値の計算は、次の解答へ続きます。
:::

:::details 解答の続き：期待値と二乗の期待値

```lean:完成例・確認コマンド
-- 共通準備と、直前の可測性・可積分性の解答を引き継ぐ。
theorem unitCoordinate_expectation :
    (∫ x, unitCoordinate x ∂unitIntervalMeasure) = 1 / 2 := by
  change (∫ x in Set.Icc (0 : ℝ) 1, x) = 1 / 2
  rw [integral_Icc_eq_integral_Ioc,
    ← intervalIntegral.integral_of_le (by norm_num : (0 : ℝ) ≤ 1),
    integral_id]
  norm_num

theorem unitCoordinate_second_moment :
    (∫ x, unitCoordinate x ^ 2 ∂unitIntervalMeasure) = 1 / 3 := by
  change (∫ x in Set.Icc (0 : ℝ) 1, x ^ 2) = 1 / 3
  rw [integral_Icc_eq_integral_Ioc,
    ← intervalIntegral.integral_of_le (by norm_num : (0 : ℝ) ≤ 1),
    integral_pow]
  norm_num
```

`change` は定義を展開して集合上の積分を表示します。`rw` は「閉区間上の積分 → 左開右閉区間上の積分 → 向き付き区間積分 → 計算公式」の順に進め、`norm_num` が端点0と1の計算を終えます。

これらの計算補題の適用には、直前の可積分性の証明を引数として渡していません。可積分性を別に示したことで、得られた値を通常の期待値として扱えることも確認できています。発展小問の分散は $1/3-(1/2)^2=1/12$ です。この分散の計算は紙上の解答です。
:::

**問題18.5**　問題18.4と同じ $X$ から $L^2(\mathbb{R},P)$ の元 $u$ を構成してください。

1. `MemLp unitCoordinate 2 unitIntervalMeasure` を示す。
2. その証明から `Lp ℝ 2 unitIntervalMeasure` の元を作る。
3. 元の関数 $X$ と、$u$ を関数として扱ったものが $P$ に関してa.e.等しいことを示す。
4. $\|u\|^2=1/3$ を示す。

:::details ヒント1：関数からL²の元へ

実数値関数では、AE強可測性のもとで `MemLp f 2 P` は二乗の可積分性と同値です。問題18.4の可測性からAE強可測性を得て、二乗の可積分性を再利用します。

所属条件を示したら `MemLp.toLp` で元を作れます。その代表関数が元の関数と等しいのはa.e.の意味なので、全点での等式へ置き換えないでください。
:::

:::details ヒント2：使う補題と等式の移し方

`memLp_two_iff_integrable_sq`、`MemLp.toLp`、`MemLp.coeFn_toLp` の型を調べてください。問題18.3の `real_l2_norm_sq` でノルムを積分に戻し、`integral_congr_ae` で代表関数を $X$ に置き換えます。`filter_upwards` でa.e.等式を受け取った点では、通常の等式として二乗の中を書き換えられます。
:::

:::details 解答を見る

```lean:完成例・確認コマンド
-- 問題18.3の real_l2_norm_sq、共通準備、問題18.4の両方の解答を引き継ぐ。
theorem unitCoordinate_memLp : MemLp unitCoordinate 2 unitIntervalMeasure := by
  exact (memLp_two_iff_integrable_sq
    unitCoordinate_measurable.aestronglyMeasurable).2 unitCoordinate_sq_integrable

noncomputable def unitCoordinateL2 : Lp ℝ 2 unitIntervalMeasure :=
  unitCoordinate_memLp.toLp unitCoordinate

theorem unitCoordinateL2_ae :
    unitCoordinateL2 =ᵐ[unitIntervalMeasure] unitCoordinate :=
  unitCoordinate_memLp.coeFn_toLp

theorem unitCoordinateL2_norm_sq : ‖unitCoordinateL2‖ ^ 2 = 1 / 3 := by
  rw [real_l2_norm_sq]
  calc
    (∫ x, (unitCoordinateL2 x) ^ 2 ∂unitIntervalMeasure) =
        ∫ x, unitCoordinate x ^ 2 ∂unitIntervalMeasure := by
      apply integral_congr_ae
      filter_upwards [unitCoordinateL2_ae] with x hx
      rw [hx]
    _ = 1 / 3 := unitCoordinate_second_moment
```

`memLp_two_iff_integrable_sq` の `.2` は「二乗が可積分 → L²に属する」の向きです。`toLp` で構成した元の代表関数について `coeFn_toLp` がa.e.等式を与えます。最後は積分がa.e.での変更に影響されないことを使い、問題18.4の二乗の期待値へ戻しています。

**振り返り**：関数 $X$、所属条件の証明、空間の元 $u$ はそれぞれ異なる対象です。また、`u x = X x` を全点で仮定する必要はありません。この区別により、測度論のa.e.等式と関数解析のノルムを同じ計算の中で使えます。
:::

:::message
**第18章 つまずきポイントQ&A**

**Q1. `MemLp f p μ` の指数はなぜ `ℝ≥0∞` なのですか？**

→ 有限の指数と $p=\infty$ を同じ型で表すためです。定義に $p=0$ や $0<p<1$ を渡せることと、通常のBanach空間の性質を使えることは別です。本章のノルム空間の説明は $1\leq p\leq\infty$ を対象にしています。

**Q2. $L^p$ノルムの積分公式をいつ使えますか？**

→ $1\leq p<\infty$ では $\|f\|_p=(\int\|f\|^p\,d\mu)^{1/p}$、$p=\infty$ では本質的上限です。Leanの `eLpNorm_eq_lintegral_rpow_enorm_toReal` は `p ≠ 0` と `p ≠ ∞` を要求します。`MemLp` の可測性条件は `AEStronglyMeasurable` です。

**Q3. 条件付き期待値のσ有限性はどの測度について確認しますか？**

→ `hm : m ≤ m₀` に対する `P.trim hm` です。`SigmaFinite P` だけで置き換えないでください。確率測度なら、この制限も有限です。加えて通常の条件付き期待値として扱うには `Integrable X P` を確認します。

**Q4. `Martingale` に確率測度の型クラスは必須ですか？**

→ 固定版の定義や `hf.condExp_ae_eq hst` には必須ではありません。添字の `Preorder`、可測空間、実ノルム空間と完備性などが型に現れます。本章の値域は実数なので、値域側のインスタンスは既に用意されています。

**Q5. `IsProbabilityMeasure P` はどう作りますか？**

→ `hP : P Set.univ = 1` から `⟨hP⟩` で作れます。18.3節の `probability_of_univ_eq_one` がその完成例です。証明を型クラス探索に使わせたい文脈では `letI : IsProbabilityMeasure P := ⟨hP⟩` と置きます。
:::
