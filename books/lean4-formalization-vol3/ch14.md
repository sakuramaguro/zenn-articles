## 14.1 可測関数の動機 ──── 積分のために必要な条件

![実数値可測関数とBorel集合の逆像を示す図](/images/vol3/fig-06.png)
*図14-1：値域が実数の例です。点線の逆像は集合に対する操作で、逆関数の存在を意味しません。*

[第16章](ch16)でLebesgue積分を定義しますが、「どんな関数でも積分できる」わけではありません。積分できる関数の候補を特定する必要があります。

実数の有界閉区間上のリーマン積分では、連続関数は積分できます。また有界関数がリーマン可積分であることは、不連続点全体がLebesgue測度ゼロであることと同値です（リーマン・ルベーグの基準）。定義域や有界性の条件を省いてはいけません。

Lebesgue積分では、まず**可測性**を確認します。ただし、可測であるだけで実数値の可積分性が得られるわけではありません。例えば実数全体での定数関数1はLebesgue可測ですが、ノルムの積分が無限大になるため可積分ではありません。

## 14.2 可測関数の数学的定義 ──── 「逆像が可測集合」

### 数学の定義：可測関数

可測空間 $(X, \mathcal{M})$ から可測空間 $(Y, \mathcal{N})$ への関数 $f : X \to Y$ が**可測**であるとは、

$$
\forall B \in \mathcal{N},\quad f^{-1}(B) \in \mathcal{M}
$$

が成り立つことをいいます。すなわち「$\mathcal{N}$ の可測集合の逆像が $\mathcal{M}$ の可測集合になる」という条件です。

これは連続関数の定義——「開集合の逆像が開集合」——の測度論版です。「開集合」を「可測集合」に置き換えた構造です。

:::message
💡 **なぜ「逆像」なのか**

積分を定義するとき、「$f$ の値が $[a, b]$ に入る $x$ の集合」を測りたくなります。これはまさに $f^{-1}([a, b])$ のことです。可測性は、このような逆像に対して測度の可算加法性を使うための条件です。Mathlibでは非可測集合にも外測度としての値を与えますが、それだけで積分に必要な性質が得られるわけではありません。
:::

## 14.3 `Measurable` の解剖と `Continuous.measurable`

### Lean の実装：`Measurable`

```lean:完成例・確認コマンド
import Mathlib
open MeasureTheory

#print Measurable
#check @Continuous.measurable

theorem measurable_iff_preimages {α β : Type*}
    [MeasurableSpace α] [MeasurableSpace β] (f : α → β) :
    Measurable f ↔ ∀ t : Set β, MeasurableSet t → MeasurableSet (f ⁻¹' t) := by
  constructor
  · intro hf t ht
    exact hf ht
  · intro h t ht
    exact h t ht
```

`Measurable f` の正体は「$\mathcal{N}$ の可測集合の $f$ による逆像が $\mathcal{M}$ の可測集合」という命題そのものです。

```lean:完成例・確認コマンド
import Mathlib
open MeasureTheory

-- 連続関数は可測（BorelSpace が必要）
theorem continuous_measurable (f : ℝ → ℝ) (hf : Continuous f) : Measurable f := hf.measurable

-- 定数関数は可測
theorem constant_measurable (c : ℝ) : Measurable (fun _ : ℝ => c) := measurable_const

-- 恒等関数は可測
theorem identity_measurable : Measurable (id : ℝ → ℝ) := measurable_id

-- 可測関数の合成は可測
theorem compose_measurable (f g : ℝ → ℝ) (hf : Measurable f) (hg : Measurable g) :
    Measurable (g ∘ f) := hg.comp hf

-- 可測関数の和は可測
theorem add_measurable (f g : ℝ → ℝ) (hf : Measurable f) (hg : Measurable g) :
    Measurable (fun x => f x + g x) := hf.add hg
```

#### 証明の実況中継：`Continuous f → Measurable f` を tactic で追う

**ステップ②：`exact hf.measurable` で閉じる**

実数から実数への関数では、`Continuous.measurable` からこの結論が得られます。連続性により、値域の開集合の逆像が開集合になります。可測集合の逆像が可測になるという性質は補集合・可算合併でも保たれるため、生成された全てのボレル集合へ広がります。一般形では、定義域に `OpensMeasurableSpace`、値域に `BorelSpace` が必要です。上の `#check @Continuous.measurable` でこの違いを確認できます。

## 14.4 AE（ほとんど至るところ）の哲学 ──── `MeasureTheory.ae`

### 数学の概念：a.e.（almost everywhere）

測度論において、「ほとんど至るところ（almost everywhere, a.e.）」という言葉は「測度ゼロの例外を除いて」という意味です。

$$
f = g \quad \mu\text{-a.e.} \iff \mu(\{x \mid f(x) \neq g(x)\}) = 0
$$

例えば、ディリクレ関数 $\mathbf{1}_{\mathbb{Q}}$ は Lebesgue 測度の意味で「ほとんど至るところ $0$」です（$\mathbb{Q}$ は測度ゼロ）。

### Lean の実装：`∀ᵐ x ∂μ` と `f =ᵐ[μ] g`

```lean:完成例・確認コマンド
import Mathlib
open MeasureTheory

#check @MeasureTheory.ae
#check @Filter.EventuallyEq
#check @ae_iff

-- 実数値の指示関数としてディリクレ関数を書く。
theorem dirichlet_ae_zero :
    (Set.range ((↑) : ℚ → ℝ)).indicator (fun _ => (1 : ℝ)) =ᵐ[volume]
      (fun _ => 0) := by
  have hQ : ∀ᵐ x : ℝ ∂volume, x ∉ Set.range ((↑) : ℚ → ℝ) :=
    (Set.countable_range ((↑) : ℚ → ℝ)).ae_notMem volume
  filter_upwards [hQ] with x hx
  simp [Set.indicator_of_notMem hx]
```

`∀ᵐ x ∂μ, P x` は `Filter.Eventually P (MeasureTheory.ae μ)` の記法です。`ae_iff` により、`{x | ¬ P x}` の外測度が0であることと同値です。この例ではLebesgue測度で各一点の測度が0なので、可算集合である有理数全体も測度0になります。任意の測度で可算集合が測度0になるわけではありません。

### 実況中継：`ae_restrict_of_ae` で制限測度に降ろす

AE 命題の便利な推論規則として `ae_restrict_of_ae` を見ていきます。「全体空間で a.e. 成り立つ」ことから「部分集合への制限測度でも a.e. 成り立つ」ことを自動的に導きます。

```lean:完成例・確認コマンド
import Mathlib
open MeasureTheory

-- 集合 s の可測性は、この方向の推論には不要。
#check @MeasureTheory.ae_restrict_of_ae
#check @MeasureTheory.ae_restrict_le
```

**証明の実況中継**：`f =ᵐ[volume] g` から `f =ᵐ[volume.restrict (Set.Icc 0 1)] g` を導きます。

```lean:完成例・確認コマンド
import Mathlib
open MeasureTheory
theorem ae_restrict_tactic (f g : ℝ → ℝ) (h : f =ᵐ[volume] g) :
    f =ᵐ[volume.restrict (Set.Icc 0 1)] g := by
  exact ae_restrict_of_ae h
```

タクティクモードで実況中継するとこうなります。

**ステップ①** — `exact ae_restrict_of_ae h` を入力する直前の InfoView：

```text

⊢ f =ᶠ[ae (volume.restrict (Set.Icc 0 1))] g
```

この表示の `=ᶠ[ae μ]` は、本文で使う `=ᵐ[μ]` と同じa.e.等式を表します。

**ステップ②** — `exact ae_restrict_of_ae h` を入力した後：

```text

```

`ae_restrict_of_ae h` の型が `∀ᵐ x ∂volume.restrict (Set.Icc 0 1), f x = g x` と推論され、ゴールと一致します。No goals ✓

:::message
💡 **フィルターという抽象層**

第2巻の `Filter.Tendsto` は、像フィルターと収束先のフィルターの順序関係で収束を記述しました。一方、a.e.の命題は `μ.ae` に関する `Filter.Eventually` です。両方で同じフィルターの枠組みを使っています。`ae_restrict_le` が `(μ.restrict s).ae ≤ μ.ae` を与え、そこから `ae_restrict_of_ae` が従います。この方向には `s` の可測性は必要ありません。
:::

## 14.5 `AEMeasurable` と `Measurable` の違い

### 数学の概念：AE 可測関数

$f : X \to Y$ が**AE 可測**（$\mu$-AE 可測）であるとは、ある可測関数 $g$ が存在して $f =_{\mu\text{-a.e.}} g$ が成り立つことをいいます。

「ほとんど至るところ可測関数と等しい関数」は AE 可測ですが、可測とは限りません。

### Lean の実装：`AEMeasurable`

```lean:完成例・確認コマンド
import Mathlib
open MeasureTheory

#print AEMeasurable
#check @AEMeasurable.congr
#check @Measurable.stronglyMeasurable
#check @StronglyMeasurable.measurable

theorem measurable_is_aemeasurable (f : ℝ → ℝ) (μ : Measure ℝ)
    (hf : Measurable f) : AEMeasurable f μ := hf.aemeasurable

theorem continuous_is_aemeasurable (f : ℝ → ℝ) (hf : Continuous f)
    (μ : Measure ℝ) : AEMeasurable f μ := hf.measurable.aemeasurable
```

:::message alert
💥 **`Measurable` と `AEMeasurable` の混同に注意**

`Measurable f` は定義域と値域のσ-代数に依存し、測度の選択には依存しません。一方 `AEMeasurable f μ` は**測度 `μ` に依存する**命題です。測度が変われば AE 可測かどうかも変わり得ます。

非負積分では `AEMeasurable` がよく使われます。一方、実数値・Banach空間値のBochner積分では `AEStronglyMeasurable` も重要です。実数値では可測性から強可測性へ移れますが、一般の値域へそのまま広げられるわけではありません。`Measurable` からは `.aemeasurable` でAE可測性を得られます。追加仮定なしに逆向きは導けません。
:::

## 14.6 まとめ ──── 第14章の全対応表と練習問題

数学とLeanの対応を表にまとめます。

| 数学の表現 | Lean の表現 |
|---|---|
| $f : X \to Y$ が可測 | `Measurable f` |
| 逆像が可測：$f^{-1}(B) \in \mathcal{M}$ | `Measurable f` の定義 |
| $f$ が連続 $\Rightarrow$ $f$ が可測 | `Continuous.measurable` |
| $f = g$ a.e. | `f =ᵐ[μ] g` |
| $\mu$-a.e. 全称量化 | `∀ᵐ x ∂μ, P x` |
| a.e. $\Leftrightarrow$ 例外集合の測度ゼロ | `ae_iff` |
| $\mu$-a.e. $\Rightarrow$ $(\mu \restriction_S)$-a.e. | `ae_restrict_of_ae` |
| $f$ が AE 可測 | `AEMeasurable f μ` |
| 可測 $\Rightarrow$ AE 可測 | `Measurable.aemeasurable` |

### 章末練習問題

**問題 14.1**　$f(x) = x^2$ が $\mathbb{R}$ 上で可測であることを `Continuous.measurable` を使って示してください。


:::details ヒントを見る

`Continuous.measurable` を使ってください。`continuous_pow 2` で $f(x) = x^2$ の連続性が出ます。または `fun_prop` タクティクが一発で解決します。
:::

:::details 解答を見る

```lean:完成例・確認コマンド
import Mathlib
-- 方法①：Continuous.measurable を使う
theorem square_measurable : Measurable (fun x : ℝ => x ^ 2) := by
  exact (continuous_pow 2).measurable
  -- No goals ✓
```

`continuous_pow 2` で $x \mapsto x^2$ の連続性を得て、`Continuous.measurable` で連続性 → 可測性を導きます。連続関数はボレル可測です。
:::

:::details 別解を見る

```lean:完成例・確認コマンド
import Mathlib
-- 方法②：fun_prop タクティクに任せる
theorem square_measurable_auto : Measurable (fun x : ℝ => x ^ 2) := by
  fun_prop
```

`fun_prop` は登録された関数の性質と合成規則を使うタクティクです。この例では冪の可測性を証明できますが、任意の可測性の問題を解けるわけではありません。
:::

**問題 14.2**　`Measurable.add`・`Measurable.mul` を使って、多項式関数が可測であることを Lean で確認してください。


:::details ヒントを見る

`fun_prop` タクティクが多項式関数の可測性を自動証明します。手動で行う場合は `Measurable.add`・`Measurable.mul`・`measurable_id`・`measurable_const` を組み合わせます。

**問題 14.3**　`AEMeasurable` の定義を `#print` で確認し、「可測関数 $g$ を a.e. 修正した関数」が AEMeasurable になることを Lean で示してください。


:::details ヒントを見る

`AEMeasurable.congr` を使ってください。`hf.aemeasurable` で `Measurable f → AEMeasurable f μ` が得られ、`h : f =ᵐ[μ] g` に対して `.congr h` で修正後の `g` に移せます。
:::

:::details 解答を見る

```lean:完成例・確認コマンド

section Example13

variable {α : Type*} [MeasurableSpace α] (μ : MeasureTheory.Measure α)
theorem ae_change_measurable (f g : α → ℝ) (hf : Measurable f) (h : f =ᵐ[μ] g) :
    AEMeasurable g μ := by
  exact hf.aemeasurable.congr h
  -- No goals ✓

end Example13
```

`Measurable.aemeasurable` で可測性から AE 可測性を得て、`AEMeasurable.congr` で a.e. 等しい関数へ転送します。
:::

:::details 別解を見る

```lean:完成例・確認コマンド
import Mathlib
section Example14

variable {α : Type*} [MeasurableSpace α] (μ : MeasureTheory.Measure α)
theorem ae_change_measurable_from_def (f g : α → ℝ) (hf : Measurable f) (h : f =ᵐ[μ] g) :
    AEMeasurable g μ := by
  exact ⟨f, hf, h.symm⟩

end Example14
```

`AEMeasurable g μ` の定義は `∃ g', Measurable g' ∧ g =ᵐ[μ] g'` です。代表元として `f` を選ぶため、最後に必要なのは `g =ᵐ[μ] f` です。ここでは `h.symm` を渡します。`.congr h` に渡す向きとの違いを確認してください。
:::

:::message
**📝 第14章 つまずきポイントQ&A**

**Q1. `Measurable` と `AEMeasurable` どちらを使えばよいですか？**
→ 非負積分では `AEMeasurable`、Bochner積分では `AEStronglyMeasurable` など、その定理の仮定を確認してください。`Measurable` は測度なしで成立する「純粋な」可測性です。`Measurable → AEMeasurable`（`Measurable.aemeasurable`）は自動的に成り立ちますが逆は成り立ちません。

**Q2. `measurable_of_measurable_on_compl_singleton` の意味を教えてください**
→ 定義域の一点集合が可測であるという `MeasurableSingletonClass` の下で、1点を除いた領域への制限が可測なら、元の関数も可測であるという補題です。測度を仮定しない可測性の主張です。

積分への影響は別に判断します。Lebesgue測度では一点の測度が0なので、そこでの変更はa.e.等式を保ちます。Dirac測度 `Measure.dirac a` では点 `a` の測度が1であり、そこで値を変えると積分値も変わります。

次の例は、0でだけ値を1にした関数を使う比較です。可測性とLebesgue測度でのa.e.等式を確認し、[第16章](ch16)で扱う積分も先取りして計算します。

```lean:完成例・確認コマンド
import Mathlib
open MeasureTheory

#check @measurable_of_measurable_on_compl_singleton

noncomputable def pointChange : ℝ → ℝ :=
  ({0} : Set ℝ).indicator (fun _ => (1 : ℝ))

theorem pointChange_measurable : Measurable pointChange :=
  measurable_const.indicator (measurableSet_singleton 0)

theorem pointChange_ae_zero : pointChange =ᵐ[volume] (fun _ => (0 : ℝ)) := by
  have h0 : ∀ᵐ x : ℝ ∂volume, x ∉ ({0} : Set ℝ) :=
    (Set.countable_singleton (0 : ℝ)).ae_notMem volume
  filter_upwards [h0] with x hx
  simp [pointChange, Set.indicator_of_notMem hx]

-- 積分の章を先取りした比較。同じ関数でも測度を変えると値が変わる。
theorem pointChange_integral_volume : (∫ x, pointChange x) = 0 := by
  simpa using integral_congr_ae pointChange_ae_zero

theorem pointChange_integral_dirac :
    (∫ x, pointChange x ∂Measure.dirac (0 : ℝ)) = 1 := by
  rw [integral_dirac]
  simp [pointChange]
```

**Q3. `StronglyMeasurable` と `Measurable` の違いは？**
→ `Measurable` は可測集合の逆像の条件、`StronglyMeasurable` は単関数列による各点での近似を表します。実数値や、ボレル構造を持つ可分なBanach空間値では両者は同値です。一般のBanach空間では可分性や値域の性質を確認する必要があります。AE強可測性は、強可測な関数とa.e.等しいことを表します。

**Q4. `Measurable.comp` の引数の順番はどうなっていますか？**
→ `hg.comp hf : Measurable (g ∘ f)` で、`hf : Measurable f`、`hg : Measurable g` です。数学では $g \circ f$ ですが、Lean では `hg` が外側、`hf` が内側です。

**Q5. 定数関数が可測なのはなぜですか？**
→ 定数関数 $f \equiv c$ について、任意の集合 $S$ の逆像は $f^{-1}(S) = \Omega$（$c \in S$）または $f^{-1}(S) = \emptyset$（$c \notin S$）です。どちらも σ-代数に属するので可測です。Lean では `measurable_const` として登録されています。
:::

### 著者より

「ほとんど至るところ」という言葉の力に最初は半信半疑でしたが、積分論では測度ゼロの集合は実質的に無視できる——その事実が `=ᵐ[μ]` という記法に凝縮されていて、Lean で書いたとき改めてその優雅さを実感しました。
