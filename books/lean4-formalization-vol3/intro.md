# はじめに

本巻は「Lean 4で始める数学の形式化」シリーズの第3巻です。σ-代数と測度から出発し、可測関数・Lebesgue積分・収束定理を学んで、Lᵖ空間と確率空間をLeanで記述するところまで進みます。

本巻の本文は、合本用原稿のPart 3（第12〜18章）と共通しています。合本の購入も検討している方は、収録内容の重複にご注意ください。

## この巻で目指すこと

到達目標は、**積分と極限を交換するための仮定を読み取り、Mathlibの定理に渡して結論を得られるようになること**です。可測性、可積分性、ほとんど至る所で成り立つ条件を区別し、単調収束定理・Fatouの補題・優収束定理を適用します。最後に、[0,1]の一様分布で期待値と二乗の期待値を計算し、同じ関数から $L^2$ の元を構成してノルムの二乗を求めます。

一般定理を最初から再証明することと、ライブラリにある定理を使うことを区別して読み進めてください。本巻では定義や定理の型を確認し、具体例の証明を通じて数学の仮定との対応を学びます。

| 章 | 学ぶ内容 |
|---|---|
| [第12章](ch12) | σ-代数、可測空間、ボレル集合、位相との関係 |
| [第13章](ch13) | 測度、Lebesgue測度、数え上げ測度、Dirac測度、確率測度 |
| [第14章](ch14) | 可測関数、ほとんど至る所での性質、測度の制限 |
| [第15章](ch15) | 単関数、指示関数、非負積分に向けた近似 |
| [第16章](ch16) | 非負積分と実数値積分、可積分性、具体的な積分公式 |
| [第17章](ch17) | 単調収束・Fatou・優収束の仮定と適用、積分と極限の交換 |
| [第18章](ch18) | Lᵖ空間、期待値、条件付き期待値、マルチンゲールの基本的な性質。一様分布とL²をつなぐ総合演習 |

第18章ではMathlibのマルチンゲールの定義から性質を取り出す完成例も扱います。具体的な確率過程の構成、Itô積分、確率微分方程式の解の構成は本巻の範囲には含まれず、第4巻で扱う予定です。

章番号は第1・2巻と合本との対応を保つため、第12〜18章としています。Zennの目次では序文も一項目として数えるため、画面の項目番号と本文の章番号は異なります。序文・第12章・第13章は無料で読めます。

## 前提知識

数学では、集合と写像、数列・関数の極限、実数の積分、距離空間と位相の基礎を前提とします。測度論の概念は各章で導入しますが、紙の上でも定義や仮定を確認しながら読み進めてください。

Leanでは、型クラス、仮定とゴールの読み方、基本的なタクティク、Mathlibの補題探索を使います。[『Lean 4で学ぶ形式証明と線形代数【第1巻】』](https://zenn.dev/matsuteru/books/ab366ea6fa62f6)がLeanの基礎を、[『Lean 4で学ぶ位相・関数解析と不動点定理【第2巻】』](https://zenn.dev/matsuteru/books/lean4-formalization-vol2)がフィルター・位相・完備性を扱っています。同程度の知識があれば、本巻から始めることもできます。

## 掲載コードと同じ環境を使う

検証に使用した組み合わせは、**Lean 4.29.0-rc6** と **Mathlib `5c8398df528176d9c87ccd9226ba8f7c8852d59c`** です。Leanはリリース候補版であり、最新版や安定版という意味ではありません。

第1・2巻の固定環境を準備済みなら、同じ `lean` フォルダを使えます。初めて準備する場合は、無料公開の[第1巻・第1章の環境構築](https://zenn.dev/matsuteru/books/ab366ea6fa62f6/viewer/d579df)を参照してください。

Git、VS Code、公式Lean 4拡張機能を準備したうえで、新しい作業場所に次の手順で検証用プロジェクトを取得します。

```sh
git clone https://github.com/sakuramaguro/zenn-articles.git
cd zenn-articles
# 掲載コードを検証した版を使う
git checkout de47df71b6aae0523272ef689d6d30a623bfbdc4
cd lean
lake exe cache get
lake build
```

VS Codeで開くのは `lean` フォルダです。通常の学習では `lake update` を実行せず、固定した依存関係を使ってください。詳しい手順は[検証環境のREADME](https://github.com/sakuramaguro/zenn-articles/blob/de47df71b6aae0523272ef689d6d30a623bfbdc4/lean/README.md)にあります。

## コード欄の読み方

| 表示 | 使い方 |
|---|---|
| 完成例・確認コマンド | 本文に示した `import`、先行宣言などの前提を揃えて実行します。型の確認に成功することと、新しい定理を証明することは区別します。 |
| 未完成の骨格・練習問題 | `sorry` などの穴を自分で埋める問題です。完成した解答とは区別します。 |

各章の冒頭にある実行手順を確認してください。同じ章の中でも、別ファイルで試す例と、先行する宣言を引き継ぐ例があります。

`No goals` はその位置のゴールが閉じたことを示します。完成の確認では、エラー・警告、主要定理の `#print axioms`、仮定と結論の数学的な意味を確認します。未証明部分に依存する `sorryAx` が残っていないことも確かめます。

## 練習問題の進め方

第12〜17章は各3問、第18章は総合演習2問を含む5問で、計23問の章末問題があります。定義を確認する問題と、Leanで性質を証明する問題を通じて復習します。ヒントと解答を開く前に、自分で仮定と結論を書き出してみてください。総合演習18.4・18.5では、第13章の制限測度、第14章の可測性とa.e.等式、第16章の積分を再利用します。掲載順にまとめた解答ファイルは、検証用プロジェクトの `lean/examples/Volume3Exercises.lean` にあります。

積分の問題では、関数が可測であること、可積分であること、非負であることのうち、どの条件が必要かを確認します。収束定理の問題では、点ごとの収束とほとんど至る所での収束、支配関数の条件を区別してください。動いたコードを写すだけで終わらず、使った定理の仮定を数学の言葉で説明できるか確かめると理解が深まります。

それでは、[第12章](ch12)で可測空間の定義から始めましょう。
