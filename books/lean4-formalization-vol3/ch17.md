# 第17章：収束定理──積分と極限の交換

## 17.0 本章のゴール ──── ゴール逆算型アプローチ

```lean:完成例・確認コマンド

open MeasureTheory Filter
open scoped ENNReal Topology

-- 型の全体は #check の出力で確認する。以下のコメントは要約。

#check @lintegral_liminf_le
-- Measurable 版の Fatou の補題。
#check @lintegral_liminf_le'
-- AEMeasurable 版の Fatou の補題。
#check @tendsto_integral_of_dominated_convergence
-- 優関数 bound の後に、各 Fₙ の AE 強可測性、bound の可積分性、

```

三定理はすべて「極限操作と積分を交換していいか」という問いへの答えです。

$$
\lim_{n \to \infty} \int f_n \, d\mu \overset{?}{=} \int \lim_{n \to \infty} f_n \, d\mu
$$

単調収束定理と優収束定理は、それぞれの仮定のもとでこの交換を正当化します。Fatouの補題は等号を主張せず、各点の極限下限の積分を、積分列の極限下限で上から評価します。以下は本書で固定したLean・Mathlibの版を対象に、既存の定理を適用する例です。

## 17.1 三定理の全体像 ──── 「なぜ極限と積分を交換できるか」

コンパクトな区間上のリーマン積分では、「連続関数列が一様収束すれば極限と積分を交換できる」という定理がありました。Lebesgue積分では、単調性や可積分な優関数による支配を使い、各点収束やa.e.収束からも交換を正当化できます。

| 定理 | 関数列の前提 | 追加の条件 | 結論 |
|---|---|---|---|
| 単調収束定理 | 非負可測関数列 | 各点で単調増加 | 上限と積分を交換 |
| Fatouの補題 | 非負可測関数列（AE 可測でもよい） | 単調性や収束の仮定は不要 | 極限下限についての不等式 |
| 優収束定理 | 実数値可測関数列（Leanの一般形はAE 強可測） | 可積分な優関数によるAE 支配とAE 収束 | 極限と積分を交換 |

単調収束定理と優収束定理は、異なる条件で交換を保証します。単調収束定理では積分が無限大になる場合も扱えます。一方、ここで扱う実数値の優収束定理は可積分な優関数を必要とします。この違いがあるため、単純な「強さ」の順位では比較しません。

## 17.2 単調収束定理（MCT） ──── `lintegral_iSup`

### 数学の定理：単調収束定理

$0 \leq f_1 \leq f_2 \leq \cdots$ が非負可測関数列で $f_n \nearrow f$（各点収束）ならば、

$$
\int f \, d\mu = \lim_{n \to \infty} \int f_n \, d\mu
$$

が成り立ちます。

### Lean の実装：`lintegral_iSup`

```lean:完成例・確認コマンド
import Mathlib
open MeasureTheory Filter
open scoped ENNReal Topology

#check @lintegral_iSup
#check @lintegral_iSup'
-- 本節は Measurable と Monotone を使う lintegral_iSup を扱う。
-- 末尾に ' が付く版は、AE 可測性と AE での単調性を受け取る。
```

`⨆ n, f n a` は各点での上限で、非負拡張実数値の単調増加列の極限と一致します。上限や積分値が∞でも扱えます。`Monotone f` は `∀ m n, m ≤ n → f m ≤ f n` という単調性です（ここでは各点で $f_m(x) \leq f_n(x)$）。

![区間0から1でn/(n+1)倍のxがxへ単調増加する関数列](/images/vol3/fig-11.png)
*図17-1：非負可測関数の単調増加の具体的な模式例です。区間[0,1]のLebesgue測度で積分も1/2へ増加します。本文の一般定理は非負拡張実数値で述べています。*

### 実況中継：`lintegral_iSup` の直接適用

既に証明した仮定を渡して、Mathlibの定理を適用します。以下のInfoViewは、仮定とゴールに絞った要約表示です。

```lean:完成例・確認コマンド

open MeasureTheory Filter
open scoped ENNReal Topology

-- 各点での上限と非負積分を交換する。

    (f : ℕ → α → ℝ≥0∞) (hf : ∀ n, Measurable (f n))
    (hmono : Monotone f) :
    (∫⁻ a, ⨆ n, f n a ∂μ) = ⨆ n, ∫⁻ a, f n a ∂μ := by
  exact lintegral_iSup hf hmono
```

💡 **`Monotone f` の意味に注意**

ここでの `Monotone f` は「自然数のインデックスに関する単調性」です。型は `f : ℕ → (α → ℝ≥0∞)` なので、`Monotone f` は `∀ m n, m ≤ n → ∀ x, f m x ≤ f n x` を意味します。数学の $f_m(x) \leq f_n(x)$ に対応します。
:::

## 17.3 Fatouの補題 ──── `lintegral_liminf_le`

### 数学の定理：Fatouの補題

非負可測関数列 $\{f_n\}$ に対して、

$$
\int \liminf_{n \to \infty} f_n \, d\mu \leq \liminf_{n \to \infty} \int f_n \, d\mu
$$

が成り立ちます。

### Lean の実装：`lintegral_liminf_le`

```lean:完成例・確認コマンド
import Mathlib
open MeasureTheory Filter
open scoped ENNReal Topology

#check @lintegral_liminf_le
#check @lintegral_liminf_le'
-- 前者は ∀ n, Measurable (f n)、後者は ∀ n, AEMeasurable (f n) μ。
-- 結論はどちらも「各点の liminf の積分 ≤ 積分列の liminf」。
```

`liminf (fun n => f n a) atTop` は「各点 $a$ での $\liminf_{n \to \infty} f_n(a)$」です。`atTop` は「$n \to \infty$」に対応するフィルターです。

### 等号が成立しない反例

Fatouの補題の不等号が真の不等号になり得る例を見ていきます。

$$
f_n(x) = \mathbf{1}_{[n, n+1)}(x)
$$

このとき各 $x$ に対して $\liminf_{n \to \infty} f_n(x) = 0$ ですが、$\int f_n \, d\lambda = 1$ なので

$$
\int \liminf f_n \, d\lambda = 0 < 1 = \liminf \int f_n \, d\lambda
$$

つまり真の不等号になります。

### 実況中継：`lintegral_liminf_le` の直接適用

```lean:完成例・確認コマンド
import Mathlib
open MeasureTheory Filter
open scoped ENNReal Topology

-- AE 可測性を仮定するので、末尾に ' の付いた版を使う。
theorem fatou_ae {α : Type*} [MeasurableSpace α] (μ : Measure α)
    (f : ℕ → α → ℝ≥0∞) (hf : ∀ n, AEMeasurable (f n) μ) :
    (∫⁻ a, liminf (fun n => f n a) atTop ∂μ) ≤
      liminf (fun n => ∫⁻ a, f n a ∂μ) atTop := by
  exact lintegral_liminf_le' hf
```

**ステップ①** — `exact lintegral_liminf_le' hf` 直前の InfoView：

```text
α : Type u_1
inst✝ : MeasurableSpace α
μ : Measure α
f : ℕ → α → ℝ≥0∞
hf : ∀ (n : ℕ), AEMeasurable (f n) μ
⊢ ∫⁻ a, liminf (fun n => f n a) atTop ∂μ ≤
    liminf (fun n => ∫⁻ a, f n a ∂μ) atTop
```

**ステップ②** — `exact lintegral_liminf_le' hf` 後：

```text
No goals
```

`lintegral_liminf_le' hf` の型がゴールと一致します。No goals ✓

`lintegral_liminf_le` は `Measurable` を、`lintegral_liminf_le'` は `AEMeasurable` を受け取ります。上の完成例は後者です。単調収束定理にもAE版の `lintegral_iSup'` があるため、この違いを定理そのものの強弱と混同しないでください。

:::message alert
⚠️ **Fatouの補題は等号ではない**

`lintegral_liminf_le` は $\leq$ であって $=$ ではありません。等号にするには追加の条件（例：優収束定理の条件）が必要です。Fatouの補題は「各点の極限下限の積分を、積分列の極限下限で上から評価する」ときに使います。
:::

![区間nからn+1の指示関数が右へ移動し、各点で0に収束する図](/images/vol3/fig-12.png)
*図17-2：実数全体のLebesgue測度で各積分は1ですが、点ごとの極限は0です。Fatouの補題で真の不等式になる例です。*

## 17.4 優収束定理（DCT） ──── `tendsto_integral_of_dominated_convergence`

### 数学の定理：Lebesgue の優収束定理

実数値可測関数列 $\{f_n\}$ と関数 $f$ を考えます。可積分関数 $g \geq 0$ が存在して、すべての $n$ で $|f_n| \leq g$ a.e. が成り立ち、かつ $f_n \to f$ a.e. ならば、各 $f_n$ と $f$ は可積分で、

$$
\lim_{n \to \infty} \int f_n \, d\mu = \int f \, d\mu
$$

「$g$ が $\{f_n\}$ を支配する（dominate）」ことが名前の由来です。

### Lean の実装：`tendsto_integral_of_dominated_convergence`

```lean:完成例・確認コマンド
import Mathlib
open MeasureTheory Filter
open scoped ENNReal Topology

#check @tendsto_integral_of_dominated_convergence

-- 実数値関数では、AE 可測性から定理に必要な AE 強可測性を得られる。
theorem real_ae_strongly_measurable (f : ℝ → ℝ) (hf : AEMeasurable f volume) :
    AEStronglyMeasurable f volume :=
  hf.aestronglyMeasurable
```

型シグネチャを実況中継で追います。

まず優関数 `bound : α → ℝ` を渡し、続いて次の4つの証明を渡します。

**仮定①**：`∀ n, AEStronglyMeasurable (F n) μ` — 各 $F_n$ はAE 強可測

**仮定②**：`Integrable bound μ` — 優関数は可積分

**仮定③**：`∀ n, ∀ᵐ a ∂μ, ‖F n a‖ ≤ bound a` — a.e. で $|F_n(a)| \leq \text{bound}(a)$（支配）

**仮定④**：`∀ᵐ a ∂μ, Tendsto (fun n => F n a) atTop (nhds (f a))` — a.e. で $F_n(a) \to f(a)$

**結論**：`Tendsto (fun n => ∫ a, F n a ∂μ) atTop (nhds (∫ a, f a ∂μ))` — $\int F_n \, d\mu \to \int f \, d\mu$

### 実況中継：`tendsto_integral_of_dominated_convergence` の直接適用

```lean:完成例・確認コマンド
import Mathlib
open MeasureTheory Filter
open scoped ENNReal Topology

-- bound の後に、定理が要求する順序で4つの証明を渡す。
theorem dominated_convergence (F : ℕ → ℝ → ℝ) (f bound : ℝ → ℝ)
    (hFm : ∀ n, AEStronglyMeasurable (F n) volume)
    (hbound : Integrable bound volume)
    (hle : ∀ n, ∀ᵐ a ∂volume, ‖F n a‖ ≤ bound a)
    (htends : ∀ᵐ a ∂volume, Tendsto (fun n => F n a) atTop (𝓝 (f a))) :
    Tendsto (fun n => ∫ a, F n a ∂volume) atTop (𝓝 (∫ a, f a ∂volume)) := by
  exact tendsto_integral_of_dominated_convergence bound hFm hbound hle htends
```

**ステップ①** — `exact tendsto_integral_of_dominated_convergence …` 直前の InfoView：

```text
F : ℕ → ℝ → ℝ
f : ℝ → ℝ
bound : ℝ → ℝ
hFm : ∀ (n : ℕ), AEStronglyMeasurable (F n) volume
hbound : Integrable bound volume
hle : ∀ (n : ℕ), ∀ᵐ (a : ℝ) ∂volume, ‖F n a‖ ≤ bound a
htends : ∀ᵐ (a : ℝ) ∂volume, Tendsto (fun n => F n a) atTop (nhds (f a))
⊢ Tendsto (fun n => ∫ (a : ℝ), F n a ∂volume) atTop (nhds (∫ (a : ℝ), f a ∂volume))
```

**ステップ②** — `exact tendsto_integral_of_dominated_convergence bound hFm hbound hle htends` 後：

```text
No goals
```

優関数 `bound` と、`hFm`・`hbound`・`hle`・`htends` の順の4つの証明で、積分列の収束が得られます。実数値関数について `AEMeasurable` を持っている場合は、上の補題のように `.aestronglyMeasurable` で変換できます。一般の値域でも条件なしでこの変換ができる、という意味ではありません。

:::message
💡 **優収束定理の「使い方」の本質**

優関数を見つけることに加えて、可測性、優関数の可積分性、支配不等式、AE 収束をそれぞれ証明します。実数から実数への連続関数なら `.aestronglyMeasurable` で可測性の条件を得られます。全点での支配や収束を証明できた場合は `ae_of_all` でAE の主張へ移せます。難しい条件は問題ごとに異なります。
:::

*図17-3：区間[0,1]上のsin(nπx)/n（n≥1）の例です。左・中央の横軸はx、右はnです。有限区間なので優関数1は可積分です。章末演習のsin(nx)/nとは周波数が異なります。*

## 17.5 三定理の使い分け ──── 対比表

| 定理 | 仮定 | 結論 | Lean の名前 |
|---|---|---|---|
| 単調収束定理 | 非負可測関数列・各点で単調増加 | $\int \sup_n f_n = \sup_n \int f_n$ | `lintegral_iSup` |
| Fatouの補題 | 非負可測関数列 | $\int \liminf \leq \liminf \int$ | `lintegral_liminf_le` |
| 優収束定理 | AE 強可測性・可積分な優関数によるAE 支配・AE 収束 | $\int \lim_n f_n = \lim_n \int f_n$ | `tendsto_integral_of_dominated_convergence` |

使い分けの指針を見ていきます。

- **単調収束定理**：非負の単調増加列が自然に現れるとき（例：可測関数の単関数近似の積分）
- **Fatouの補題**：非負列だが単調性も優関数もないとき（上界の証明に使う）
- **優収束定理**：可積分な優関数が見つかるとき（実際の解析学の計算で最もよく使う）

:::message
💡 **三定理の依存関係**

数学の標準的な証明では、単調収束定理からFatouの補題を導き、さらにFatouの補題を使って優収束定理を導くことができます。これは数学上の証明の道筋です。Mathlibの一般のBochner積分に対する実装の依存関係を、そのまま表したものではありません。
:::

## 17.6 まとめ ──── 第17章の全対応表と練習問題

数学とLeanの対応を表にまとめます。

| 数学の表現 | Lean の表現 |
|---|---|
| $f_n$ が単調増加 | `Monotone f`（関数列版）|
| 非負単調増加列の各点の極限 | `fun a => ⨆ n, f n a` |
| $\sup_n f_n$ | `⨆ n, f n` |
| $\liminf_{n \to \infty}$ | `liminf (·) atTop` |
| $\lim_{n \to \infty}$ | `Tendsto (·) atTop (nhds ·)` |
| 単調収束定理 | `lintegral_iSup` |
| Fatouの補題 | `lintegral_liminf_le` |
| 優収束定理 | `tendsto_integral_of_dominated_convergence` |
| 支配する関数（優関数）$g$ | `bound` + `Integrable bound μ` |

### 章末練習問題

**問題 17.1**　`lintegral_iSup` の仮定を `#check` で確認し、`Monotone f` が「関数列 $f : \mathbb{N} \to (\alpha \to \mathbb{R}_{\geq 0}^\infty)$ の単調性」を意味することを確かめてください。


:::details ヒントを見る

`#check @lintegral_iSup` でシグネチャを確認してください。`Monotone f` は `∀ m n, m ≤ n → f m ≤ f n` で、ここでは関数列の各点での単調性を要求します。
:::

:::details 解答を見る

```lean:完成例・確認コマンド
import Mathlib
open MeasureTheory Filter
open scoped ENNReal Topology

#check @lintegral_iSup

theorem monotone_sequence_iff {α : Type*} (f : ℕ → α → ℝ≥0∞) :
    Monotone f ↔ ∀ m n, m ≤ n → ∀ a, f m a ≤ f n a := by
  rfl
```

`Monotone f` は `∀ m n, m ≤ n → f m ≤ f n` で、ここでは $f_n : \alpha \to \mathbb{R}_{\geq 0}^\infty$ の単調性（点ごとの $f_m(a) \leq f_n(a)$）を要求します。
:::

:::details 別解を見る

```lean:完成例・確認コマンド
import Mathlib
open MeasureTheory Filter
open scoped ENNReal Topology
theorem increasing_constants {α : Type*} [MeasurableSpace α] (μ : Measure α) :
    (∫⁻ _a : α, ⨆ n : ℕ, (n : ℝ≥0∞) ∂μ) =
      ⨆ n : ℕ, (n : ℝ≥0∞) * μ Set.univ := by
  have hmono : Monotone (fun n : ℕ => fun _a : α => (n : ℝ≥0∞)) := by
    intro m n hmn a
    change (m : ℝ≥0∞) ≤ (n : ℝ≥0∞)
    exact_mod_cast hmn
  rw [lintegral_iSup (fun _ => measurable_const) hmono]
  simp
```

各項が定数関数である列 $f_n(a) = n$ を例に `lintegral_iSup` の適用方法を具体的に確認する別解です。
:::

**問題 17.2**　Fatouの補題で等号が成立しない反例（$f_n = \mathbf{1}_{[n, n+1)}$）を Lean で形式化してください。まず各項の積分を求め、次に各点収束と両辺の極限下限を確認します。


:::details ヒントを見る

$f_n = \mathbf{1}_{[n, n+1)}$ は各 $n$ で $\int f_n = 1$ ですが $f_n \to 0$ 各点収束するため $\int \liminf f_n = 0$ となります。`lintegral_indicator` と `Real.volume_Ico` が使えます。
:::

:::details 解答を見る

```lean:完成例・確認コマンド
import Mathlib
open MeasureTheory Filter
open scoped ENNReal Topology
noncomputable def movingIndicator (n : ℕ) : ℝ → ℝ≥0∞ :=
  (Set.Ico (n : ℝ) (n + 1)).indicator (fun _ => 1)

theorem movingIndicator_measurable (n : ℕ) : Measurable (movingIndicator n) :=
  measurable_const.indicator measurableSet_Ico

theorem movingIndicator_integral (n : ℕ) :
    (∫⁻ x : ℝ, movingIndicator n x) = 1 := by
  rw [movingIndicator, lintegral_indicator measurableSet_Ico]
  simp [Real.volume_Ico]
```

`movingIndicator` は非負拡張実数値の指示関数です。可測性と各項の積分が1であることを示しました。次のコードを続けて置き、各点収束と真の不等式まで証明します。
:::

:::details 解答の続き：各点収束と真の不等式

```lean:完成例・確認コマンド
-- 直前の movingIndicator と、その積分値の証明を引き継ぐ。
theorem movingIndicator_tendsto (x : ℝ) :
    Tendsto (fun n => movingIndicator n x) atTop (𝓝 0) := by
  have hn : ∀ᶠ n : ℕ in atTop, x < (n : ℝ) :=
    tendsto_natCast_atTop_atTop.eventually (eventually_gt_atTop x)
  apply tendsto_const_nhds.congr'
  filter_upwards [hn] with n hn
  symm
  exact Set.indicator_of_notMem (fun hx => (not_le_of_gt hn) hx.1) _

theorem fatou_strict :
    (∫⁻ x : ℝ, liminf (fun n => movingIndicator n x) atTop) <
      liminf (fun n => ∫⁻ x : ℝ, movingIndicator n x) atTop := by
  simp only [(movingIndicator_tendsto _).liminf_eq, movingIndicator_integral]
  simp
```

固定した $x$ に対し、十分大きな $n$ では $x<n$ となるため、指示関数の値は0です。`movingIndicator_tendsto` から各点の `liminf = 0` を得て、各項の積分が1であることと合わせます。最後の `fatou_strict` が $0<1$ に対応する完成した反例です。
:::

**問題 17.3**　$n\geq1$ で $F_n(x) = \sin(nx)/n$ とし、$F_0(x)=0$ と定めます。`tendsto_integral_of_dominated_convergence` を使って、$[0,1]$ 上の積分が0に収束することを示してください。優関数 $g\equiv1$ が使えます。Leanでは0による除算を0と定義しているため、下の式は $n=0$ でもこの定義と一致します。


:::details ヒントを見る

`tendsto_integral_of_dominated_convergence` の引数を確認してください。優関数 $g \equiv 1$ は `[0,1]` 上で可積分です（制限測度上の `integrable_const`）。各点収束 $\frac{\sin(nx)}{n} \to 0$ が必要です。
:::

:::details 解答を見る

```lean:完成例・確認コマンド
import Mathlib
open MeasureTheory Filter
open scoped ENNReal Topology
noncomputable def sineSequence (n : ℕ) (x : ℝ) : ℝ :=
  Real.sin ((n : ℝ) * x) / (n : ℝ)

theorem sineSequence_zero (x : ℝ) : sineSequence 0 x = 0 := by
  simp [sineSequence]

theorem sineSequence_norm_le (n : ℕ) (x : ℝ) :
    ‖sineSequence n x‖ ≤ 1 / (n : ℝ) := by
  simp only [sineSequence, Real.norm_eq_abs, abs_div, Nat.abs_cast]
  exact div_le_div_of_nonneg_right (Real.abs_sin_le_one _) (Nat.cast_nonneg n)

theorem sineSequence_norm_le_one (n : ℕ) (x : ℝ) :
    ‖sineSequence n x‖ ≤ 1 := by
  cases n with
  | zero => norm_num [sineSequence]
  | succ n =>
    apply (sineSequence_norm_le (n + 1) x).trans
    apply (div_le_one (by positivity : (0 : ℝ) < (↑(n + 1) : ℝ))).2
    exact_mod_cast Nat.succ_le_succ (Nat.zero_le n)

theorem sineSequence_tendsto (x : ℝ) :
    Tendsto (fun n => sineSequence n x) atTop (𝓝 0) :=
  squeeze_zero_norm (fun n => sineSequence_norm_le n x)
    tendsto_one_div_atTop_nhds_zero_nat

theorem sineSequence_integral_tendsto :
    Tendsto (fun n => ∫ x, sineSequence n x ∂volume.restrict (Set.Icc 0 1))
      atTop (𝓝 0) := by
  have hFm (n : ℕ) : AEStronglyMeasurable (sineSequence n)
      (volume.restrict (Set.Icc 0 1)) :=
    ((Real.continuous_sin.comp (continuous_const.mul continuous_id)).div_const _).aestronglyMeasurable
  have h := tendsto_integral_of_dominated_convergence (μ := volume.restrict (Set.Icc 0 1))
    (F := sineSequence) (f := fun _ => 0) (fun _ => 1) hFm (integrable_const 1)
    (fun n => ae_of_all _ (sineSequence_norm_le_one n))
    (ae_of_all _ sineSequence_tendsto)
  simpa using h
```

まず $\lVert F_n(x)\rVert\leq1/n$ を示し、はさみうちで各点収束を得ています。数学の $1/n$ の評価は $n\geq1$ で読み、$n=0$ では `sineSequence_zero` により値0を確認できます。Leanでは $1/0=0$ なので、評価補題を全自然数について書けます。

支配条件 $\lVert F_n(x)\rVert\leq1$ は $n=0$ を別に処理します。連続性、有限測度上の定数関数の可積分性、支配条件、収束の4つが揃ったところで、優収束定理を適用します。最後の `simpa` は極限関数0の積分を0へ書き換えます。定数1が可積分なのは、ここでは有限な制限測度を使っているためです。実数全体のLebesgue測度では定数1は可積分ではありません。
:::

:::message
**📝 第17章 つまずきポイントQ&A**

**Q1. 優収束定理の「優関数」はどう指定しますか？**
→ `tendsto_integral_of_dominated_convergence bound hFm hbound hle htends` の `bound : α → ℝ` が優関数です。`hbound : Integrable bound μ` は可積分性、`hle : ∀ n, ∀ᵐ x ∂μ, ‖F n x‖ ≤ bound x` は支配不等式の証明です。

**Q2. `tendsto_integral_of_dominated_convergence` の引数の順番は？**
→ 優関数 `bound` の後に、`hFm`（各項のAE 強可測性）、`hbound`（優関数の可積分性）、`hle`（AE 支配）、`htends`（AE 収束）の順で渡します。結論は積分列の収束です。

**Q3. 単調収束定理を使う条件（単調性の証明）はどう書きますか？**
→ `lintegral_iSup` では `intro m n hmn a` と進め、`f m a ≤ f n a` を示します。AE版の `lintegral_iSup'` では、`∀ n, AEMeasurable (f n) μ` と `∀ᵐ x ∂μ, Monotone (fun n => f n x)` を渡します。

**Q4. Fatou の補題と逆 Fatou の違いは？**
→ 非負可測関数列に対するFatouは `∫ liminf fₙ ≤ liminf ∫ fₙ` です。例えば非負の実数値可測関数列に可積分な優関数 $g$ があり、すべての $n$ で $0≤f_n≤g$ a.e. なら、逆向きの評価 `limsup ∫ fₙ ≤ ∫ limsup fₙ` も得られます。逆Fatouには、このような追加の支配条件が必要です。

**Q5. `ae_of_all` と `Filter.Eventually.of_forall` の関係は？**
→ `ae_of_all μ h : ∀ᵐ x ∂μ, P x` は「全点で成立 → a.e. 成立」です。`Filter.Eventually.of_forall` も同じ意味で、`∀ x, P x` から `∀ᵐ x ∂μ, P x` を導きます。
:::
