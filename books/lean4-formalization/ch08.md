本章の最終ゴールは2つです。

```lean:完成例・確認コマンド
import Mathlib

open Filter Topology

-- 連続性の合成は位相空間で成り立つ
theorem composition_goal (X Y Z : Type*)
    [TopologicalSpace X] [TopologicalSpace Y] [TopologicalSpace Z]
    (f : X → Y) (g : Y → Z) (hf : Continuous f) (hg : Continuous g) :
    Continuous (g ∘ f) := hg.comp hf

-- 非空なコンパクト集合上の実数値連続関数は最大値を達成する
theorem maximum_goal (f : ℝ → ℝ) (hf : Continuous f) (s : Set ℝ)
    (hs : IsCompact s) (hne : s.Nonempty) :
    ∃ x ∈ s, ∀ y ∈ s, f y ≤ f x := by
  obtain ⟨x, hx, hmax⟩ := hs.exists_isMaxOn hne hf.continuousOn
  exact ⟨x, hx, fun y hy => hmax hy⟩
```

どちらの定理も `dist` を直接使いません。第2の例では、`hs` がコンパクト性、`hne` が非空性を与えます。ここではコンパクト性を仮定しており、Heine–Borelの定理はまだ使っていません。

## 8.1 位相空間という抽象化 ──── 距離を持たない「開集合の世界」

### なぜ距離を捨てるのか

[第7章](ch07)では「開集合とは各点の周りに開球が入る集合」と定義しました。しかしこの定義は距離関数 `dist` に依存しています。

開集合から構造を指定する例には、次のものがあります。これらすべてが距離化できないという意味ではありません。

- **離散位相**：すべての部分集合が開。この位相は、異なる2点の距離を1、同じ点の距離を0とする離散距離から得られます。
- **Zariski 位相**：多項式の族の共通零点集合を閉集合とする位相。
- **弱位相**：連続線形汎関数の値を通じて収束を調べる位相。[第10章](ch10)で扱うノルム位相とは区別します。
- **商位相**：同値類への射影を通じて開集合を定める位相。

距離化できない簡単な例は、2点以上の集合に入れた密着位相（開集合が空集合と全体集合だけ）です。異なる2点を分離できないため、距離から得られる位相にはなりません。

これらすべてを統一的に扱うために、「開集合の族」だけを公理にとる **位相空間（topological space）** を導入します。

距離空間からは擬距離空間の構造が得られ、擬距離空間からは位相が得られます。次の表で、利用できる構造を整理します。

| 持っている構造 | 利用できる構造・性質 |
|---|---|
| `MetricSpace X` | 擬距離構造に加え、距離0なら同一点という性質 |
| `PseudoMetricSpace X` | 対応する一様構造・位相 |
| `UniformSpace X` | 対応する位相、Cauchy性や一様連続性を扱う枠組み |
| `TopologicalSpace X` | 開集合・近傍・連続性を扱う枠組み |

この表は利用できる構造の関係を示します。Mathlibの`extends`の直接の親子関係を省略せず列挙したものではありません。

### 数学の定義：位相の公理

集合 $X$ 上の **位相（topology）** $\mathcal{T}$ とは、$X$ の部分集合族（「開集合族」）であって次の3条件を満たすものです。

$$
\text{（O1）}\quad \emptyset \in \mathcal{T} \quad \text{かつ} \quad X \in \mathcal{T}
$$

$$
\text{（O2）}\quad \{ U_\lambda \}_{\lambda \in \Lambda} \subseteq \mathcal{T} \Rightarrow \bigcup_{\lambda \in \Lambda} U_\lambda \in \mathcal{T} \quad \text{（任意の合併）}
$$

$$
\text{（O3）}\quad U_1, U_2 \in \mathcal{T} \Rightarrow U_1 \cap U_2 \in \mathcal{T} \quad \text{（有限交叉）}
$$

### Leanの実装：`TopologicalSpace` 型クラス

```lean:完成例・確認コマンド
import Mathlib

open Filter Topology

-- 定義を表示し、実際のフィールドを調べる
#print TopologicalSpace
-- IsOpen・isOpen_univ・isOpen_inter・isOpen_sUnion を持つ。
-- isOpen_empty はフィールドではなく、任意合併から導く補題。
```

:::message
 **💡 Mathlibの美しい設計：`isOpen_empty` は「公理」ではなく「定理」**

数学のテキストでは O1 を「$\emptyset \in \mathcal{T}$ かつ $X \in \mathcal{T}$」と2つセットで書くことが多いです。しかし Mathlib の実際のフィールドは `TopologicalSpace.isOpen_univ`（$X$ が開）だけで、**`isOpen_empty`（$\emptyset$ が開）は補題として導出されています**。

なぜ $\emptyset$ の開性が導出できるのでしょうか。答えは O2（任意合併）にあります。

$$
\emptyset = \bigcup_{S \in \emptyset} S \quad \text{（空の集合族の合併は空集合）}
$$

空の族 $\emptyset$（どの集合も含まない族）の合併を取ると $\emptyset$ になります。`isOpen_sUnion` に「空の族」を渡せば、$\emptyset$ に属する集合はひとつもないので前提「$\forall t \in \emptyset,\; \mathtt{IsOpen}\; t$」は vacuously true（空虚に真）となり、結論 `IsOpen (⋃₀ ∅) = IsOpen ∅` が得られます。

```lean:完成例・確認コマンド
import Mathlib

open Filter Topology

theorem empty_open_from_union (α : Type*) [TopologicalSpace α] :
    IsOpen (∅ : Set α) := by
  have : (∅ : Set α) = ⋃₀ (∅ : Set (Set α)) := by simp
  rw [this]
  exact isOpen_sUnion (fun t ht => ht.elim)
```

公理を最小化しつつ、他の性質を最大限に導出する——この設計は Mathlib 全体を貫く哲学です。
:::

数学の公理とLeanのフィールド・補題の対応を表にまとめます。フィールドの正式名は `TopologicalSpace.isOpen_univ` などです。根名前空間の `isOpen_univ` や `IsOpen.inter` は、その公理を使いやすく取り出す補題です。

| 数学の公理 | 数式 | Lean での扱い | 種別 |
|-----------|------|--------------|------|
| O1（空集合が開） | $\emptyset \in \mathcal{T}$ | `isOpen_empty` | **補題**（`isOpen_sUnion` から導出） |
| O1（全体集合が開） | $X \in \mathcal{T}$ | `TopologicalSpace.isOpen_univ` / `isOpen_univ` | **公理フィールドとその補題** |
| O2（任意合併） | $\bigcup_\lambda U_\lambda \in \mathcal{T}$ | `TopologicalSpace.isOpen_sUnion` / `isOpen_sUnion` | **公理フィールドとその補題** |
| O3（有限交叉） | $U_1 \cap U_2 \in \mathcal{T}$ | `TopologicalSpace.isOpen_inter` / `IsOpen.inter` | **公理フィールドとその補題** |

```lean:完成例・確認コマンド
import Mathlib

open Filter Topology

#check @isOpen_univ
#check @isOpen_empty
#check @IsOpen.inter
#check @IsOpen.union     -- 2つの開集合の合併
#check @isOpen_iUnion    -- 添字付きの任意合併
#check @isOpen_sUnion    -- 集合族の任意合併
```

:::message
**💡 距離空間に備わる位相構造**

`[MetricSpace X]` が与えられると、型クラス機構を通じて `TopologicalSpace X` も利用できます。`MetricSpace` と `TopologicalSpace` は別の型クラスです。

```lean:完成例・確認コマンド

#check (inferInstance : TopologicalSpace ℝ)
#check (fun (X : Type) [MetricSpace X] => (inferInstance : TopologicalSpace X))
```

この仕組みにより、距離空間でも位相空間についての定理を使えます。ただし、[第7章](ch07)で距離の性質を使った証明まで、任意の位相空間へ一般化されるわけではありません。
:::

## 8.2 連続性の位相的定義 ──── 開集合の逆像

距離空間では連続性をε-δで定義しました。位相空間では距離がないため、別の定義が必要です。

### 数学の定義：開集合の逆像による連続性

関数 $f : X \to Y$（位相空間間の写像）が **連続（continuous）** であるとは：

$$
\forall \text{ 開集合 } V \subseteq Y,\; f^{-1}(V) \subseteq X \text{ も開集合}
$$

この定義は距離を一切使いません。「出力側の開集合の逆像が入力側でも開集合」——これが連続性の本質です。

$$
f\text{ が連続}\quad\Longleftrightarrow\quad
\forall V\subseteq Y,\quad V\text{ が開集合}\ \Longrightarrow\ f^{-1}(V)\text{ が開集合}.
$$

### Leanの実装：`Continuous` と `isOpen_preimage`

```lean:完成例・確認コマンド
import Mathlib

open Filter Topology

#check @Continuous
#check @continuous_def
-- Continuous f ↔ ∀ s, IsOpen s → IsOpen (f ⁻¹' s)
```

数学の定義がそのまま `continuous_def` に対応しています。

| 数学の表現 | Lean の表現 |
|-----------|------------|
| $f$ は連続 | `Continuous f` |
| $\forall$ 開集合 $V \subseteq Y,\; f^{-1}(V)$ は開集合 | `∀ s, IsOpen s → IsOpen (f ⁻¹' s)` |
| 上の同値 | `continuous_def` |

### 点での連続性と全域での連続性をつなぐ

ここで連続性の表現を整理します。表の上2行は**1点での連続性**、最後の行は**定義域のすべての点での連続性**です。

| 定義の種類 | 数学の表現 | Lean の表現 | 文脈 |
|-----------|-----------|------------|------|
| ε-δ定義 | $\forall \varepsilon > 0, \exists \delta > 0, \ldots$ | `Metric.continuousAt_iff` | 距離空間 |
| フィルター定義 | `Tendsto f (nhds a) (nhds (f a))` | `ContinuousAt f a`（定義そのもの） | 位相空間 |
| 開集合の逆像 | $f^{-1}(\text{開集合})$ は開集合 | `continuous_def` | 位相空間 |

```lean:完成例・確認コマンド
import Mathlib

open Filter Topology

#check @Metric.continuousAt_iff
#check @continuous_iff_continuousAt
#check @continuous_def

theorem continuous_at_every_point (X Y : Type*)
    [TopologicalSpace X] [TopologicalSpace Y] (f : X → Y) :
    (∀ x, ContinuousAt f x) ↔ ∀ s, IsOpen s → IsOpen (f ⁻¹' s) := by
  rw [← continuous_iff_continuousAt, ← continuous_def]
```

:::message
**💡 なぜ3つの定義が必要なのか**

- **ε-δ** は計算に強い。具体的な $\delta$ を構成するときに使います。
- **フィルター** は合成・極限の代数に強い。`hf.comp hg` のような一行証明が可能です。
- **開集合の逆像** は全域での連続性を扱うのに便利です。フィルターによる定義も、開集合の逆像による定義も、任意の位相空間で使えます。

`continuous_iff_continuousAt` が `Continuous f ↔ ∀ x, ContinuousAt f x` を与えます。距離空間では各点で `Metric.continuousAt_iff` を使い、全域の連続性には「すべての点で」という量化を加えてください。
:::

## 8.3 `nhds` の真の姿 ──── 第6章の伏線回収

[第6章](ch06)を思い出してください。あのとき著者は `nhds a` を「点 $a$ の近傍フィルター」と紹介し、距離空間では `Metric.ball a ε` の族が基底になると説明しました。

ここでは、近傍の記述を一般の位相空間で確認します。

> 「`nhds a` そのものはどう**定義**されているのか？」

[第7章](ch07)の `Metric.nhds_basis_ball` は、近傍を開球で調べるための特徴付けでした。`nhds` 自体は、開集合を使って距離に依存せず定義できます。

### 数学の定義：開集合のインフィマムとして

位相空間 $(X, \mathcal{T})$ の点 $a$ に対して、近傍フィルター $\mathcal{N}(a)$ は**主フィルター（principal filter）のインフィマム**として定義されます。

集合 $s \subseteq X$ に対して、その**主フィルター** $\mathcal{P}(s)$ とは「$s$ を含むすべての集合の族」です。

$$
\mathcal{P}(s) = \{ U \subseteq X \mid s \subseteq U \}
$$

これを使うと、$a$ の近傍フィルターは：

$$
\mathcal{N}(a) = \inf \left\{ \mathcal{P}(s) \;\middle|\; a \in s \text{ かつ } s \in \mathcal{T} \right\}
$$

ここで下限は**最大の下界**です。各主フィルターより細かいフィルターのうち、順序で最大のもの、つまり共通の細分の中で最も粗いものを取ります。

![点xを含む開集合を使って近傍フィルターを構成する模式図](/images/vol2/fig-08.png)
*図8-1：図中の「開集合のみ」は構成に使う開近傍を指します。`nhds x`の要素には、それらを含む開でない集合も含まれます。円や入れ子は模式的で、距離や全開近傍の入れ子関係を仮定しません。*

### Leanの実装：`⨅` と `𝓟`

```lean:完成例・確認コマンド
import Mathlib

open Filter Topology

#check Filter.principal
#check nhds_def

-- 下界である：各開近傍の主フィルターより細かい。
theorem nhds_le_open_principal (a : ℝ) (s : Set ℝ) (ha : a ∈ s) (hs : IsOpen s) :
    nhds a ≤ Filter.principal s := by
  rw [nhds_def]
  exact iInf_le_of_le s (iInf_le_of_le ⟨ha, hs⟩ le_rfl)

-- 最大の下界である：どの共通の下界も nhds a 以下になる。
theorem le_nhds_from_open_principals (f : Filter ℝ) (a : ℝ)
    (h : ∀ s, a ∈ s → IsOpen s → f ≤ Filter.principal s) : f ≤ nhds a := by
  rw [nhds_def]
  exact le_iInf fun s => le_iInf fun hs => h s hs.1 hs.2
```

`⨅` は**インフィマム**（最大の下界）を表す記号です。フィルターでは「細かい ≤ 粗い」という順序なので、上の2つの証明は、`nhds a` が各候補以下であり、共通の下界 `f` は必ず `nhds a` 以下になることを確認しています。最小元 `⊥` と下限を混同しないでください。

```lean:完成例・確認コマンド
import Mathlib

open Filter Topology

theorem neighborhood_infimum (a : ℝ) :
    nhds a = ⨅ s ∈ {s : Set ℝ | a ∈ s ∧ IsOpen s}, Filter.principal s := by
  exact nhds_def a
```

**ステップ①：ゴール確認**

```text
a : ℝ
⊢ nhds a = ⨅ s ∈ {s | a ∈ s ∧ IsOpen s}, 𝓟 s
```

**ステップ②：`nhds_def` で一発**

```text
-- No goals ✓
```

`nhds_def` は「`nhds` の定義を展開する」補題です。定義そのものなので `exact` で即座に閉じます。

### 数学↔Lean の対応表

| 数学の表現 | Lean の表現 |
|-----------|------------|
| 主フィルター $\mathcal{P}(s) = \{U \mid s \subseteq U\}$ | `Filter.principal s`（略記：`𝓟 s`） |
| $a$ を含む開集合の族 $\{s \mid a \in s,\; s \in \mathcal{T}\}$ | `{s \| a ∈ s ∧ IsOpen s}` |
| インフィマム $\inf$ | `⨅`（完備束の `iInf`） |
| 近傍フィルター $\mathcal{N}(a) = \inf \{\mathcal{P}(s) \mid a \in s,\; s \text{ 開}\}$ | `nhds a = ⨅ s ∈ {s \| a ∈ s ∧ IsOpen s}, 𝓟 s` |
| 距離空間での基底 $\{B(a,\varepsilon) \mid \varepsilon > 0\}$ | `Metric.nhds_basis_ball`（派生した性質） |

:::message
**💡 この定義が「位相空間の力」の核心**

[第7章](ch07)まで `nhds a` は「距離 `dist` を通じて開球で定義される」ものだと思っていたかもしれません。しかし `nhds_def` を見ると、`dist` は一切登場しません。**`IsOpen` という概念さえあれば `nhds` が定義できる**のです。

これが「位相空間の力」です。距離のない空間（Zariski 位相、有限位相空間、弱位相など）でも、`IsOpen` を定めた瞬間に `nhds` が自動的に決まり、`ContinuousAt`・`Filter.Tendsto`・収束の概念がすべて使えるようになります。

[第6章](ch06)で著者が `nhds` を「望遠鏡のレンズ」と呼んだのは、「$a$ を含む開集合たちを通して見る方向」を意味していました。その比喩は今、`⨅ s ∈ {s | a ∈ s ∧ IsOpen s}, 𝓟 s` という精密な定義として回収されました。
:::

:::message alert
**⚠️ 距離空間では「基底」が便利なだけ**

距離空間 `MetricSpace` の場合、`nhds_def` の右辺（すべての開集合のインフィマム）と `Metric.nhds_basis_ball`（開球の族）は同じフィルターを定義しています。距離空間では開球が開集合の基底をなすからです。

距離を指定していない位相空間では、開球を使うことはできません。それでも `nhds_def` や開近傍による基底を使えます。[第10章](ch10)の $\ell^2$ はノルムから得られる距離・位相で扱います。
:::

## 8.4 合成定理の証明 ──── InfoViewでのゴールの変化

本章の最初のゴール、「連続関数の合成は連続」を証明します。

### 証明の方針

ゴール：$f : X \to Y$、$g : Y \to Z$ がともに連続 $\Rightarrow$ $g \circ f : X \to Z$ も連続

開集合逆像を使った証明の骨格：

$V \subseteq Z$ を任意の開集合とする。$g$ が連続なので $g^{-1}(V)$ は $Y$ の開集合。$f$ が連続なので $(g \circ f)^{-1}(V) = f^{-1}(g^{-1}(V))$ は $X$ の開集合。∎

### 証明を順に組み立てる

以下の5つのLeanブロックは、宣言・`rw`・`intro`・`simp only`・最後の `apply` と `exact` の順に、同じファイルへ連結してください。

```lean:完成例・確認コマンド
import Mathlib

open Filter Topology

theorem composition_by_preimages (X Y Z : Type*)
    [TopologicalSpace X] [TopologicalSpace Y] [TopologicalSpace Z]
    (f : X → Y) (g : Y → Z) (hf : Continuous f) (hg : Continuous g) :
    Continuous (g ∘ f) := by
```

**ステップ①：最初のゴール**

```text
X Y Z : Type*
inst✝¹ : TopologicalSpace X
inst✝  : TopologicalSpace Y
inst✝² : TopologicalSpace Z
f : X → Y
g : Y → Z
hf : Continuous f
hg : Continuous g
⊢ Continuous (g ∘ f)
```

**ステップ②：`continuous_def` でゴールを開集合の言葉に展開**

```lean:断片
  rw [continuous_def]
```

```text
⊢ ∀ s, IsOpen s → IsOpen ((g ∘ f) ⁻¹' s)
```

**ステップ③：任意の開集合 `s` と `hs` を導入**

```lean:断片
  intro s hs
```

```text
s : Set Z
hs : IsOpen s
⊢ IsOpen ((g ∘ f) ⁻¹' s)
```

**ステップ④：逆像の合成を展開**

```lean:断片
  simp only [Set.preimage_comp]
```

```text
⊢ IsOpen (f ⁻¹' (g ⁻¹' s))
```

`(g ∘ f) ⁻¹' s = f ⁻¹' (g ⁻¹' s)` という逆像の合成則が適用されました。

**ステップ⑤：`hf` で逆像の開性に帰着し、`hg` で閉じる**

```lean:断片
  apply hf.isOpen_preimage (g ⁻¹' s)
  exact hg.isOpen_preimage s hs
```

```text
-- No goals ✓
```

:::message
**💡 `isOpen_preimage` の役割**

`Continuous.isOpen_preimage` は「$f$ が連続かつ $s$ が開集合 $\Rightarrow$ $f^{-1}(s)$ も開集合」という補題です。

```lean:完成例・確認コマンド
import Mathlib

open Filter Topology

#check Continuous.isOpen_preimage
-- hf.isOpen_preimage s hs のように、集合 s も明示的に渡す。
```

これが `continuous_def` の「$\Rightarrow$」方向を直接表現したものです。
:::

## 8.5 コンパクト集合 ──── 有限性の抽象化

### 数学の定義：コンパクト集合

位相空間 $X$ の部分集合 $K$ が **コンパクト（compact）** であるとは：

$$
\forall \text{ 開被覆 } \{ U_\lambda \}_{\lambda \in \Lambda},\; K \subseteq \bigcup_\lambda U_\lambda
\Rightarrow \exists \text{ 有限部分集合 } \Lambda_0 \subseteq \Lambda,\; K \subseteq \bigcup_{\lambda \in \Lambda_0} U_\lambda
$$

「任意の開被覆から有限部分被覆が取れる」——これがコンパクト性の定義です。

開被覆は、各 $U_\lambda$ が開集合で、族全体の合併が $K$ を含むという条件です。コンパクト性では、どの開被覆からも有限個を選び、なお $K$ 全体を覆えることを要求します。ある一つの有限な被覆が存在するだけでは、コンパクト性は示せません。

### Leanの実装：`IsCompact`

```lean:完成例・確認コマンド
import Mathlib

open Filter Topology

#print IsCompact
#check IsCompact.elim_finite_subcover
-- IsCompact の定義はフィルターによる。
-- elim_finite_subcover は、開被覆から有限部分被覆を取り出す定理。
```

`#print IsCompact` は、Mathlibの内部定義がフィルターを使うことを示します。開被覆による数学の定義との対応は `IsCompact.elim_finite_subcover` で利用できます。

| 数学の表現 | Lean の表現 |
|-----------|------------|
| $K$ はコンパクト | `IsCompact K` |
| 各 $U_i$ が開集合 | `hopen : ∀ i, IsOpen (U i)` |
| 族全体で $K$ を覆う | `hcover : K ⊆ ⋃ i, U i` |
| 有限部分被覆が存在 | `∃ t : Finset ι, K ⊆ ⋃ i ∈ t, U i` |
| コンパクト性と開被覆から有限部分被覆を取り出す | `IsCompact.elim_finite_subcover` |

開被覆として使うには、`hopen` と `hcover` の両方が必要です。`hK : IsCompact K` と併せて、有限部分被覆を取り出す定理へ渡します。

### ℝ上のコンパクト集合：Heine-Borel定理

$\mathbb{R}$ ではコンパクト性は「有界閉集合」と同値です。

```lean:完成例・確認コマンド
import Mathlib

open Filter Topology

-- 実数の閉区間はコンパクト
theorem compact_interval (a b : ℝ) : IsCompact (Set.Icc a b) := isCompact_Icc

-- 距離空間で ProperSpace を仮定した Heine–Borel 型の同値
theorem compactIffClosedBounded {X : Type*} [MetricSpace X] [ProperSpace X]
    (s : Set X) : IsCompact s ↔ IsClosed s ∧ Bornology.IsBounded s :=
  Metric.isCompact_iff_isClosed_bounded

#check IsCompact.isSeqCompact
```

:::message
**💡 `ProperSpace`：閉球がコンパクトな空間**

固定したMathlibでは、閉球がコンパクトであることを **`ProperSpace`** という型クラスで表します。`HeineBorelSpace` という名前の型クラスはありません。

```lean:完成例・確認コマンド
import Mathlib

open Filter Topology

#check ProperSpace
#check (inferInstance : ProperSpace ℝ)
#check (inferInstance : ProperSpace (EuclideanSpace ℝ (Fin 3)))
#check @Metric.isCompact_iff_isClosed_bounded
```

`ProperSpace` の定義は擬距離空間にも使えます。一方、`Metric.isCompact_iff_isClosed_bounded` は `[PseudoMetricSpace X]`、`[ProperSpace X]` に加え、コンパクト集合が閉となるための `[T2Space X]` を要求します。上の完成例では `[MetricSpace X]` からこの分離条件が得られます。

$\mathbb{R}$・$\mathbb{R}^n$・$\mathbb{C}$ には `ProperSpace` のインスタンスがあります。[第10章](ch10)の $\ell^2$ では単位閉球が非コンパクトであることを証明し、`ProperSpace` が成り立たないと結論します。**`inferInstance` の失敗だけから、この否定は導けません。** 探索失敗には、インポートや仮定、登録されたインスタンスの不足という可能性もあります。
:::

:::message alert
**⚠️ 任意の距離空間で使えるわけではない**

「有界閉集合 ↔ コンパクト」は $\mathbb{R}^n$ に限らず、`ProperSpace` である距離空間で成立します。ただし、一般の距離空間や完備距離空間へ無条件に広げることはできません。例えば、実ノルム空間では、この性質と有限次元性が同値です。

[第10章](ch10)で扱う $\ell^2$（無限次元）では単位閉球

$$
\bar{B}(0, 1) = \{ (x_n)_{n \in \mathbb{N}} \mid \sum_{n=0}^\infty x_n^2 \leq 1 \}
$$

が**有界かつ閉**であるにもかかわらず、**コンパクトではありません**。これが無限次元の「壁」の一つです。
:::

## 8.7 コンパクト集合上の連続関数の最大値定理

本章の最終ゴール②、「コンパクト集合上の連続関数は最大値を持つ」を形式化します。

### 数学の定理

**空でない**コンパクト集合 $K$ 上の実数値連続関数は、最大値と最小値を達成します。空集合もコンパクトですが、その中に極値を達成する点はありません。

$$
\exists x^* \in K,\; \forall y \in K,\; f(y) \leq f(x^*)
$$

### Mathlibでの形式化

```lean:完成例・確認コマンド
import Mathlib

open Filter Topology

#check IsCompact.exists_isMaxOn
-- hs : IsCompact s, hne : s.Nonempty, hf : ContinuousOn f s から
-- ∃ x ∈ s, IsMaxOn f s x を得る。

theorem no_maximizer_in_empty (f : ℝ → ℝ) :
    ¬ ∃ x ∈ (∅ : Set ℝ), ∀ y ∈ (∅ : Set ℝ), f y ≤ f x := by
  simp
```

以下の4つのLeanブロックを順に連結します。まず区間の非空性 `hne` と関数の連続性 `hcont` を用意し、`obtain` で得られた最大点を返します。

```lean:完成例・確認コマンド
import Mathlib

open Filter Topology

theorem square_maximum :
    ∃ x ∈ Set.Icc (0 : ℝ) 1, ∀ y ∈ Set.Icc (0 : ℝ) 1, y ^ 2 ≤ x ^ 2 := by
```

**ステップ①：ゴール確認**

```text
⊢ ∃ x ∈ Icc 0 1, ∀ y ∈ Icc 0 1, y ^ 2 ≤ x ^ 2
```

**ステップ②：非空性を補助命題として用意**

```lean:断片
  have hne : (Set.Icc (0 : ℝ) 1).Nonempty := by
```

```text
-- have の中で証明する補助ゴール
⊢ (Set.Icc 0 1).Nonempty
```

**ステップ③：空でないことの証明**

```lean:断片
    exact Set.nonempty_Icc.mpr (by norm_num)
```

```text
-- 非空性の証明が終わり、元のゴールへ戻る
hne : (Set.Icc 0 1).Nonempty
⊢ ∃ x ∈ Set.Icc 0 1, ∀ y ∈ Set.Icc 0 1, y ^ 2 ≤ x ^ 2
```

**ステップ④：連続性を示し、最大点を返す**

```lean:断片
  have hcont : ContinuousOn (fun x : ℝ => x ^ 2) (Set.Icc 0 1) :=
    (continuous_pow 2).continuousOn
  obtain ⟨x, hx, hmax⟩ := isCompact_Icc.exists_isMaxOn hne hcont
  exact ⟨x, hx, fun y hy => hmax hy⟩
```

```text
-- No goals ✓
```

`continuous_pow 2` から区間上の連続性を得ます。最後の行は `hmax : IsMaxOn ...` を使います。`IsMaxOn` の点 `y` は暗黙引数なので、`fun y hy => hmax hy` により本文の明示的な量化へ変換します。

:::message
**💡 `Continuous` と `ContinuousOn` の違い**

| 概念 | Lean | 意味 |
|------|------|------|
| 全域連続 | `Continuous f` | 定義域全体で連続 |
| 集合上で連続 | `ContinuousOn f s` | 集合 `s` に制限して連続 |
| 点での連続 | `ContinuousAt f x` | 1点 `x` で連続 |

`Continuous f → ContinuousOn f s` は `Continuous.continuousOn` で変換できます。
:::

## 8.8 本章のまとめ：「距離を捨てた先」の景色

本章で学んだことを整理します。

| 概念 | 数学の記法 | Lean の記法 |
|------|-----------|------------|
| 位相空間 | $(X, \mathcal{T})$ | `[TopologicalSpace X]` |
| 開集合 | $U \in \mathcal{T}$ | `IsOpen U` |
| 閉集合 | $U^c \in \mathcal{T}$ | `IsClosed U` |
| 任意合併が開（公理） | $\bigcup_\lambda U_\lambda \in \mathcal{T}$ | `isOpen_sUnion`（公理から取り出す補題） |
| 有限交叉が開（公理） | $U \cap V \in \mathcal{T}$ | `TopologicalSpace.isOpen_inter` / `IsOpen.inter` |
| 空集合が開（導出） | $\emptyset \in \mathcal{T}$ | `isOpen_empty`（補題） |
| 全体集合が開（公理） | $X \in \mathcal{T}$ | `isOpen_univ`（公理から取り出す補題） |
| 連続（開集合逆像） | $f^{-1}(\text{開}) = \text{開}$ | `continuous_def` |
| 内部 | $\mathrm{int}(S)$ | `interior S` |
| 閉包 | $\overline{S}$ | `closure S` |
| コンパクト（開被覆） | 有限部分被覆が存在 | `IsCompact` |
| 極値定理 | $\exists x^*, \forall y, f(y) \leq f(x^*)$ | `IsCompact.exists_isMaxOn` |
| 閉区間（$\mathbb{R}$） | $[a,b]$ はコンパクト | `isCompact_Icc` |
| Heine-Borel（`ProperSpace` の距離空間） | 閉 ∧ 有界 ↔ コンパクト | `Metric.isCompact_iff_isClosed_bounded` |

**本章の核心的洞察：**

> 距離空間 `MetricSpace` は位相空間 `TopologicalSpace` の特殊ケースです。距離から導かれる位相を使えば、$\mathbb{R}$ や $\mathbb{R}^n$ で「距離の言葉」と「位相の言葉」を自由に行き来できます。

:::message alert
 **💀 次の崖：完備性という「見えない壁」**

$\ell^2$ でも、有限集合などのコンパクト集合には極値定理を使えます。ただし、閉かつ有界という条件だけではコンパクト性を得られません。

Cauchy列に極限が存在することを保証するには、何が必要でしょうか。

答えは **完備性（completeness）** です。「すべての Cauchy 列が収束する」という性質が、無限次元解析の生命線です。次章ではこの `CompleteSpace` 型クラスと、Cauchy 列の形式化に踏み込みます。そこで初めて、[第11章](ch11)のラスボス「Banachの不動点定理」の前提が揃います。
:::

:::message
**🔗 [第9章](ch09)への伏線**

本章で「コンパクト集合 = 任意の開被覆から有限部分被覆が取れる集合」を定義しました。

次元にかかわらず、コンパクト距離空間は完備です。逆は $\mathbb{R}$ でも成り立ちません。実数全体は完備ですがコンパクトではないからです。距離空間でコンパクト性と同値なのは「完備かつ全有界」であり、全有界性は通常の有界性より強い条件です。

特に `Cauchy`（Cauchy フィルター）と `CompleteSpace`（完備空間）の定義を、[第7章](ch07)の `Filter.Tendsto` と同じ「フィルターの言語」で統一的に理解します。
:::

 **問4（発展：Heine-Borel の限界）**

$\ell^2$ 空間の単位閉球がコンパクトでないことを「感じる」ための例を構成してください。次の数列 $e_n = (\delta_{nk})_{k \in \mathbb{N}}$（$n$ 番目だけ 1、それ以外は 0 の数列）について：

$$
\|e_m - e_n\|_{\ell^2} = \sqrt{2} \quad (m \neq n)
$$

この等式を確認し、$\{e_n\}$ から収束部分列が取れないことを直感的に説明してください。（Leanでのコードは[第10章](ch10)で扱います。）

:::details ヒントを見る

$\|e_m - e_n\|^2 = \sum_{k} |\delta_{mk} - \delta_{nk}|^2$ を計算します。$m \neq n$ の場合、$k=m$ と $k=n$ の2項が 1 になり残りは 0 です。
:::

:::details 解答を見る

**計算：** $m \neq n$ のとき

$$
\|e_m - e_n\|^2 = \sum_{k=0}^{\infty} |\delta_{mk} - \delta_{nk}|^2
= |1 - 0|^2 + |0 - 1|^2 + \sum_{k \neq m, n} |0|^2 = 1 + 1 = 2
$$

したがって $\|e_m - e_n\|_{\ell^2} = \sqrt{2}$。

**収束部分列が取れない理由：** 数列 $(e_n)$ の異なる添字の2項の距離が $\sqrt{2}$ で一定なので、どの部分列を取っても隣り合う項の距離が $\sqrt{2} > 0$ のまま変わりません。収束列は Cauchy 列なので、$N$ 以降の項が $\varepsilon = \sqrt{2}/2$ の帯に入る $N$ が存在するはずですが、異なる $m,n\geq N$ を選べば $\|e_m - e_n\| = \sqrt{2} > \varepsilon$ となり、Cauchy 条件が満たせません。

これが「$\ell^2$ の閉単位球はコンパクトでない」ことの直感的証明です（Heine-Borel の限界）。
:::

:::details 別解を見る

コンパクト性の別の特徴付けを使った論法：

距離空間では、集合のコンパクト性は「その集合内のすべての点列が、集合内に極限を持つ収束部分列を持つ」ことと同値です。$(e_n)$ はこれを満たさない点列の例を与えています。有限次元 $\mathbb{R}^n$ では Bolzano-Weierstrass 定理が保証しますが、無限次元ではこれが崩壊します。
:::

**📝 第8章 つまずきポイントQ&A**

**Q1. `TopologicalSpace` は `MetricSpace` より難しそうで怖いのですが…**
→ 距離を使わずに「開集合の公理」だけで連続性を定義する、という発想の転換が肝です。距離空間から位相構造は得られますが、一般の位相空間には距離がありません。距離の計算を使う定理には、引き続きその仮定が必要です。

**Q2. `IsOpen` と `isOpen_univ` など `IsOpen` 系のレンマが多すぎて混乱します**
→ `IsOpen` 系は「特定の集合が開かどうか」を述べます。`isOpen_univ`（全体集合は開）、`IsOpen.inter`（開集合の有限交叉は開）、`IsOpen.union`（2つの開集合の合併は開）を区別しましょう。任意合併には `isOpen_iUnion` または `isOpen_sUnion` を使います。

**Q3. `ContinuousAt` と `Continuous` の違いは？**
→ `Continuous f` は「すべての点で連続」、`ContinuousAt f x` は「点 `x` で連続」です。`Continuous f ↔ ∀ x, ContinuousAt f x` が成り立ちます（`continuous_iff_continuousAt`）。

**Q4. コンパクト集合はなぜ重要なのですか？**
→ 非空なコンパクト集合上の実数値連続関数は最大値・最小値を達成します。コンパクト距離空間から距離空間への連続写像は一様連続です。一般の位相空間で一様連続性を述べるには、一様構造も必要です。「有界閉集合 = コンパクト」はユークリッド空間などの `ProperSpace` で成り立ちます。一般の位相空間では距離による有界性自体を仮定なしに使えません。

**Q5. `[TopologicalSpace X]` と書くだけで距離なしの定理が使えるのはなぜですか？**
→ 定理の引数に `[TopologicalSpace X]` と書くことは、`X` の位相構造を仮定として受け取るという意味です。呼び出し側では既存のインスタンスを自動で渡せますが、任意の型に目的の位相が自動で決まるわけではありません。
:::

> **著者より**：「距離のない空間で連続性を語る」という発想は、初めて聞くと奇妙に感じます。しかし Lean に `[TopologicalSpace X]` と書いた瞬間に「距離なしで連続性の定理が使える」ことを型チェッカーが保証してくれる——この体験は、抽象数学の正当性を文字通り「コンパイル」して確かめる感覚です。
