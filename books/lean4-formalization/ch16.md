## 16.1 `lintegral`（`∫⁻`）とは何か ──── 非負可測関数の積分

### 数学の定義：非負可測関数の Lebesgue 積分

非負可測関数 $f : X \to [0, +\infty]$ の積分を次で定義します。

$$
\int f \, d\mu := \sup \left\{ \int \phi \, d\mu \;\middle|\; \phi \text{ は単関数},\; 0 \leq \phi \leq f \right\}
$$

単関数近似定理（第15章）により、$\phi_n \nearrow f$ となる単関数列 $\{\phi_n\}$ が存在し、

$$
\int f \, d\mu = \lim_{n \to \infty} \int \phi_n \, d\mu = \sup_n \int \phi_n \, d\mu
$$

が成り立ちます。第17章では、この関係を一般化する単調収束定理の仮定と適用を確認します。

### Lean の実装：`MeasureTheory.lintegral`

Mathlibの `lintegral` は、可測性を仮定しない任意の `ℝ≥0∞` 値関数にも定義されます。その定義は下にある単関数全体の積分の上限で、一般には「下積分」としての性質を持ちます。通常の非負Lebesgue積分の加法性や近似定理を使う際は、それぞれの可測性の仮定を確認します。

```lean
import Mathlib
open MeasureTheory
open scoped ENNReal

theorem lintegral_notation (μ : Measure ℝ) (f : ℝ → ℝ≥0∞) :
    (∫⁻ x, f x ∂μ) = lintegral μ f := rfl

-- 全ての下側の単関数について上限を取る定義。
theorem lintegral_definition (μ : Measure ℝ) (f : ℝ → ℝ≥0∞) :
    (∫⁻ x, f x ∂μ) =
      ⨆ (g : SimpleFunc ℝ ℝ≥0∞) (_ : (g : ℝ → ℝ≥0∞) ≤ f), g.lintegral μ := by
  rw [lintegral]

theorem constant_lintegral (c : ℝ≥0∞) (μ : Measure ℝ) :
    (∫⁻ _x, c ∂μ) = c * μ Set.univ := lintegral_const c

theorem indicator_lintegral (A : Set ℝ) (hA : MeasurableSet A) (μ : Measure ℝ) :
    (∫⁻ x, A.indicator (fun _ => (1 : ℝ≥0∞)) x ∂μ) = μ A := by
  rw [lintegral_indicator hA]
  simp
```

:::message alert
💀 **`lintegral` の値域は `ℝ≥0∞`（ENNReal）**

`lintegral` の返り値の型は `ℝ≥0∞`（`ENNReal`）です。これは $[0, +\infty]$ を表す型で、発散した場合は `⊤`（トップ）を返します。`⊤ + 1 = ⊤`、`⊤ * 0 = 0` など、通常の実数とは異なる演算規則があります。`ℝ` への変換には `ENNReal.toReal` を使えますが、`⊤` の場合は `0` に変換されるので注意が必要です。
:::

![lintegral と integral の型の違いを示す対比図。左側に「lintegral：非負関数 f : α → ℝ≥0∞ → 値 ℝ≥0∞（⊤まで許容）」、右側に「integral：符号付き関数 f : α → E → 値 E（可積分なら有限、非可積分なら 0 を返す）」を並べる。ENNReal の数直線（0 から ⊤）と実数直線（−∞ から +∞）の対比も示す](/images/vol3/fig-09.png)

## 16.2 `integral`（Bochner積分、`∫`）とは何か

### 数学の概念：可積分関数と Bochner 積分

実数値関数 $f$ がLebesgue可積分のとき、その積分は、正部分と負部分の有限な非負積分の差で説明できます。$f$ の正部分 $f^+ = \max(f, 0)$ と負部分 $f^- = \max(-f, 0)$ に分けます。

$$
\int f \, d\mu := \int f^+ \, d\mu - \int f^- \, d\mu
$$

通常の有限なLebesgue積分として扱うには、両方の積分が有限であること、すなわち $\int |f| \,d\mu<\infty$ を要求します。一般のバナッハ空間値関数にはこの正部分・負部分は定義できません。Bochner積分は単関数による近似から構成され、AE 強可測性とノルム積分の有限性が可積分性の条件になります。

### Lean の実装：`integral`

```lean
import Mathlib
open MeasureTheory
open scoped ENNReal

#print integral
#check @integral_undef
```

:::message alert
💥 **`integral` は可積分でない関数に対して `0` を返す**

`∫ x, f x ∂μ` は、`f` が可積分でない場合でも記述できます。値は規約で **`0`** になります。これは型エラーや例外を表す値ではなく、積分という関数を全ての入力に定義するための取り決めです。

次の例では、実数全体での定数1がLebesgue可積分でないことを証明してから、`integral_undef` を使います。同じ定数を `ℝ≥0∞` 値で非負積分すると `∞` になります。

```lean
import Mathlib
open MeasureTheory
open scoped ENNReal

-- Lebesgue測度で実数全体を考えると、定数1は可積分でない。
theorem one_not_integrable : ¬ Integrable (fun _ : ℝ => (1 : ℝ)) volume := by
  simp [integrable_const_iff, isFiniteMeasure_iff]

theorem one_integral_undef : (∫ _x : ℝ, (1 : ℝ)) = 0 :=
  integral_undef one_not_integrable

-- 同じ定数をENNReal値で非負積分すると、値は無限大。
theorem one_lintegral_infinite : (∫⁻ _x : ℝ, (1 : ℝ≥0∞)) = ⊤ := by
  simp
```

この例の0を通常の有限な積分値と解釈することはできません。有限なBochner積分として扱うときは、`Integrable f μ` を証明するか仮定に置きます。ただし、積分に関する全ての定理がこの仮定を要求するわけではありません。
:::

`#print integral` では、値域の完備性による場合分けも見られます。積分式自体は実ノルム空間で書けますが、通常のBochner積分を扱う舞台は完備な実ノルム空間です。固定版では値域が完備でない場合にも規約値0を返します。本章の実数値の例では `CompleteSpace ℝ` が用意されています。

## 16.3 `Integrable` の条件 ──── `HasFiniteIntegral` と可測性

### 数学の条件：可積分性

実数値可測関数 $f$ について、可積分性は $\int |f| \,d\mu<\infty$ で判定できます。一般の値域も扱うLeanの定義では、次の可測性の条件を含みます。

### Lean の実装：`Integrable`

```lean
import Mathlib
open MeasureTheory
open scoped ENNReal

#print Integrable
#print HasFiniteIntegral
-- 定義の要約（型の引数・型クラスなどは省略）：
-- Integrable f μ = AEStronglyMeasurable f μ ∧ HasFiniteIntegral f μ
-- HasFiniteIntegral f μ = ((∫⁻ a, ‖f a‖ₑ ∂μ) < ∞)
-- ‖f a‖ₑ は ℝ≥0∞ に値を取るノルム。
```

`Integrable f μ` の正体は2つの条件の連言です。

1. `AEStronglyMeasurable f μ`：$f$ がAE 強可測（強可測な関数とAE で等しい）
2. `HasFiniteIntegral f μ`：$\int \|f\| \, d\mu < \infty$（`lintegral` が `⊤` にならない）

```lean
import Mathlib
open MeasureTheory

theorem constant_integrable (c : ℝ) (μ : Measure ℝ) [IsFiniteMeasure μ] :
    Integrable (fun _ => c) μ :=
  integrable_const c

theorem sine_integrable_on_interval :
    IntegrableOn Real.sin (Set.Icc 0 (2 * Real.pi)) volume :=
  Real.continuous_sin.continuousOn.integrableOn_Icc
```

## 16.4 リーマン積分との比較 ──── ディリクレ関数の例

ディリクレ関数を見ていきます。

$$
f(x) = \begin{cases} 1 & (x \in \mathbb{Q}) \\ 0 & (x \notin \mathbb{Q}) \end{cases}
$$

**リーマン積分の場合**：$[0,1]$ の任意の分割 $P$ に対して上リーマン和は1、下リーマン和は0となり、リーマン可積分ではありません。

**Lebesgue 積分の場合**：$\mathbb{Q}$ は測度ゼロ（$\lambda(\mathbb{Q}) = 0$）なので、

$$
\int_0^1 f \, d\lambda = 1 \cdot \lambda(\mathbb{Q} \cap [0,1]) + 0 \cdot \lambda(\mathbb{Q}^c \cap [0,1]) = 0
$$

```lean
import Mathlib
open MeasureTheory

-- 実数値のディリクレ関数。有理数の像で1、それ以外で0。
noncomputable def dirichlet : ℝ → ℝ :=
  (Set.range ((↑) : ℚ → ℝ)).indicator (fun _ => 1)

theorem rationals_volume_zero : volume (Set.range ((↑) : ℚ → ℝ)) = 0 :=
  (Set.countable_range ((↑) : ℚ → ℝ)).measure_zero volume

theorem dirichlet_ae_zero : dirichlet =ᵐ[volume] (fun _ => 0) := by
  filter_upwards [(Set.countable_range ((↑) : ℚ → ℝ)).ae_notMem volume] with x hx
  simp [dirichlet, Set.indicator_of_notMem hx]

theorem dirichlet_integrable : Integrable dirichlet volume :=
  (integrable_zero ℝ ℝ volume).congr dirichlet_ae_zero.symm

theorem dirichlet_integral : (∫ x : ℝ, dirichlet x) = 0 := by
  calc
    (∫ x : ℝ, dirichlet x) = ∫ _x : ℝ, (0 : ℝ) := integral_congr_ae dirichlet_ae_zero
    _ = 0 := integral_zero _ _
```

ディリクレ関数は全実数上でもAE で0なので、Lebesgue可積分で、その積分は0です。上では「可積分である」と「積分が0である」を別々に証明しました。章末では $[0,1]$ への制限についても確認します。この0は、非可積分な関数に `integral_undef` を適用して得る規約値とは理由が異なります。

## 16.5 `lintegral` と `integral` の関係 ──── 実況中継

### 関係の全体像

`lintegral` と `integral` は別物ですが、非負関数の場合は変換公式でつながります。

```lean
import Mathlib
open MeasureTheory

#check @integral_eq_lintegral_of_nonneg_ae
-- 仮定と結論を実数値関数に限定して確認する。
theorem nonnegative_integral (f : ℝ → ℝ) (μ : Measure ℝ)
    (hf : 0 ≤ᵐ[μ] f) (hfm : AEStronglyMeasurable f μ) :
    (∫ x, f x ∂μ) = (∫⁻ x, ENNReal.ofReal (f x) ∂μ).toReal :=
  integral_eq_lintegral_of_nonneg_ae hf hfm
```

`ENNReal.toReal` は `∞` に対して0を返します。この式を通常の有限な積分の変換として使う場合は、可積分性も確認します。

数学とLeanの対応を表にまとめます（本節分）。

| 状況 | 使うべき記法 |
|------|------------|
| $f \geq 0$、値域 $[0, +\infty]$ で扱いたい | `∫⁻ x, f x ∂μ`（`lintegral`） |
| $f$ が符号付き、バナッハ空間値 | `∫ x, f x ∂μ`（`integral`） |
| 非負 `integral` を `lintegral` で評価 | `integral_eq_lintegral_of_nonneg_ae` |

### 実況中継①：`integral_add` で積分の加法性を確認する

可積分関数の範囲で、積分が加法性を持つことを確認します。非可積分な関数まで含む全ての関数上で、加法的であるという主張ではありません。

```lean
import Mathlib
open MeasureTheory
open scoped ENNReal

theorem integral_add_demo (f g : ℝ → ℝ)
    (hf : Integrable f volume) (hg : Integrable g volume) :
    (∫ x, (f x + g x) ∂volume) = (∫ x, f x ∂volume) + ∫ x, g x ∂volume := by
  exact integral_add hf hg
```

**ステップ①** — `exact integral_add hf hg` 直前の InfoView：

```text
f g : ℝ → ℝ
hf : Integrable f volume
hg : Integrable g volume
⊢ ∫ (x : ℝ), f x + g x = (∫ (x : ℝ), f x) + ∫ (x : ℝ), g x
```

**ステップ②** — `exact integral_add hf hg` 後：

```text
No goals
```

`integral_add hf hg` の型が `∫ x, (f x + g x) ∂volume = ∫ x, f x ∂volume + ∫ x, g x ∂volume` と推論されてゴールと一致します。No goals ✓

:::message alert
💥 **`integral_add` は `Integrable` 仮定が必須**

`integral_add` の適用には `hf : Integrable f μ` と `hg : Integrable g μ` の証明が必要です。積分式を書くだけなら可積分性は要求されませんが、この補題には両方の証明を渡します。仮定を外すと加法性は一般には保証されません。非可積分な関数が現れる全ての例で、等式が必ず偽になるという意味でもありません。非負積分の `lintegral_add_left` は、別の条件として一方の関数の可測性を要求します。
:::

### 実況中継②：`integral_smul` で積分のスカラー倍を確認する

```lean
import Mathlib
open MeasureTheory
open scoped ENNReal

theorem integral_smul_demo (r : ℝ) (f : ℝ → ℝ) (μ : Measure ℝ) :
    (∫ x, r • f x ∂μ) = r • ∫ x, f x ∂μ := by
  exact integral_smul r f
```

**ステップ①** — `integral_smul r f` 直前の InfoView：

```text
r : ℝ
f : ℝ → ℝ
μ : Measure ℝ
⊢ ∫ (x : ℝ), r • f x ∂μ = r • ∫ (x : ℝ), f x ∂μ
```

**ステップ②** — `integral_smul r f` 後：

```text
No goals
```

この実数スカラーの例では、`Integrable f μ` の仮定は不要です。`r = 0` なら両辺は0です。`r ≠ 0` ならスカラー倍によって可積分性は変わらないため、非可積分の場合は両側の積分が規約値0になります。一般のスカラー環に無条件で広げられるわけではなく、`integral_smul` はノルム付き斜体や作用の整合性などの型クラスを要求します。

### `norm_integral_le_integral_norm` の確認

```lean
import Mathlib
open MeasureTheory
open scoped ENNReal

theorem norm_integral_bound (f : ℝ → ℝ) (μ : Measure ℝ) :
    ‖∫ x, f x ∂μ‖ ≤ ∫ x, ‖f x‖ ∂μ :=
  norm_integral_le_integral_norm f
```

この不等式は「積分のノルムは、ノルムの積分以下」という三角不等式の積分版です。`f` が非可積分なら左辺は規約により0です。一方、右辺は非負であるため不等式が保たれます。`f` の可測性が不足していてもノルムは可積分という場合があるので、右辺まで必ず0になるとは限りません。

## 16.6 まとめ ──── 第16章の全対応表と練習問題

数学とLeanの対応を表にまとめます。

| 数学の表現 | Lean の表現 |
|---|---|
| $\int^- f \, d\mu$（非負積分） | `∫⁻ x, f x ∂μ`（`lintegral`） |
| 値域 $[0, +\infty]$ | `ℝ≥0∞`（`ENNReal`） |
| 発散 $= +\infty$ | `⊤ : ℝ≥0∞` |
| $\int f \, d\mu$（Bochner 積分） | `∫ x, f x ∂μ`（`integral`） |
| $f$ が可積分（$\int |f| < \infty$） | `Integrable f μ` |
| $\int |f| < \infty$ の部分 | `HasFiniteIntegral f μ` |
| $\int (f + g) = \int f + \int g$ | `integral_add` |
| $\int r \cdot f = r \cdot \int f$ | `integral_smul` |
| 非負 integral と lintegral の一致 | `integral_eq_lintegral_of_nonneg_ae` |
| $\|\int f\| \leq \int \|f\|$ | `norm_integral_le_integral_norm` |

### 章末練習問題

**問題 16.1**　`lintegral_const` を使って `∫⁻ _x : ℝ, (3 : ℝ≥0∞) ∂volume` の値（`⊤` になるはず）を確認し、なぜ `⊤` になるかを説明してください。


<details>
<summary>💡 ヒントを見る</summary>

`lintegral_const` のシグネチャは `∫⁻ _, c ∂μ = c * μ Set.univ` です。`ℝ` の全体 `Set.univ` の Lebesgue 測度は `⊤`（`Real.volume_univ`）なので積が `⊤` になります。

</details>

<details>
<summary>✅ 解答を見る</summary>

```lean
import Mathlib
open MeasureTheory
open scoped ENNReal

theorem const_three_lintegral_top : (∫⁻ _x : ℝ, (3 : ℝ≥0∞) ∂volume) = ⊤ := by
  rw [lintegral_const, Real.volume_univ]
  simp
```

`lintegral_const` で `3 * volume Set.univ` に変換し、`Real.volume_univ : volume (Set.univ : Set ℝ) = ⊤` から `3 * ⊤ = ⊤` が成立します（$\mathbb{R}$ は無限大の測度を持つ）。

</details>

<details>
<summary>🔄 別解を見る</summary>

```lean
import Mathlib
open MeasureTheory
open scoped ENNReal

theorem const_three_lintegral_top_alt : (∫⁻ _x : ℝ, (3 : ℝ≥0∞) ∂volume) = ⊤ := by
  calc
    (∫⁻ _x : ℝ, (3 : ℝ≥0∞) ∂volume) = 3 * volume (Set.univ : Set ℝ) := lintegral_const 3
    _ = ⊤ := by simp
```

`calc` で、定数積分の公式を適用する段階と、`3 * ∞ = ∞` を計算する段階を分けています。

</details>

**問題 16.2**　`Integrable` の定義を確認し、$f(x) = e^{-x}$（$x \geq 0$）が $[0, \infty)$ 上で可積分であることを、既存の定理を使って証明してください。


<details>
<summary>💡 ヒントを見る</summary>

`Integrable f μ` は `AEStronglyMeasurable f μ ∧ HasFiniteIntegral f μ` と展開されます。`integrableOn_exp_neg_Ioi` は開半直線上での可積分性を与えます。`integrableOn_Ici_iff_integrableOn_Ioi` で端点を含む場合へ移します。

</details>

<details>
<summary>✅ 解答を見る</summary>

```lean
import Mathlib
open MeasureTheory

-- 開半直線での既存定理を、端点0を含む半直線へ移す。
theorem exp_neg_integrable :
    Integrable (fun x : ℝ => Real.exp (-x)) (volume.restrict (Set.Ici 0)) := by
  exact Iff.mpr integrableOn_Ici_iff_integrableOn_Ioi (integrableOn_exp_neg_Ioi 0)
```

Lebesgue測度では一点の測度が0なので、端点0を加えても可積分性は変わりません。これは可積分性の証明で、積分値 $\int_0^\infty e^{-x} dx=1$ の計算とは別です。

</details>

<details>
<summary>✅ 補足：可積分性を2つの条件に分ける</summary>

```lean

-- 前の exp_neg_integrable を使い、Integrable の2条件を確認する。
theorem exp_neg_integrable_parts :
    Integrable (fun x : ℝ => Real.exp (-x)) (volume.restrict (Set.Ici 0)) := by
  refine ⟨?_, ?_⟩
  · exact (Real.continuous_exp.comp continuous_id.neg).aestronglyMeasurable
  · exact exp_neg_integrable.hasFiniteIntegral
```

`Integrable` の第1成分は、連続性から得られるAE 強可測性です。第2成分は前の解答 `exp_neg_integrable` の `.hasFiniteIntegral` から取り出しています。これは前の解答を使った定義の確認であり、有限性を独立に再証明する別解ではありません。

</details>

**問題 16.3**　`integral_undef` の型を `#check` で確認し、可積分でない関数への `integral` の挙動を確かめてください。


<details>
<summary>💡 ヒントを見る</summary>

`integral_undef` は `¬Integrable f μ → ∫ x, f x ∂μ = 0` を述べます。`#check @integral_undef` で型を確認してください。

</details>

<details>
<summary>✅ 解答を見る</summary>

```lean
import Mathlib
open MeasureTheory

#check @integral_undef
-- 非可積分性を仮定した場合の規約値。
theorem integral_of_not_integrable (f : ℝ → ℝ) (hf : ¬Integrable f volume) :
    (∫ x, f x) = 0 :=
  integral_undef hf
```

`integral_undef` は、非可積分性の証明から規約値0の等式を与えます。この例は非可積分性を仮定しています。16.2節の定数1の例では、非可積分性そのものも証明しました。

</details>

<summary>✅ 対比：ディリクレ関数は可積分</summary>

```lean
-- 16.4節の dirichlet と dirichlet_ae_zero を引き継ぐ。
-- [0,1] への制限でも、可積分性と積分値0の両方を証明する。
theorem dirichlet_on_unit_interval :
    Integrable dirichlet (volume.restrict (Set.Icc 0 1)) ∧
      (∫ x, dirichlet x ∂volume.restrict (Set.Icc 0 1)) = 0 := by
  have h : dirichlet =ᵐ[volume.restrict (Set.Icc 0 1)] (fun _ => 0) :=
    ae_restrict_of_ae dirichlet_ae_zero
  constructor
  · exact (integrable_zero ℝ ℝ _).congr h.symm
  · calc
      (∫ x, dirichlet x ∂volume.restrict (Set.Icc 0 1)) =
          ∫ _x : ℝ, (0 : ℝ) ∂volume.restrict (Set.Icc 0 1) := integral_congr_ae h
      _ = 0 := integral_zero _ _
```

これは非可積分な関数との対比です。ディリクレ関数はLebesgue可積分なので `integral_undef` を使う前提が成り立ちません。AE で0に等しいことから可積分性を移し、`integral_congr_ae` で積分値を計算します。

</details>

**📝 第16章 つまずきポイントQ&A**

**Q1. `lintegral`（`∫⁻`）と `integral`（`∫`）はどちらを使えばよいですか？**
→ 非負関数や測度論的な計算（収束定理など）では `∫⁻`、符号付き関数やBanach空間値関数では `∫` を使います。`∫⁻` の値域は `ℝ≥0∞`（`⊤` を含む）、`∫` の値域は関数と同じ型です。

**Q2. ENNReal で `∞ + a = ∞` になるケースはどう扱いますか？**
→ `ENNReal.top_add`（`⊤ + a = ⊤`）や `ENNReal.add_top`（`a + ⊤ = ⊤`）を使い、`simp` で簡約できます。乗法では `0 * ∞ = 0` である一方、正の値と `∞` の積は `∞` です。有限な実数の計算と同じ規則をそのまま適用しないようにします。

**Q3. `lintegral_mono` と `lintegral_mono_ae` の仮定はどう違いますか？**
→ `lintegral_mono` は各点での不等式 `f ≤ g`、`lintegral_mono_ae` はa.e.不等式 `∀ᵐ x ∂μ, f x ≤ g x` を使います。全ての点で成り立つ不等式からa.e.不等式へ移すには `Filter.Eventually.of_forall` を使えます。

**Q4. `lintegral_add_left` の可測性条件はどこで必要ですか？**
→ `lintegral_add_left (hf : Measurable f) g` で `f` の可測性が必要です。`g` の可測性はこの補題では不要です。任意の非可測関数同士に、同じ加法性を無条件で適用できるという意味ではありません。AE可測性を使う場合は `lintegral_add_left'` の型を確認します。

**Q5. `∫⁻`（lintegral）と `∫`（integral）の記法の使い分けを教えてください**
→ `∫⁻ x, f x ∂μ` は lintegral（非負値）、`∫ x, f x ∂μ` は Bochner integral（符号付き）です。`∂μ` を省略すると `volume`（デフォルト測度）が使われます。
:::
