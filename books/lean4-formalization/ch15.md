# 第15章：単関数と積分の足場 〜`SimpleFunc`を解剖する〜

以下の完成例は、各ブロックのimportと宣言を含めて、それぞれ別のLeanファイルで実行できます。`open scoped ENNReal` は `ℝ≥0∞` の記法を使うための指定です。

## 15.0 本章のゴール ──── ゴール逆算型アプローチ

本章の終着点を見ていきます。最終的に証明したいのは次の命題です。

```lean:完成例・確認コマンド
import Mathlib
open MeasureTheory
open scoped ENNReal

#check @SimpleFunc.lintegral
#check @SimpleFunc.const
#check @SimpleFunc.const_lintegral

-- 定数3を、[0,1]に制限したLebesgue測度で積分する。
theorem simple_const_unit_integral :
    (SimpleFunc.const ℝ (3 : ℝ≥0∞)).lintegral (volume.restrict (Set.Icc 0 1)) = 3 := by
  rw [SimpleFunc.const_lintegral]
  norm_num [Measure.restrict_apply_univ, Real.volume_Icc]
```

単関数は「有限個の値しかとらない可測関数」です。複雑な関数の積分を、まずこの単純な関数で近似してから極限を取るという戦略が Lebesgue 積分の本質です。章の後半では `SimpleFunc.eapprox` を使って一般の非負可測関数への橋渡しを見ていきます。

## 15.1 なぜ単関数から始めるか ──── 「積分の足場」

積分の定義を「直感的に」作ろうとするとき、最も簡単な場合から始めるのが得策です。

$$
\phi(x) = \sum_{i=1}^n c_i \cdot \mathbf{1}_{A_i}(x)
$$

ここで $A_i$ は互いに素な可測集合、$c_i \geq 0$ は定数です。この形の関数（**単関数**）に対しては、積分の値は明白です。

$$
\int \phi \, d\mu = \sum_{i=1}^n c_i \cdot \mu(A_i)
$$

これは「各集合上の値 × 集合の測度」の和です。リーマン和では定義域を小区間に分けますが、ここでは同じ値をとる点を集めた可測集合を使えます。これらの集合は区間である必要がありません。

一般の非負可測関数は、単調増加する単関数列で近似できます。

$$
0 \leq \phi_1 \leq \phi_2 \leq \cdots \leq f,\quad \phi_n(x) \nearrow f(x)
$$

この近似列の積分の極限として $\int f \, d\mu$ を定義するのが Lebesgue 積分の方針です。

## 15.2 単関数の数学的定義 ──── 「有限個の値をとる可測関数」

### 数学の定義：単関数（simple function）

可測空間 $(X, \mathcal{M})$ 上の関数 $\phi : X \to [0, +\infty)$ が**単関数**であるとは、

1. $\phi$ は可測関数
2. $\phi$ の値域が有限集合

の両方を満たすことをいいます。

値域が有限集合 $\{c_1, c_2, \ldots, c_n\}$ であれば、$A_i := \phi^{-1}(\{c_i\})$ は可測集合で（可測関数だから）、

$$
\phi = \sum_{i=1}^n c_i \cdot \mathbf{1}_{A_i}
$$

と書けます。一点集合がボレル可測なので、可測性から各逆像の可測性を得ています。

ここではまず有限の非負実数値で説明しました。Mathlibの `SimpleFunc α ℝ≥0∞` では、有限個の値の一つとして `∞` を含むこともできます。`eapprox` が返す近似単関数の値は、各段階では全て有限です。

## 15.3 `SimpleFunc α β` を解剖します

### Lean の実装：`MeasureTheory.SimpleFunc`

```lean:完成例・確認コマンド
import Mathlib
open MeasureTheory
open scoped ENNReal

#print SimpleFunc
#check @SimpleFunc.measurableSet_fiber
#check @SimpleFunc.finite_range
#check @SimpleFunc.measurable
```

出力を簡略化すると、

```text
structure MeasureTheory.SimpleFunc (α : Type u_1)
    [MeasurableSpace α] (β : Type u_2) where
  toFun : α → β
  measurableSet_fiber' : ∀ x, MeasurableSet (toFun ⁻¹' {x})
  finite_range' : (Set.range toFun).Finite
```

`SimpleFunc` は、関数本体、各値の逆像の可測性、値域の有限性を持ちます。可測性・有限性のフィールド名の末尾には `'` が付きます。利用者向けの `SimpleFunc.measurableSet_fiber` と `SimpleFunc.finite_range` は、これらを取り出す補題です。

構造体自体は値域 `β` の可測構造を要求しません。値域にどの可測構造を入れても `.measurable` で可測性が得られます。一方、通常の可測関数の可測性から各値の逆像が可測だと結論するには、値域の一点集合が可測であることが必要です。`ℝ≥0∞` の標準のボレル構造ではこの条件を満たします。

```lean:完成例・確認コマンド
import Mathlib
open MeasureTheory
open scoped ENNReal

noncomputable def myConst : SimpleFunc ℝ ℝ≥0∞ := SimpleFunc.const ℝ 2

-- #evalではなく、等式として関数値を確認する。
theorem myConst_at_zero : myConst 0 = 2 := rfl

#check @SimpleFunc.piecewise
#check @SimpleFunc.restrict
#check @SimpleFunc.coe_restrict
```

`myConst_at_zero` は、定義から値が2であることを `rfl` で証明しています。`#eval` による実行可能な数値計算とは区別します。`ℝ≥0∞` や古典的な集合の構成は、一般にそのまま実行できるデータではありません。

## 15.4 単関数の積分の定義 ──── $\sum c_i \cdot \mu(A_i)$

### 数学の定義：単関数の積分

$\phi = \sum_{i=1}^n c_i \cdot \mathbf{1}_{A_i}$ （$A_i$ は互いに素な可測集合）に対して、

$$
\int \phi \, d\mu := \sum_{i=1}^n c_i \cdot \mu(A_i) \in [0, +\infty]
$$

積分の値域は `ℝ≥0∞`（= `ENNReal`、拡張非負実数）で、$+\infty$ も許します。ここでは `0 * ∞ = 0` と定めるため、値0の部分が無限測度でも寄与は0です。

:::message
💡 **なぜ `ENNReal` なのか**

測度の値が $+\infty$ になり得るので（$\mu(\mathbb{R}) = +\infty$ など）、積分値も $+\infty$ になり得ます。`ENNReal` は $[0, +\infty]$ を型として表現します。後の `integral`（Bochner積分）は実数値や一般のBanach空間値を扱います。Leanでは非可積分な関数にも規約値0を割り当てるため、通常の有限な積分として扱うには可積分性の確認が必要です。
:::

## 15.5 `SimpleFunc.lintegral` の実装 ──── 実況中継

### Lean の実装：単関数の積分

`SimpleFunc.lintegral` は、値域を有限集合 `Finset` として表した `φ.range` 上の加重和です。`Set.range φ` は集合、`φ.range` は `Finset` であることを区別してください。以下では、その定義を等式として確認します。

```lean:完成例・確認コマンド
import Mathlib
open MeasureTheory
open scoped ENNReal

#check @SimpleFunc.lintegral
#check @SimpleFunc.const_lintegral

theorem simple_lintegral_definition {α : Type*} [MeasurableSpace α]
    (φ : SimpleFunc α ℝ≥0∞) (μ : Measure α) :
    φ.lintegral μ = ∑ c ∈ φ.range, c * μ (φ ⁻¹' {c}) := rfl
```

### 実況中継：`[0,1]` 上の定数 3 の積分が `3` になることを証明する

証明の構造を俯瞰すると、「単関数の積分を定数×全体測度に展開」→「制限測度の全体 = 元の測度の s」→「`Real.volume_Icc` で数値化」という 3 ステップです。

```lean:完成例・確認コマンド
import Mathlib
open MeasureTheory
open scoped ENNReal

theorem simple_const_unit_integral_steps :
    (SimpleFunc.const ℝ (3 : ℝ≥0∞)).lintegral (volume.restrict (Set.Icc 0 1)) = 3 := by
  rw [SimpleFunc.const_lintegral]
  rw [Measure.restrict_apply_univ]
  rw [Real.volume_Icc]
  norm_num
```

**ステップ①** — `rw [SimpleFunc.const_lintegral]` 直前の InfoView：

```text
⊢ (SimpleFunc.const ℝ 3).lintegral (volume.restrict (Set.Icc 0 1)) = 3
```

**ステップ②** — `rw [SimpleFunc.const_lintegral]` 後：

```text
⊢ 3 * (volume.restrict (Set.Icc 0 1)) Set.univ = 3
```

`SimpleFunc.const_lintegral` が「定数単関数の積分 = 定数 × 全体の測度」に書き換えました。一般の関数に対する `MeasureTheory.lintegral_const` とは名前の順序が異なります。

**ステップ③** — `rw [Measure.restrict_apply_univ]` 後：

```text
⊢ 3 * volume (Set.Icc 0 1) = 3
```

制限測度 `μ.restrict s` の `Set.univ` への適用が `μ s` に変換されました。

**ステップ④** — `rw [Real.volume_Icc]` 後：

```text
⊢ 3 * ENNReal.ofReal (1 - 0) = 3
```

Lebesgue 測度の具体値 `λ([0,1]) = ENNReal.ofReal 1` が代入されました。

**ステップ⑤** — `norm_num` 後：

```text
No goals
```

`norm_num` が `1 - 0 = 1`、`ENNReal.ofReal 1 = 1`、`3 * 1 = 3` を処理して証明を閉じます。

## 15.6 非負可測関数を単関数で近似する ──── `SimpleFunc.eapprox`

### 数学の定理：単関数近似定理

非負可測関数 $f : X \to [0, +\infty]$ に対して、単調増加単関数列 $\{\phi_n\}$ が存在して

$$
0 \leq \phi_1 \leq \phi_2 \leq \cdots,\quad \lim_{n \to \infty} \phi_n(x) = f(x) \quad (\forall x)
$$

が成り立ちます。

### Lean の実装：`SimpleFunc.eapprox`

```lean:完成例・確認コマンド
import Mathlib
open MeasureTheory
open scoped ENNReal

#print SimpleFunc.eapprox
#check @SimpleFunc.approx_apply
#check @SimpleFunc.monotone_eapprox
#check @SimpleFunc.iSup_eapprox_apply
#check @lintegral_eq_iSup_eapprox_lintegral

theorem eapprox_sup_eq {α : Type*} [MeasurableSpace α]
    (f : α → ℝ≥0∞) (hf : Measurable f) (x : α) :
    (⨆ n, SimpleFunc.eapprox f n x) = f x :=
  SimpleFunc.iSup_eapprox_apply hf x

-- 可測なfについての等式。lintegral自体の定義とは区別する。
theorem lintegral_eapprox_formula {α : Type*} [MeasurableSpace α]
    (f : α → ℝ≥0∞) (hf : Measurable f) (μ : Measure α) :
    (∫⁻ x, f x ∂μ) = ⨆ n, (SimpleFunc.eapprox f n).lintegral μ :=
  lintegral_eq_iSup_eapprox_lintegral hf
```

固定版の `eapprox` は、非負有理数を値域とする列 `SimpleFunc.ennrealRatEmbed` を使います。`f` が可測なとき、先頭の `n` 個（添字 `k < n`）の候補のうち `f x` 以下のものと0から、最大値を選んだものが `eapprox f n x` です。`n` 等分の刻み幅を使う実装ではありません。

列の定義と単調性には `Measurable f` は不要ですが、全ての点で上限が `f x` と一致する定理には可測性が必要です。`eapprox_sup_eq` は各点での上限を、`lintegral_eapprox_formula` は積分の上限との関係を確認しています。`⨆` は上限を表します。単調な列なので、上限は極限とも一致します。

:::message
🔗 **次章への伏線**

[第16章](ch16)で確認する `lintegral` の定義は、`f` 以下の単関数全体の積分の上限です。一つの近似列を指定して定義しているわけではありません。可測な `f` について `eapprox` による上限と一致することを述べる定理が `lintegral_eq_iSup_eapprox_lintegral` です。
:::

## 15.7 まとめ ──── 第15章の全対応表と練習問題

数学とLeanの対応を表にまとめます。

| 数学の表現 | Lean の表現 |
|---|---|
| 拡張非負実数値の単関数 $\phi : X \to [0, \infty]$ | `SimpleFunc α ℝ≥0∞` |
| 値域が有限 | `SimpleFunc.finite_range` |
| 各値の逆像が可測 | `SimpleFunc.measurableSet_fiber` |
| 定数単関数 | `SimpleFunc.const α c` |
| $\int \phi \, d\mu = \sum c_i \mu(A_i)$ | `SimpleFunc.lintegral φ μ` |
| 定数単関数の積分：$c \cdot \mu(X)$ | `SimpleFunc.const_lintegral` |
| 制限測度の全体 = 元の測度 $\mu(s)$ | `Measure.restrict_apply_univ` |
| 単関数近似列 $\phi_n \nearrow f$ | `SimpleFunc.eapprox f n` |
| $\sup_n \phi_n(x) = f(x)$ | `SimpleFunc.iSup_eapprox_apply` |

### 章末練習問題

**問題 15.1**　`SimpleFunc.const ℝ (3 : ℝ≥0∞)` の `.finite_range` の型を `#check` で確認し、どのような型の証明かを確かめてください。


:::details ヒントを見る

`#check (SimpleFunc.const ℝ (3 : ℝ≥0∞)).finite_range` で型を確認してください。通常の関数としての `Set.range` が有限である、という証明です。`Finset` を返す `.range` 自体と混同しないようにします。
:::

:::details 解答を見る

```lean:完成例・確認コマンド
import Mathlib
open MeasureTheory
open scoped ENNReal

#check @SimpleFunc.finite_range
#check (SimpleFunc.const ℝ (3 : ℝ≥0∞)).finite_range

theorem const_three_finite_range :
    (Set.range (SimpleFunc.const ℝ (3 : ℝ≥0∞) : ℝ → ℝ≥0∞)).Finite :=
  (SimpleFunc.const ℝ (3 : ℝ≥0∞)).finite_range
```

`SimpleFunc.finite_range` は、内部の `finite_range'` フィールドから値域の有限性を取り出す補題です。ここでは型の確認に加え、具体的な定数単関数についてその証明を与えています。
:::

:::details 別解を見る

```lean:完成例・確認コマンド
import Mathlib
open MeasureTheory
open scoped ENNReal

-- 値域が一点集合になるには、定義域の非空性が必要。
theorem const_range_nonempty {α : Type*} [MeasurableSpace α] [Nonempty α] :
    (SimpleFunc.const α (3 : ℝ≥0∞)).range = {3} :=
  SimpleFunc.range_const α 3

-- 空の定義域では値域も空。
theorem const_range_empty {α : Type*} [MeasurableSpace α] [IsEmpty α] :
    (SimpleFunc.const α (3 : ℝ≥0∞)).range = ∅ :=
  SimpleFunc.range_eq_empty_of_isEmpty _
```

定義域が非空なら、定数単関数の値域は1要素です。空の定義域では値をとる点がないため、値域も空です。非空性を省いた元の主張は一般には成り立ちません。
:::

**問題 15.2**　`id : ℝ≥0∞ → ℝ≥0∞` の近似について、`n = 0` では値が0であること、`n = 1` の近似が `n = 2` 以下であること、各段階の値が有限であることを証明してください。さらに、各点で近似列の上限が元の値に一致することを確認してください。


:::details ヒントを見る

`eapprox` は `Finset.range n` の上限を取るので、`n = 0` では候補がなく、単関数の最小元になります。単調性には `SimpleFunc.monotone_eapprox`、値の有限性には `SimpleFunc.eapprox_lt_top` を使います。
:::

:::details 解答を見る

```lean:完成例・確認コマンド
import Mathlib
open MeasureTheory
open scoped ENNReal

theorem eapprox_id_zero (x : ℝ≥0∞) :
    SimpleFunc.eapprox (id : ℝ≥0∞ → ℝ≥0∞) 0 x = 0 := by
  change (⊥ : SimpleFunc ℝ≥0∞ ℝ≥0∞) x = 0
  rfl

theorem eapprox_id_one_le_two (x : ℝ≥0∞) :
    SimpleFunc.eapprox (id : ℝ≥0∞ → ℝ≥0∞) 1 x ≤ SimpleFunc.eapprox id 2 x :=
  SimpleFunc.monotone_eapprox id (by decide : 1 ≤ 2) x

theorem eapprox_id_finite (n : ℕ) (x : ℝ≥0∞) :
    SimpleFunc.eapprox (id : ℝ≥0∞ → ℝ≥0∞) n x < ⊤ :=
  SimpleFunc.eapprox_lt_top id n x
```

`change` で0番目の近似を単関数の最小元と見なし、値が0であることを確認しています。`monotone_eapprox` に `1 ≤ 2` を渡して各点で評価し、`eapprox_lt_top` で値が `∞` でないことを示します。ここでは近似の性質を証明しており、`#eval` で数値を出しているわけではありません。
:::

:::details 別解を見る

```lean:完成例・確認コマンド
import Mathlib
open MeasureTheory
open scoped ENNReal

theorem eapprox_id_sup (x : ℝ≥0∞) :
    (⨆ n, SimpleFunc.eapprox (id : ℝ≥0∞ → ℝ≥0∞) n x) = x :=
  SimpleFunc.iSup_eapprox_apply measurable_id x
```

`measurable_id` が恒等関数の可測性を与えるため、`iSup_eapprox_apply` を適用できます。`x = ∞` の場合も、各項の値は有限のまま上限が `∞` になります。有限な値の列でも上限が有限とは限りません。
:::

**問題 15.3**　単関数 $\phi = \mathbf{1}_{[0,1]}$（$[0,1]$ の指示関数）を `SimpleFunc.piecewise` を使って構築し、その Lebesgue 積分が $1$ になることを確認してください。


:::details ヒントを見る

`SimpleFunc.piecewise` で内側を1、外側を0にします。`SimpleFunc.lintegral_eq_lintegral` で一般の非負積分へ移し、`lintegral_piecewise` と定数積分の公式を使えます。
:::

:::details 解答を見る

```lean:完成例・確認コマンド
import Mathlib
open MeasureTheory
open scoped ENNReal

theorem simple_indicator_unit_integral :
    (SimpleFunc.piecewise (Set.Icc (0 : ℝ) 1) measurableSet_Icc
      (SimpleFunc.const ℝ (1 : ℝ≥0∞))
      (SimpleFunc.const ℝ 0)).lintegral volume = 1 := by
  classical
  rw [← SimpleFunc.lintegral_eq_lintegral]
  simp only [SimpleFunc.coe_piecewise, SimpleFunc.coe_const]
  rw [lintegral_piecewise measurableSet_Icc]
  simp [Real.volume_Icc]
```

最初の書き換えで単関数の積分を一般の `lintegral` へ移し、関数としての `piecewise` を取り出しています。`lintegral_piecewise` は集合と補集合への制限積分の和を返します。定数積分の公式と `Real.volume_Icc` を使うと、`1 * 1 + 0 * ∞ = 1` になります。
:::

:::details 別解を見る

```lean:完成例・確認コマンド
import Mathlib
open MeasureTheory
open scoped ENNReal

theorem indicator_unit_lintegral :
    (∫⁻ x : ℝ, (Set.Icc 0 1).indicator (fun _ => (1 : ℝ≥0∞)) x) = 1 := by
  rw [lintegral_indicator measurableSet_Icc]
  simp [Real.volume_Icc]
```

`lintegral_indicator` を使って `lintegral` で直接計算する別解です。`SimpleFunc` を介さずに済みます。
:::

**📝 第15章 つまずきポイントQ&A**

**Q1. `SimpleFunc` と通常の関数（`α → β`）の型の違いは？**
→ `SimpleFunc α β` は「`α → β` の関数」に「値域が有限集合」「各値の逆像が可測」という条件を付けた構造体です。`toFun : α → β` フィールドで通常の関数として取り出せます。

**Q2. `SimpleFunc.lintegral` と `lintegral` の関係は？**
→ 一般の `lintegral μ f` は、`f` 以下の単関数の積分全体の上限です。単関数自身については `SimpleFunc.lintegral_eq_lintegral` で一致し、可測な一般の関数については `lintegral_eq_iSup_eapprox_lintegral` で特定の近似列の上限と一致します。

**Q3. 単関数を集合の外で0にするにはどうしますか？**
→ `[Zero β]` の下で `f.restrict A` を使えます。`hA : MeasurableSet A` があれば、`SimpleFunc.coe_restrict f hA` が通常の関数 `A.indicator f` との一致を与えます。固定版の `restrict` は、非可測な集合では零単関数になる定義です。可測性を確かめてから指示関数として扱います。

**Q4. 単関数の近似列はどう構成されますか？**
→ `SimpleFunc.eapprox f n` は非負有理数の列挙から作られます。単調性は `SimpleFunc.monotone_eapprox`、可測な `f` に対する各点での上限の一致は `SimpleFunc.iSup_eapprox_apply` が述べます。

**Q5. 単関数の `⊔` や `⊓` はどう使いますか？**
→ 値域 `β` が束なら `SimpleFunc α β` にも各点で計算する束の構造が入ります。`(f ⊔ g) x = f x ⊔ g x` であり、実数や `ℝ≥0∞` のような線形順序では最大値に対応します。任意の値域に追加仮定なしで束の構造があるわけではありません。
:::
