# 第6章：Banachの不動点定理 〜完備性が反復列の収束を保証する〜

## 6.0 本章のゴール：不動点の存在・一意性・反復列の収束

本章ではMathlibにあるBanachの不動点定理を適用し、一般の一意存在と、具体的な不動点・反復列の収束を証明します。Mathlib内部の定理を最初から再証明する章ではありません。

まず $f(x)=x/2$ が縮小写像であることを示し、Mathlibが与える不動点が0と等しいことを確認します。

```lean
import Mathlib
open Filter
open scoped Topology NNReal ENNReal

theorem halfContracting :
    ContractingWith (1 / 2 : ℝ≥0) (fun x : ℝ => x / 2) := by
  refine ⟨by norm_num, LipschitzWith.of_dist_le_mul fun x y => ?_⟩
  simp only [Real.dist_eq]
  rw [← sub_div, abs_div]
  norm_num
  ring_nf
  exact le_rfl

theorem half_fixedPoint_zero :
    halfContracting.fixedPoint (fun x : ℝ => x / 2) = 0 :=
  (halfContracting.fixedPoint_unique (by norm_num : (0 : ℝ) / 2 = 0)).symm
```

`halfContracting.fixedPoint (fun x : ℝ => x / 2)` がMathlibの定理から得る不動点です。`fixedPoint_unique` は、別途確認した不動点0がそれと等しいことを述べます。等号の向きを `.symm` で反転しています。

以下の完成例は、上の `import`・`open` と先行する名前付き宣言を引き継いで、掲載順に同じファイルへ置きます。途中の証明断片は指定された順に連結します。6.6節の意図的な失敗例と演習の `sorry` は別ファイルで実行してください。

一般の到達目標は次の形です。

```lean
-- 非空な完備距離空間上の縮小写像：一意存在と全初期点からの収束
theorem banach_fixed_point_and_convergence
    {X : Type*} [MetricSpace X] [CompleteSpace X] [Nonempty X]
    (f : X → X) {k : ℝ≥0} (hf : ContractingWith k f) :
    ∃! z : X, f z = z ∧
      ∀ x : X, Tendsto (fun n : ℕ => f^[n] x) atTop (𝓝 z) := by
  refine ⟨hf.fixedPoint f, ⟨hf.fixedPoint_isFixedPt,
    fun x => hf.tendsto_iterate_fixedPoint x⟩, ?_⟩
  intro y hy
  exact hf.fixedPoint_unique hy.1
```

不動点の存在と一意性だけでなく、すべての初期点から同じ点への収束を表しています。`∃! z, f z = z` そのものの証明も6.3節で取り出します。

## 6.1 縮小写像の数学とLeanの対応

距離空間 $(X,d)$ の写像 $f:X\to X$ が定数 $k\ge0$ のLipschitz連続であるとは、

$$
\forall x,y\in X,\quad d(f(x),f(y))\le k\,d(x,y)
$$

が成り立つことです。さらに $k<1$ なら縮小写像と呼びます。定数写像も含めるため、$k=0$ も許します。

![縮小写像の概念図。f を適用するたびに2点間の距離が k 倍以下になる様子](/images/vol2/fig-17.png)

```lean
-- 出力には一般の空間構造や宇宙変数も含まれる
#check @LipschitzWith
#check @ContractingWith
#check @ContractingWith.toLipschitzWith
```

`LipschitzWith k f` と `ContractingWith k f` は命題であり、型クラスではありません。証明を `hf : ContractingWith k f` のように受け取ります。`ContractingWith k f` は `k < 1 ∧ LipschitzWith k f` と定義されています。

一般のMathlibの定義では `edist` を使います。本章の距離空間では、`dist` を用いた次の同値で内容を確認できます。

```lean
theorem contracting_iff (k : ℝ≥0) (f : ℝ → ℝ) :
    ContractingWith k f ↔
      k < 1 ∧ ∀ x y, dist (f x) (f y) ≤ (k : ℝ) * dist x y := by
  constructor
  · intro ⟨hk, hlip⟩
    exact ⟨hk, hlip.dist_le_mul⟩
  · intro ⟨hk, h⟩
    exact ⟨hk, LipschitzWith.of_dist_le_mul h⟩
```

`k : ℝ≥0` は非負実数です。距離と掛けるときは `(k : ℝ)` として実数へ移します。`hf.toLipschitzWith` からLipschitz連続性の証明が得られ、そこから連続性も従います。

## 6.2 Banachの不動点定理：非空性・完備性・縮小性

**Banachの不動点定理（縮小写像原理）**：非空な完備距離空間 $(X,d)$ と、定数 $k\in[0,1)$ の縮小写像 $f:X\to X$ に対して、一意な不動点 $z$ が存在します。任意の $x_0\in X$ から定める反復列 $x_{n+1}=f(x_n)$ は、その $z$ に収束します。

$$
\exists! z\in X,\ f(z)=z,\qquad \lim_{n\to\infty}f^n(x_0)=z
$$

非空性は省けません。空の距離空間は完備で、空集合上の自己写像は縮小条件を満たしますが、不動点となる元はありません。初期点を明示的に与える場合は、その点から非空性が得られます。

### MathlibのAPIを読む

```lean
#check @ContractingWith.fixedPoint
#check @ContractingWith.fixedPoint_isFixedPt
#check @ContractingWith.fixedPoint_unique
#check @ContractingWith.fixedPoint_unique'
#check @ContractingWith.tendsto_iterate_fixedPoint
```

以下の表は距離空間の場合の要約です。完全な引数・型クラスは上の `#check` で確認できます。

| 役割 | `hf : ContractingWith k f` から使う表現 | 得られるもの |
|---|---|---|
| 不動点の構成 | `hf.fixedPoint f` | 点 $z$ |
| 不動点であること | `hf.fixedPoint_isFixedPt` | `Function.IsFixedPt f z`、すなわち `f z = z` |
| 一意性 | `hf.fixedPoint_unique hy` | `hy : f y = y` から `y = hf.fixedPoint f` |
| 2つの不動点の一致 | `hf.fixedPoint_unique' hx hy` | `f x = x` と `f y = y` から `x = y` |
| 反復列の収束 | `hf.tendsto_iterate_fixedPoint x₀` | `f^[n] x₀` が `hf.fixedPoint f` へ収束 |

`fixedPoint` の構成とそれへの収束には `[MetricSpace X] [CompleteSpace X] [Nonempty X]` を使います。一方、既に与えられた2つの不動点の一致を示す `fixedPoint_unique'` は、距離空間と縮小性だけで使えます。一意性の証明自体に完備性は必要ありません。

固定版には `ContractingWith.existsFixedPoint` という名前のAPIはありません。似た名前の `exists_fixedPoint` は拡張距離空間向けで、初期点と有限距離の仮定を受け取り、存在・その初期点からの収束・誤差評価を返します。本章の一意存在は、上のAPIから明示的に組み立てます。

## 6.3 $f(x)=x/2$ の一意存在を段階的に証明する

以下の6つのコードブロックは、1つの証明の続きです。6.0節の短い書き方を、ゴールの変化と対応させて確認します。

```lean
theorem half_map_fixed_point : ∃! z : ℝ, (fun x : ℝ => x / 2) z = z := by
```

最初のゴールは、ある `z` が不動点で、任意の不動点がその `z` と一致することです。

```text
⊢ ∃! z : ℝ, (fun x : ℝ => x / 2) z = z
```

まず縮小性を作ります。`constructor` で定数の条件とLipschitz条件に分けます。

```lean
  have hf : ContractingWith (1 / 2 : ℝ≥0) (fun x : ℝ => x / 2) := by
    constructor
    · norm_num
```

残るLipschitz条件は、距離による評価に直します。`LipschitzWith` のゴールへ直接 `intro x y` を使う前に、`LipschitzWith.of_dist_le_mul` で必要な形へ移ることが大切です。

```lean
    · apply LipschitzWith.of_dist_le_mul
      intro x y
      simp only [Real.dist_eq]
```

実数の距離が絶対値になりました。係数の型変換を整理すると、目標は次の不等式です。この表示は型変換の表記を省略した要約です。

```text
x y : ℝ
⊢ |x / 2 - y / 2| ≤ (1 / 2 : ℝ) * |x - y|
```

```lean
      rw [← sub_div, abs_div]
      norm_num
      ring_nf
      exact le_rfl
```

`sub_div` と `abs_div` により左辺を $|x-y|/2$ にします。`norm_num` と `ring_nf` が定数・積を整理し、最後は同じ量どうしの不等式なので `le_rfl` で閉じます。これで `hf` が得られました。

次に不動点を候補として指定し、その不動点性を渡します。

```lean
  refine ⟨hf.fixedPoint (fun x : ℝ => x / 2), hf.fixedPoint_isFixedPt, ?_⟩
```

残るゴールの意味は「任意の不動点 `y` が選んだ点と一致する」です。

```text
⊢ ∀ y : ℝ, (fun x : ℝ => x / 2) y = y →
    y = hf.fixedPoint (fun x : ℝ => x / 2)
```

```lean
  intro y hy
  exact hf.fixedPoint_unique hy
```

`fixedPoint_unique` の等号は、ここで必要な `y = fixedPoint` の向きです。6.0節で固定点の値を0と表示したときとは向きが異なります。

完成したファイルにエラー・警告がないことを確認し、主要定理は `#print axioms` で公理依存も調べます。カーソル位置の `No goals` だけでは、`sorry` がないことまでは保証されません。

### 一般の非空な完備距離空間へ

```lean
theorem banach_fixed_point
    (X : Type*) [MetricSpace X] [CompleteSpace X] [Nonempty X]
    (k : ℝ≥0) (f : X → X) (hf : ContractingWith k f) :
    ∃! z : X, f z = z := by
  refine ⟨hf.fixedPoint f, hf.fixedPoint_isFixedPt, ?_⟩
  intro y hy
  exact hf.fixedPoint_unique hy
```

この形には、距離・完備性・非空性・縮小性がすべて現れています。証明は実数の場合と同じです。

初期点を引数にするなら、非空性はその点から作れます。

```lean
-- 初期点を引数として受け取る場合は、それから Nonempty を作れる
theorem banach_fixed_point_from_start
    {X : Type*} [MetricSpace X] [CompleteSpace X]
    (x₀ : X) (f : X → X) {k : ℝ≥0} (hf : ContractingWith k f) :
    ∃! z : X, f z = z := by
  letI : Nonempty X := ⟨x₀⟩
  exact banach_fixed_point X k f hf
```

`letI : Nonempty X := ⟨x₀⟩` が局所的なインスタンスを与えます。初期点を受け取る形と、非空性を仮定する形は、このように結び付きます。

## 6.4 反復列が0に収束することを示す

次の2つのブロックを連結します。

```lean
theorem half_iterates_to_zero (x₀ : ℝ) :
    Tendsto (fun n : ℕ => (fun x : ℝ => x / 2)^[n] x₀) atTop (𝓝 0) := by
```

Mathlibの収束定理が直接与える収束先は `halfContracting.fixedPoint (fun x : ℝ => x / 2)` です。6.0節でその値が0だと証明したので、書き換えて目標の収束を得ます。

```lean
  simpa only [half_fixedPoint_zero] using
    halfContracting.tendsto_iterate_fixedPoint x₀
```

`fun n : ℕ => ...` が反復回数を変数とする数列です。`f^[n]` は関数の $n$ 回反復を表し、`f^[0]` は恒等写像です。

:::message
**連続性と反復列の収束は別の主張**

`Tendsto f (nhds a) (nhds (f a))` は、入力点が $a$ に近づくときの連続性です。`Tendsto (fun n : ℕ => f^[n] x₀) atTop (nhds z)` は、反復回数が増えるときの数列の収束です。同じフィルターの言語を使いますが、出発するフィルターと変化する変数が異なります。
:::

## 6.5 $\ell^2$ でも使える一般定理

前章で、$\ell^2$ は完備距離空間ですが、単位閉球はコンパクトではないことを確認しました。Banachの不動点定理には単位閉球のコンパクト性は不要です。$\ell^2$ はゼロ列を持つため非空でもあります。

```lean
abbrev ell2 := lp (fun _ : ℕ => ℝ) 2

#check (inferInstance : MetricSpace ell2)
#check (inferInstance : CompleteSpace ell2)
#check (inferInstance : Nonempty ell2)

theorem ell2_banach (f : ell2 → ell2) (k : ℝ≥0)
    (hf : ContractingWith k f) : ∃! z : ell2, f z = z :=
  banach_fixed_point ell2 k f hf
```

| 学んだ道具 | 不動点定理での役割 |
|---|---|
| `MetricSpace` | 距離による縮小条件と一意性 |
| `CompleteSpace` | Cauchy列の極限が空間内に存在すること |
| `Nonempty` | 反復を始める点が存在すること |
| `ContractingWith` | 反復列をCauchy列にする評価と連続性 |
| `Tendsto`・`atTop`・`nhds` | 反復列の収束の記述 |

## 6.6 最初の予告コードを読み直す

次のコードは、仮定の足りない主張を観察するための失敗例です。完成例と別ファイルで実行してください。

```lean
import Mathlib

-- 意図的な失敗例。完成例と別のファイルで実行する。
example (f : ℝ → ℝ) (a : ℝ) :
    Filter.Tendsto f (nhds a) (nhds (f a)) := by
  exact?
```

任意の関数が任意の点で連続であるとは限らないため、この一般的な主張は偽です。不動点定理を学んだ後も、仮定を追加しない元の主張が正しくなるわけではありません。

縮小写像を仮定すれば、Lipschitz連続性からすべての点で連続性が得られます。ここに完備性は不要です。さらに非空性と完備性から不動点を構成すると、その点の近傍が自分自身の近傍へ写るという収束も書けます。

```lean
theorem contracting_continuousAt
    {X : Type*} [MetricSpace X] {k : ℝ≥0} {f : X → X}
    (hf : ContractingWith k f) (a : X) : ContinuousAt f a :=
  hf.toLipschitzWith.continuous.continuousAt

theorem tendsto_at_fixedPoint
    {X : Type*} [MetricSpace X] [CompleteSpace X] [Nonempty X]
    {k : ℝ≥0} {f : X → X} (hf : ContractingWith k f) :
    Tendsto f (𝓝 (hf.fixedPoint f)) (𝓝 (hf.fixedPoint f)) := by
  simpa only [ContinuousAt, hf.fixedPoint_isFixedPt.eq] using
    contracting_continuousAt hf (hf.fixedPoint f)
```

後半の証明は、前半の連続性に `f z = z` を代入しています。不動点であることだけから連続性を導いているのではありません。

## 章末練習問題

**問1（縮小写像の確認）**

次の写像について、指定された定義域で縮小条件を満たすかを判定し、自己写像としてBanachの不動点定理を使えるか説明してください。

- (a) $f(x)=x/3+1$、定義域は $\mathbb{R}$。
- (b) $f(x)=(x+1)/(x+2)$、定義域は $[0,\infty)$。
- (c) $f(x)=\cos x$、まず定義域を $\mathbb{R}$ とし、次に $[0,1]$ へ制限する。

<details>
<summary>💡 ヒントを見る</summary>

平均値定理から、区間上で $|f'|\le k$ なら距離の評価が得られます。不動点定理を適用するときは、定義域が非空・完備であることと、その集合が写像で保たれることも確認します。
</details>

<details>
<summary>✅ 解答を見る</summary>

(a) $|f(x)-f(y)|=|x-y|/3$ なので、縮小定数は $1/3$ と取れます。実数全体は非空で完備です。

(b) $f'(x)=1/(x+2)^2$ で、$x\ge0$ なら $|f'(x)|\le1/4$ です。また $1/2\le f(x)<1$ なので $f([0,\infty))\subset[0,\infty)$ です。半直線は実数の閉集合であり、引き継いだ距離について非空・完備です。したがって縮小定数 $1/4$ で不動点定理を適用できます。閉集合であることと、自己写像として集合を保つことを別々に確認しましょう。

(c) 実数全体では縮小写像ではありません。もし定数 $k<1$ でLipschitz連続なら、微分係数の絶対値も $k$ 以下ですが、$x=\pi/2$ では $|\cos'(x)|=1$ となり矛盾します。これは差商の極限からの議論であり、異なる2点で距離評価の等号が成立するという主張ではありません。

一方、$[0,1]$ では $|\cos'(x)|=\sin x\le\sin1<1$ です。また $\cos([0,1])\subset[\cos1,1]\subset[0,1]$ なので、非空な完備距離空間 $[0,1]$ 上の縮小自己写像になります。任意の区間 $[a,b]\subset(0,\pi)$ で同じ結論になるわけではありません。

問1の区間・微分の議論は紙上の解答です。続く演習では(a)と $\ell^2$ の具体例をLeanで検証します。
</details>

<details>
<summary>🔍 定数の確認</summary>

```lean
example : (1 / 3 : ℝ≥0) < 1 := by norm_num
```

この確認だけでは写像のLipschitz条件まで証明したことにはなりません。
</details>

**問2（Leanで縮小性を証明する）**

次の演習の `sorry` を埋めてください。この骨格は完成例と別ファイルへ置きます。

```lean
import Mathlib
open scoped NNReal

-- 演習の穴。完成例とは別ファイルで実行する。
theorem affine_contraction_exercise :
    ContractingWith (1 / 3 : ℝ≥0) (fun x : ℝ => x / 3 + 1) := by

```

<details>
<summary>💡 ヒントを見る</summary>

`LipschitzWith.of_dist_le_mul` で距離の不等式へ移り、`Real.dist_eq` で実数の絶対値に直します。定数項の差を消してから `abs_div` を使います。

<details>
<summary>✅ 解答を見る</summary>

```lean
theorem affineContracting :
    ContractingWith (1 / 3 : ℝ≥0) (fun x : ℝ => x / 3 + 1) := by
  refine ⟨by norm_num, LipschitzWith.of_dist_le_mul fun x y => ?_⟩
  simp only [Real.dist_eq]
  rw [show x / 3 + 1 - (y / 3 + 1) = (x - y) / 3 by ring, abs_div]
  norm_num
  ring_nf
  exact le_rfl
```

`rw` で左辺を $|x-y|/3$ に書き換えます。最後のゴールは不等式なので、式を整理した後に `le_rfl` で閉じています。
</details>

<details>
<summary>🔄 calcを使う別解</summary>

```lean
theorem affineContracting_calc :
    ContractingWith (1 / 3 : ℝ≥0) (fun x : ℝ => x / 3 + 1) := by
  refine ⟨by norm_num, LipschitzWith.of_dist_le_mul fun x y => ?_⟩
  norm_num only [NNReal.coe_div, NNReal.coe_one, NNReal.coe_ofNat]
  simp only [Real.dist_eq]
  calc
    |x / 3 + 1 - (y / 3 + 1)| = |x - y| / 3 := by
      rw [show x / 3 + 1 - (y / 3 + 1) = (x - y) / 3 by ring, abs_div]
      norm_num
    _ ≤ (1 / 3 : ℝ) * |x - y| := le_of_eq (by ring)
```

`calc` の最後に等式を使う場合も、目標に合わせて `le_of_eq` で不等式を得ています。
</details>

**問3（不動点の値と反復列の収束）**

$f(x)=x/3+1$ の不動点を手計算で求め、問2の証明とMathlibの不動点APIを使って、一意存在・不動点の値・任意の初期点からの収束を証明してください。

<details>
<summary>💡 ヒントを見る</summary>

$z/3+1=z$ を解くと $z=3/2$ です。その点が不動点だと確認すれば、`affineContracting.fixedPoint_unique` でMathlibの不動点と一致させられます。
</details>

<details>
<summary>✅ 一意存在と値の解答</summary>

```lean
theorem affine_map_fixed_point : ∃! z : ℝ, (fun x : ℝ => x / 3 + 1) z = z :=
  banach_fixed_point ℝ (1 / 3) (fun x : ℝ => x / 3 + 1) affineContracting

theorem affine_fixedPoint_value :
    affineContracting.fixedPoint (fun x : ℝ => x / 3 + 1) = 3 / 2 :=
  (affineContracting.fixedPoint_unique
    (by norm_num : (3 / 2 : ℝ) / 3 + 1 = 3 / 2)).symm
```

`∃!` の証明と、選ばれた不動点が具体的な値に等しいという証明を分けました。`norm_num` は $f(3/2)=3/2$ を確認しています。
</details>

<details>
<summary>✅ 反復列の収束の解答</summary>


**問4（発展：$\ell^2$ 上で各成分を半分にする）**

$f(x)_n=x_n/2$ を定義し、縮小定数 $1/2$、不動点の一意存在、その値がゼロ列であること、反復列の収束を証明してください。完備性がどこで使われるかも説明してください。

<details>
<summary>💡 ヒントを見る</summary>

成分ごとに新しい数列を構成する代わりに、既存のスカラー倍 `(1 / 2 : ℝ) • x` を使います。`norm_smul` により、距離も $1/2$ 倍になります。
</details>

<details>
<summary>✅ 解答を見る</summary>

```lean
-- 6.5節の ell2 の定義を引き継ぐ
noncomputable def halfEll2 (x : ell2) : ell2 := (1 / 2 : ℝ) • x

theorem halfEll2_apply (x : ell2) (n : ℕ) : halfEll2 x n = x n / 2 := by
  simp [halfEll2, lp.coeFn_smul, smul_eq_mul, div_eq_mul_inv, mul_comm]

theorem halfEll2Contracting : ContractingWith (1 / 2 : ℝ≥0) halfEll2 := by
  refine ⟨by norm_num, LipschitzWith.of_dist_le_mul fun x y => ?_⟩
  simp only [halfEll2, dist_eq_norm, ← smul_sub, norm_smul]
  norm_num

theorem halfEll2_unique : ∃! z : ell2, halfEll2 z = z :=
  banach_fixed_point ell2 (1 / 2) halfEll2 halfEll2Contracting

theorem halfEll2_fixedPoint_zero : halfEll2Contracting.fixedPoint halfEll2 = 0 := by
  apply Eq.symm
  apply halfEll2Contracting.fixedPoint_unique
  simp [Function.IsFixedPt, halfEll2]

theorem halfEll2_iterates (x₀ : ell2) :
    Tendsto (fun n : ℕ => halfEll2^[n] x₀) atTop (𝓝 0) := by
  simpa only [halfEll2_fixedPoint_zero] using
    halfEll2Contracting.tendsto_iterate_fixedPoint x₀
```

`halfEll2_apply` でスカラー倍が意図した成分ごとの写像であることも確認しました。`norm_smul` で縮小性を示すため、無限和を一から展開する必要はありません。

一般定理の内部では、反復列がCauchy列になること、完備性から極限が空間内に存在すること、連続性からその極限が不動点であることを順に使います。ただし、この特定の写像についてゼロ列が不動点だと直接確認するだけなら、完備性は不要です。本解答は一般のBanachの不動点定理を適用する流れも検証しています。
</details>

## つまずきポイントQ&A

**Q1. 縮小性を表す証明は型クラスですか？**

`ContractingWith k f` は命題です。距離空間や完備性の型クラスとは異なり、通常は `hf : ContractingWith k f` として証明を渡します。

**Q2. `fixedPoint` は実際の値を計算する関数ですか？**

`fixedPoint` は非計算的な定義です。非空性から出発点を選び、存在が証明された反復列の極限を使って点を与えます。具体的な値を知りたい場合は、候補が不動点だと示し、一意性によって同定します。

**Q3. `efixedPoint` と `fixedPoint` は何が違いますか？**

`efixedPoint f hf x₀ hx` は拡張距離空間向けで、初期点 `x₀` と `hx : edist x₀ (f x₀) ≠ ∞` を受け取ります。一般の拡張距離空間では、有限距離で結ばれない部分どうしに別々の不動点があり得ます。`fixedPoint f hf` は非空な完備距離空間向けで、距離の有限性を自動で満たし、初期点によらない一意な不動点を与えます。

**Q4. どんな場面で使いますか？**

微分方程式の局所的な解の存在・一意性や、反復法の収束証明に使います。その際も、対象集合が非空・完備であること、その集合を写像が保つこと、1未満の一様な縮小定数を持つことを確かめます。Newton法も無条件に縮小写像になるわけではありません。
